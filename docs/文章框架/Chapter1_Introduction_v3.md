# 第一章 引言

## 1.1 研究背景:多智能体强化学习中的合作-竞争张力

多智能体强化学习(MARL)旨在通过多个智能体在共享环境中的持续交互,自主学习满足各自或集体目标的最优决策策略。过去十年间,MARL 在合作博弈(StarCraft Multi-Agent Challenge、Hanabi、Flatland)和纯零和博弈(围棋、星际争霸 1v1、Diplomacy)两个极端场景上取得了重大突破。然而,绝大多数真实世界的多智能体系统并不落在这两个极端,而是处于二者之间的**混合动机博弈**(mixed-motive games)区段——智能体的目标既不完全一致(纯合作),也不严格对立(零和),而是在合作与竞争之间存在持续的张力。

Leibo 等人于 2017 年开创性地提出**序贯社会困境**(Sequential Social Dilemma, SSD)范式 [Leibo et al., 2017],将经典博弈论中的囚徒困境、公地悲剧等单步社会困境扩展为时间和空间上展开的多步决策问题,代表性环境包括 Cleanup(公共物品困境)与 Harvest(公地资源悲剧)。Hughes 等人 [Hughes et al., 2018] 进一步通过引入不平等厌恶(inequity aversion)等内在动机机制,展示了人工智能体如何在跨期社会困境中维持合作。在此基础上,DeepMind 的 Melting Pot 基准 [Leibo et al., 2021] 系统化地评估了 MARL 算法在十余类混合动机场景下对新型社会伙伴的泛化能力。这一系列工作奠定了 mixed-motive MARL 作为 MARL 研究中**第三条主流路径**的学术地位(并列于纯合作 MARL 与零和博弈)。

尽管 mixed-motive MARL 已发展出活跃的研究社区,绝大多数现有方法仍存在一个根本性的局限:**它们将合作-竞争的博弈结构视为静态属性**——一个环境一旦被设定为社会困境,其囚徒博弈支付矩阵(或其时空展开版本)在整个学习过程中保持不变。这与真实世界中**博弈关系本身随环境状态动态演化**的事实严重脱节。海洋渔业可持续期与崩溃期的捕捞方关系、共享带宽充裕期与拥塞期的租户关系、电力系统平稳期与紧急调度期的节点关系——这些场景的本质都不是"静态的混合动机",而是**混合动机本身在合作与竞争两极之间漂移**。

本文聚焦的核心问题正是这一被忽视的子类:**博弈关系由环境的可观测物理状态(尤其是资源丰度)动态调控的多智能体混合动机博弈**。

## 1.2 公地资源:混合博弈的天然温床

在所有混合动机的真实场景中,**共享资源**(commons)是最具普遍性也最具研究价值的母题。Garrett Hardin 于 1968 年在《Science》发表的经典论文《公地悲剧》[Hardin, 1968] 指出,当多个自利个体共同使用一项可再生但容量有限的资源时,每个个体追求个人收益最大化的理性行为,会导致资源的过度消耗与最终崩溃——一个集体非理性的结果。Elinor Ostrom 等人则证明,人类社会通过演化出的规范、制度与沟通机制,可以在某些条件下避免这一悲剧 [Ostrom, 1990]。公地资源博弈因此成为博弈论、经济学、社会学与人工智能交叉研究的核心议题。

公地资源场景之所以是混合动机博弈的"天然温床",在于它具备一组特殊的内部结构,使得合作与竞争**从博弈结构本身涌现**,而无需通过奖励工程显式指定:

**结构 1(资源的时间动力学)**。 资源是**可再生但非无穷**的。其再生速率不仅取决于资源自身的状态(存量越接近上限,边际再生越慢),还取决于全局的环境条件——丰年时再生迅速,荒年时再生迟缓。在数学上,资源点 $k$ 的存量 $r_k$ 通常遵循形如下式的扩散-增长方程:
$$\frac{dr_k}{dt} = \underbrace{\alpha(c_t) \cdot f(\text{neighbors}(k)) \cdot (R_{\max} - r_k)}_{\text{再生项}} - \underbrace{\sum_i u_{i,k}(t)}_{\text{消耗项}}$$
其中 $\alpha(c_t)$ 是由全局丰度参数 $c_t$ 调控的再生率系数,$u_{i,k}$ 是智能体 $i$ 在资源点 $k$ 的瞬时采集量。该方程的非线性使得"留种"(留下部分资源以维持再生)与"竭泽"(立即采尽)之间存在内在的策略张力。

**结构 2(资源的空间分布性)**。 资源并非在地图上均匀分布,而是呈现**斑块化**(patchy)分布——存在富资源区(hotspots)与贫资源区(deserts)。智能体必须在采集点之间移动以最大化收益,因此空间维度成为博弈的额外舞台:富资源区往往被多个智能体同时争夺,贫资源区则面临"是否值得探索"的决策。资源点之间的空间邻近关系还通过结构 1 中的 $f(\text{neighbors}(k))$ 项,引入了空间外部性——一个资源点的存量影响邻居的再生速率,使得局部行为产生全局后果。

**结构 3(自利奖励 + 涌现博弈)**。 在 ResourceCommons 类环境中,每个智能体的瞬时奖励**纯粹是自利的**:
$$R_i(s, a) = (\text{智能体 } i \text{ 本步采集到的资源量}) - \epsilon \cdot (\text{移动代价})$$
**这里没有显式的合作奖励项,也没有显式的竞争惩罚项**。然而,这一极简的自利奖励结构,在结构 1 与结构 2 共同作用下,产生了博弈关系的自动切换:
- **当 $c_t$ 高时**(资源充裕,再生迅速):每个智能体即使全力采集也不会显著影响邻居与未来再生,采集行为之间**几乎不耦合**;若进一步引入协同采集加成机制(下文 1.3 节),合作甚至会被正向激励。
- **当 $c_t$ 低时**(资源稀缺,再生迟缓):每个智能体的采集行为直接挤压其他智能体的可采资源量;此时博弈逼近**零和**结构,公地悲剧成为纳什均衡的天然吸引子。

这一"自利奖励 + 涌现博弈"的设计原则,是 ResourceCommons 与传统通过奖励重塑(reward shaping)实现"合作-竞争切换"的环境的根本区别。它保证了博弈结构的真实性,也保证了研究问题不会退化为"被奖励标签驱动的多任务学习"。

## 1.3 关系非平稳混合博弈:形式化

### 1.3.1 共享上下文变量

为统一刻画上述资源驱动的混合博弈,本文引入**共享上下文变量** $c_t \in \mathcal{C} \subseteq \mathbb{R}$ 作为博弈关系演化的物理载体。**$c_t$ 直接对应于资源场的全局丰度指标**——它通过双重通道调节博弈结构:

$$\alpha(c_t): \text{ 资源再生率系数} \quad ; \quad \beta(c_t): \text{ 协同采集加成系数}$$

其中 $\alpha(\cdot), \beta(\cdot)$ 均为 $\mathcal{C}$ 上的单调递增函数。这一双重设计使得 $c_t$ 在两端分别凸显博弈的不同极:
- $c \to 1$ 时,$\alpha$ 和 $\beta$ 都高 → 资源再生迅速且多人采集获得正加成 → **合作占优**
- $c \to 0$ 时,$\alpha$ 和 $\beta$ 都低 → 资源稀缺且采集相互挤压 → **竞争占优(公地悲剧)**

$c_t$ 具有三个本质特性:

**特性 1(物理实在性)**。 $c_t$ 是环境状态的真实物理参数,具有明确的物理对应物(资源再生速率、生态承载力)。它**不是**人为指定给奖励函数的标签,也**不是**由 agent 行为直接生成的语义量。

**特性 2(关系调控性)**。 $c_t$ **不改变**底层物理转移分布 $P$(物体的运动、采集动作的执行机制都不依赖 $c$),但通过 $(\alpha(c), \beta(c))$ 间接调节合作-竞争张力。

**特性 3(部分可观测与不可控)**。 智能体可通过观测当前局部的资源密度推断 $c_t$ 的当前值或趋势,但**不能直接控制**它。$c_t$ 由环境的内禀机制演化或在 episode 起始由分布 $\rho_c$ 采样决定。

### 1.3.2 RNS-MMG 形式化定义

**定义 1(关系非平稳混合博弈,RNS-MMG)** 关系非平稳的多智能体混合博弈定义为元组
$$\mathcal{G} = \langle N, \mathcal{S}, \{\mathcal{A}_i\}_{i=1}^N, P, \{R_i\}_{i=1}^N, \{O_i\}_{i=1}^N, \mathcal{C}, P_c, \rho_c, \gamma \rangle$$
其中:
- $N$ 为智能体数量,$\mathcal{S}$ 为联合物理状态空间(包含资源场状态),$\mathcal{A}_i$ 为智能体 $i$ 的动作空间;
- $P: \mathcal{S} \times \mathcal{A} \to \Delta(\mathcal{S})$ 为**上下文无关**(context-invariant)的物理转移函数;
- $R_i: \mathcal{S} \times \mathcal{A} \to \mathbb{R}$ 为智能体 $i$ 的自利奖励函数(**不**直接依赖 $c$);
- $O_i$ 为智能体 $i$ 的观测函数;
- $\mathcal{C}$ 为共享上下文空间,$P_c$ 为上下文的内禀演化分布,$\rho_c$ 为 episode 起始时的初始化分布;
- $\gamma \in [0, 1)$ 为折扣因子。

该博弈需满足以下三条结构性约束:

**(C1) 物理转移的上下文不变性**:$\forall s, a, c_1, c_2: \quad P(\cdot \mid s, a; c_1) = P(\cdot \mid s, a; c_2)$。该约束将 RNS-MMG 与"物理动力学本身发生变化"的一般非平稳问题(如 Sim2Real、领域随机化)严格区分。

**(C2) 博弈关系的上下文耦合**:存在两个非平凡函数 $\alpha(c), \beta(c)$,通过资源场动力学(1.2 节式)与瞬时采集机制,使得在不同 $c$ 下,智能体策略集 $\{\pi_i^*(c)\}$ 之间的合作系数(以方差缩减或社会福利衡量)呈现单调连续的变化。该约束**不要求显式给出**合作-竞争权重函数——博弈关系是**由结构涌现的**,而非奖励工程指定的。

**(C3) 上下文的物理性与不可控性**:$c_t$ 是环境状态的一部分,其演化 $c_{t+1} \sim P_c(\cdot \mid c_t, s_t, a_t)$ 由环境内禀机制决定,智能体动作对其只有间接或缓慢影响。

### 1.3.3 研究目标

本文聚焦的核心研究问题是:

> **能否设计一个统一的 model-based 多智能体强化学习框架,使其在满足约束 (C1)-(C3) 的 RNS-MMG 中,同时实现以下三项目标?**
> - **目标 1(客观一致)**:学到的物理世界模型 $\hat{P}$ —— 尤其是资源场的时空动力学 —— 在所有 agent 间共享且不随 $c$ 切换发生坍缩;
> - **目标 2(主观适应)**:每个 agent 的策略与价值估计能根据自身能力特征与对当前博弈状态的信念(包括对 $c_t$ 与其他 agent 类型/意图的推断),动态调整合作-竞争倾向;
> - **目标 3(样本高效)**:在面对从未见过的 $c$ 值或新的社会伙伴构成时,无需重新训练即可零样本泛化。

## 1.4 现有方法的局限性

在 RNS-MMG 视角下重新审视现有 MARL 文献,可以系统识别出四类主流方法的核心局限:

| 方法类别 | 代表算法 | 在 RNS-MMG 下的核心局限 |
|---|---|---|
| 无模型协作 MARL | MAPPO、QMIX、MADDPG、VDN | 网络权重隐式拟合**特定 $c$ 下**的转移与奖励结构,$c$ 切换时面临灾难性遗忘;基于共享团队回报的设定违背混合动机的本质,无法处理 $c$ 低区段的零和性 |
| 单智能体世界模型扩展 | MuZero、Dreamer、DreamerV3 | 直接扩展到混合动机多智能体时,不同 agent 视角下相反的奖励信号会**撕裂共享世界模型**,导致同一资源场状态被映射到不同的物理预测(分叉坍缩) |
| 多智能体世界模型 | MAMBA、MARIE、MATWM、MABL | 几乎全部以**协作博弈**(SMAC、Flatland)为主战场,核心机制(集中通信、共享 critic)假定团队同质共赢,在 $c$ 低区段的竞争性子博弈中产生错误的协作偏置 |
| 社会困境专用方法 | Inequity Aversion [Hughes 2018]、Social Influence [Jaques 2019]、LIO [Yang 2020]、Conflict-Aware GA [Kim 2025] | 几乎全为**无模型方法**,样本效率受限;且大多通过内在动机或奖励重塑促进合作,**未触及"$c$ 演化下世界模型如何保持物理一致性"这一根本问题**;无法在合作-竞争连续切换的设定下平滑工作 |

这四类方法各自在"模型样本效率"、"非平稳适应"、"混合博弈处理"三个维度上有所长,但**没有任何现有方法同时具备这三种能力**。这正是 RNS-MMG 问题留下的算法空白,也是本文核心贡献的着力点。

## 1.5 本文的主要贡献

围绕上述研究问题,本文做出以下四点核心贡献:

**贡献 1(问题层面的形式化)**。 本文首次将"博弈关系由环境资源动态调控的多智能体混合博弈"作为一类独立的 MARL 问题进行形式化,定义为 **关系非平稳混合博弈 RNS-MMG**,并通过三条结构性约束 (C1)-(C3) 严格界定其与一般非平稳 MARL、静态社会困境、领域随机化等相关问题的边界。该形式化为 mixed-motive MARL 研究开辟了一个被长期忽视的关键子方向。

**贡献 2(算法层面的主客体解耦双路超网络)**。 针对传统多智能体世界模型在混合博弈下"主观奖励梯度撕裂客观状态预测"的痛点,本文提出双路超网络架构(DualHyperNetwork),将世界模型的参数生成显式分为两条通路:

- **客观通路** 仅依赖于环境上下文(含 $c_t$ 推断),生成共享的**资源场时空动力学**预测网络参数。它负责回答"资源如何再生、消耗、扩散"这一所有智能体客观面对的同一物理事实,保证物理预测的唯一性。

- **主观通路** 编码两类与智能体强相关的信息——**角色异质性**与**信念状态**——并生成 agent 特定的奖励预测与策略-价值网络参数:
   - **角色异质性**:每个智能体在物理能力(采集速度、视野范围、移动速度、负载容量)上存在固有差异,这些差异由可学习的能力嵌入(capability embedding)与身份嵌入(ID embedding)联合编码,使主观通路能针对"我这副身体"生成最合适的决策权重。
   - **信念状态**:由历史轨迹经 GRU 编码而成的隐含表示,综合刻画了智能体对**当前 $c_t$ 值**与**其他智能体的类型/意图**的推断。这一组合使主观通路不仅能适应"现在是丰年还是荒年",还能适应"我的对手是合作型还是剥削型"。

该设计在数学结构上严格对应于约束 (C1)-(C2):客观通路兑现 C1 的物理一致性,主观通路兑现 C2 的关系适应性。从博弈论视角看,这相当于将"共同知识"(common knowledge,即所有 agent 都同意的物理规律)与"私人信念"(private belief,即每个 agent 各自的视角)进行架构层面的解耦——这是 Harsanyi 不完全信息博弈 [Harsanyi, 1967] 在深度世界模型中的自然对应。

**贡献 3(规划层面的逐智能体协调下降 MVE 规划器)**。 针对联合动作空间在多智能体场景下的组合爆炸($A^N$)与"评估单个 agent 动作差异时被其他 agent 的随机性所淹没"的方差陷阱,本文提出 **Per-Agent Coordinate Descent MVE + Common Random Numbers (CRN)** 双重技术。协调下降将联合搜索空间从 $A^N$ 降为 $N \cdot A$,使有限采样预算具备真实判别力;CRN 通过在候选评估中固定其他 agent 的步零动作,将信号-噪声比从近零提升至理论最优,使规划器在资源博弈这种"动作差异微小但累积效应巨大"的场景中保持有效。

**贡献 4(实验层面的 ResourceCommons 基准与 SOTA 全面对比)**。 本文构建了 **ResourceCommons** —— 一个面向资源驱动混合博弈的多智能体基准环境,通过共享变量 $c_t$ 同时调控资源再生率 $\alpha(c)$ 与协同采集加成系数 $\beta(c)$,使合作与竞争从底层博弈结构中自然涌现。在该环境上,本文与覆盖三大方法类的 SOTA 算法进行系统对比:

- **Model-based MARL**:MA-MuZero(AAAI 2024)、MAMBA(AAMAS 2022)、MARIE(ICML 2024);
- **混合博弈专用**:Conflict-Aware Gradient Adjustment(NeurIPS 2025);
- **Model-free 经典基线**:MAPPO、QMIX。

并通过覆盖样本效率、零样本上下文泛化、社会福利、客观一致性、信念分化度等多维指标,验证本文方法在 RNS-MMG 类问题上的系统性优势。

## 1.6 论文组织结构

本文其余章节组织如下:

- **第二章 相关工作综述**。从 mixed-motive MARL 与社会困境、世界模型与基于模型的强化学习、非平稳与多任务 MARL、超网络与条件计算四个维度对相关文献进行梳理,定位本文在文献版图中的位置。
- **第三章 ResourceCommons 环境设计**。详细阐述基于可再生资源的混合博弈环境构造,包括资源场的时空动力学方程、协同采集加成机制、异质智能体能力建模、上下文 $c_t$ 的双重含义,以及"自利奖励 → 涌现博弈"的设计原则。
- **第四章 Hyper-MuZero 框架核心架构**。介绍主客体解耦双路超网络的设计原理,详细推导客观通路(资源场动力学)与主观通路(角色异质性 + 信念状态)的输入输出关系,并讨论功能网络的四层稳定性防线。
- **第五章 规划器与训练算法**。详细推导 Per-Agent Coordinate Descent MVE + CRN 的数学原理,介绍 MuZero 风格的 $K$ 步展开训练流程、信念状态推断网络的训练目标、Target Network EMA 稳定 bootstrap、Consistency Loss 等关键设计。
- **第六章 实验设置与结果分析**。给出完整实验协议(SOTA 基线适配细节、超参数配置、评估指标定义),报告主对比实验、消融实验、零样本上下文泛化实验、社会福利与个体公平性分析,以及超网络权重分化的可视化结果。
- **第七章 总结与展望**。总结本文核心贡献,讨论方法局限性,并展望离线 RL 扩展、规模化验证(8-16 智能体)、与真实工业场景对接等后续方向。
