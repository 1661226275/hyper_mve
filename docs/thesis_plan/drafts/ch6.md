## §6.1 贡献总结（~1 200 字）

> 本节在全文结论框架下，对本论文提出的四项核心贡献作系统性复述，并对照第五章的实验数据说明各项理论断言的验证状态。
>
> 本文工作从**问题形式化**出发，将博弈关系随可观测物理状态动态切换的场景抽象为**关系非平稳混合动机博弈（RNS-MMG）**，明确引入共享上下文变量 c_t 刻画博弈关系动态切换，并据此构建 **ResourceCommons** 仿真环境——该环境以可配置的 c_visible ∈ {True, False} 双档支持遮蔽条件下的消融对比，代码已随论文开源。在**算法层面**，本文设计了 DualHyperNetwork v2 架构，将超网络的生成通路显式分解为仅依赖共享上下文嵌入的"客观通路"（生成状态转移参数 θ_state）与融合 agent 身份嵌入的"主观通路"（生成奖励头参数 θ_rew 及预测头参数 θ_pred），在 Harsanyi 类比下的三联上下文 c_aug = [c_ctx, role_i, belief_i] 表示下，实现了跨 agent 视角的参数生成。在**规划层面**，本文将逐 agent 协调下降（Per-Agent Coordinate Descent）与公共随机数（CRN）注入相结合，实测信噪比从 0.02 提升至约 1.0，有效抑制了多智能体蒙特卡洛展开中的方差累积。
>
> 在**实证层面**，第五章对四项断言逐一作出报告：断言 A（类型梯度撕裂的钟形曲线）在消融 3 与 6.11 可视化中得到验证/部分支持/未支持 [写作时填入实测结果]；断言 B′（条件化谱内部最优）在 §5.5 七变体消融与零样本泛化测试中得到验证/部分支持/未支持；断言 C（三联通路缺一不可）在 §5.6 与 §5.10 双档信念质量测试中得到验证/部分支持/未支持；断言 D（CoordDesc × CRN 不可分割）在 §5.8 Easy N=2 完整 2×2 与 Medium N=4 必要性二轴中得到验证/部分支持/未支持。与此同时，从 v3 到 v4 的结构升级路径——包括 EMA 目标网络（τ=0.99）、Adam ε=1e-5 修正以及折扣因子 γ=0.95 的重新校准——作为保证上述断言可信性的工程前提，已在第四章加以说明。以下各节依次展开对局限性与未来方向的讨论。

## §6.2 局限（~900 字）

> 本节对本文方法与实验设计的适用边界作出如实说明，旨在帮助读者准确把握所得结论的有效范围。总体而言，本文的局限性可从规模泛化、消融覆盖度、社会偏好建模以及理论完备性四个维度加以梳理。
>
> 在 **agent 规模**方面，本文的主要实验均在 N=4 的 Medium 配置下完成，Hard 配置（N=8）仅提供了初步的 Scale-up 验证，尚未系统考察更大种群规模下联合动作空间急剧扩张对 MVE 规划器以及超网络参数量的双重压力。当 N 进一步增大时，CRN 在蒙特卡洛展开中的方差压制效果是否仍然稳健、超网络的表达容量能否在不引入显著计算开销的前提下随 N 线性扩展，这些问题在本文框架内均未得到充分实证回答。
>
> 在**消融实验的覆盖粒度**方面，联合枚举完整的 2×2 因子设计仅在 Easy（N=2）配置上实现；Medium 配置受限于计算资源，只针对协调轴与 CRN 轴提供了必要性证据，其余因子交互效应的分离验证有待后续工作补充。
>
> 在**社会偏好建模**方面，本文以 Fehr-Schmidt 不平等厌恶模型 [40] 作为类型 β 偏好结构的理论依据，该模型以不平等厌恶为核心参数，能够较简洁地刻画分配公平偏好。然而，社会偏好理论中存在多个并行流派：Charness 与 Rabin [45] 的效率-公平权衡模型强调对最低收益的关注，Bolton 与 Ockenfels 的 ERC 框架则将相对份额作为独立效用论元。本文未对上述替代族群进行系统性覆盖，因而所得结论在偏好规范的选择上仍带有一定的单一性。
>
> 此外，本文全程在仿真环境下开展实验，未涉及离线强化学习场景或真实工业数据集；隐藏-c 模式下 ĉ_i 的推断收敛性目前仅依赖实验曲线给出经验支撑，其完整的理论分析——包括 GRU 上下文编码器的辨识条件与收敛速率——尚未建立。上述局限性既界定了本文贡献的适用范围，也为后续研究指明了若干可具体推进的方向，下节将就此作出展望。

## §6.3 展望（~900 字，W2 两方向重点）

> 本节在总结全文结论的基础上，就 Hyper-MuZero 框架的两条可执行扩展路径展开讨论，并以制度治理耦合作为长期愿景的落脚点。
>
> **第一条路径面向工业规模的 8–16 agent 扩展**：当前实验在 4 agent、12×12 网格设置下完成，若将场景推进至 24×24 乃至更大的网格、同时增加 agent 数量，Per-Agent Coordinate Descent 的顺序更新复杂度将随 agent 数线性增长，需借助分布式实现加以消解；与此同时，HyperNet 在每个决策步动态生成全量参数的方式在大规模场景下存在显著计算冗余，可预先按 type × c bucket 离线展开参数并在推理时查表，从而将生成开销与在线规划解耦；在环境侧，将本框架与真实渔场仿真器对接，将使博弈涌现的实验结论向现实公地治理场景迁移提供直接的可行性验证。
>
> **第二条路径面向离线强化学习与历史公地数据的结合**：在线采集数据成本高昂、且受限于探索覆盖，若能利用渔场、牧场等历史采集记录作为经验回放的主体，则 BeliefNet 需适配回放轨迹中固有的 OOD（out-of-distribution）推断问题，具体而言，可参考 OMAR、ICQ 等离线 MARL 方法对保守约束的处理思路，同时将当前由在线观测驱动的 c_t 估计替换为从历史采集量反推的代理信号。
>
> 两条路径的交汇处，是 Ostrom [16] 所倡导的"设计原则驱动的公地自治"愿景：当 Hyper-MuZero 框架中的共享上下文 c_t 不再由研究者外生给定，而是与机制设计过程共演化，本文的技术框架便获得了与制度经济学接轨的潜在空间。

## §6.4 结语（~1 000 字）

> 本节对全文的研究路径作简要回顾，并重申本论文的方法论立场。从第三章起，本文沿一条相对集中的技术线索推进：以 v3 NonStationaryTag 环境为初始场景，验证超网络能够在零和阵营翻转场景下将博弈视角内化为条件权重，从而使同一主干网络在不同 REL 下呈现出不同的策略行为。这一阶段的核心关切在于证明可行性——即超网络条件化机制在非平稳博弈视角切换问题上是否成立，而非追求跨场景的广泛泛化。
>
> 在确认 v3 阶段的可行性之后，第四、五章将同一思路延伸至偏好异质的混合动机场景 ResourceCommons，引入 DualHyperNetwork v2、BeliefNet 三阶段课程与 Per-Agent MVE+CRN 规划器三项机制，并以四项预登记断言（A 至 D）作为可证伪的验证锚点。断言 A 关注超网络条件化对类型梯度撕裂的缓解作用，断言 B′ 聚焦条件化谱内部容量-优化最优点的存在，断言 C 检验三联上下文通路的必要性，断言 D 则考察规划器双重技术的不可分割性。四项断言之间存在层级依赖关系，任一断言的实验结果不支持预期方向，均触发预登记的贡献降级协议——这是本文在方法论层面的明确承诺，而非事后补充的保守措辞。
>
> 在**研究定位**上，本文无意主张开拓新的研究方向。非平稳多智能体强化学习、超网络权重生成以及基于模型的规划各自均有成熟的文献积累，本文所做的是将三者在一个具体问题设置下加以组合并在内部保持一致性：环境设计、模型结构、训练目标与评估指标之间的对应关系是明确的，各设计选择的依据在正文各节均有交代。这种**内部一致性**，而非单项技术的新颖性，构成本文方法论贡献的主要形式。第六章的消融实验与统计检验结果将在以下各节依次呈现，为上述四项断言提供具体的数值依据。
