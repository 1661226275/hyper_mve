## §4.1 动机：三个容量瓶颈（~2 500 字）

> 本节从代数层面确立三个容量瓶颈，为 DualHyperNetwork v2 的三条条件化通路提供形式化动机。
>
> 在 RNS-MMG 场景中，共享一套神经网络参数来同时服务于不同类型的 agent 会在三个维度上产生结构性失配。第一个瓶颈来自**类型梯度撕裂**。在 ResourceCommons 设定下，类型 α 的奖励 R^α_i = u_i 对联合动作的偏导 ∂R^α/∂u_i ≡ 1 恒为常数；类型 β 的奖励 R^β_i = u_i + φ(c)ψ(Δ_i) 对 u_i 的偏导依赖 (c, Δ_i) 取值，可取 {0, 0.7, 1.3, 2.0}（详见 §4.1.1 偏导表）。在 c 低区段（φ(c) > 0）类型 β 厌恶被甩开，∂R^β/∂u_i 可大于 1；在 c 高区段（φ(c) < 0）类型 β 反向厌恶超过他人，∂R^β/∂u_i 可小于 1。共享 RewardHead 的反向传播被两种相反方向的梯度同时拉扯，最终收敛到类型平均策略，而非任何一种类型所需的最优权重。这一失配随类型混合比例 ρ_β 接近 50/50 而加剧，是断言 A 钟形曲线的代数根源。
>
> 第二个瓶颈是**信念稀释**。Self Info 观测设定下，agent 仅能感知自己的类型与位置/速度等物理量，他人类型 τ_{-i} 对自己而言是隐变量。即使共享网络在不同信念后验 P(τ_{-i} | o_i^t) 下都"努力"学习，由于网络权重必须同时拟合所有后验下的最优策略，最终的拟合精度上界低于按后验分别建模的上界。这一现象在 Hughes 等人 [11] 的 Cleanup 环境与 Fehr & Schmidt [40] 的偏好建模文献中已有结构上类似的讨论。
>
> 第三个瓶颈是**角色平均**：每个 agent 在 episode 开始时被指派的能力向量 (η_i, φ^fov_i, ν_i, ζ_i) 是异质的——采集能力 η、视野半径 φ^fov、移动速度 ν、容量 ζ 在 ResourceCommons 中均从指定分布独立采样。共享主干将这些异质能力映射到同一隐空间时，所学到的表征是各能力维度上的折中，限制了任意单一 agent 的策略专化上限。这三个瓶颈恰好对应 DualHyperNetwork v2 的三条条件化通路：c_ctx 通路负责跨上下文物理动力学的解耦，role_i 通路承接能力与类型异质，belief_i 通路压缩对他人类型的后验。下节将逐一给出三条通路的形式化定义与实现。

**核心引用**：[40] Fehr & Schmidt 1999 · [11] Hughes 2018

## §4.2 条件化谱：容量-优化几何（~2 500 字）

> 本节将在条件化超网络的表达力-优化效率平面上建立一套几何分析框架，为后续断言 B′ 的理论预登记奠定基础。所谓"条件化谱"，是指将 per-context 参数生成机制视为一个连续坐标轴：左端为输入拼接（Input Concat），其等效参数增量 θ_eff(c) = θ_base ⊕ g_Θ(c) 仅在第一层引入 O(h) 量级的额外自由度；右端为全参数超网络（Full HyperNet），如 Ha 等 [42] 的原始构型，每个上下文 c 独立生成完整网络权重，可表达力达 O(h²)。FiLM [44]、CAVIA [43] 以及 LoRA（Hu et al. 2022）等方法则分布在谱的中间区段，以不同的秩或调制维度实现容量的连续插值。
>
> 在这一表达力维度之外，优化轴同样不可忽视。谱左端的方法依赖共享基础参数 θ_base 作为跨上下文的梯度累加器：不同上下文的损失信号在同一组参数上叠加，每次更新的方差相对较低，但也因此难以捕捉不同 c_t 区段下本质不同的奖励结构，导致**容量平均化**（capacity averaging）——网络学到的是所有上下文的混合最优策略，而非各上下文的专属策略。谱右端则走向另一个极端：per-context 梯度估计方差随自由度 O(h²) 增长而急剧放大，优化轨迹在高维参数空间中振荡，不同上下文的预测表征趋于坍缩——实验中观察到 **cos_pred_cross 由 0.61 升至 0.998**，即网络对不同上下文输出近乎相同的潜在向量，条件化的区分能力实质上已经丧失（Galanti & Wolf 2020 [44] 从谱归一化角度给出了类似的坍缩条件分析）。
>
> 上述两端的双面失败共同指向一个研究问题：在条件化谱的内部，是否存在一个"容量-优化"的帕累托最优区间，使得表达力足以区分不同 c_t 下的动态，同时优化方差又被控制在可接受范围内？本节将以此问题为核心，在 §4.3 中预登记**断言 B′**——即 film_head 加 LoRA 至 lora_fc2 的插值区段构成该最优区间的理论预测——并为第五章的消融实验提供可证伪的理论基准。

**核心引用**：[42] Ha 2017 ICLR · [43] CAVIA · [44] FiLM · Hu et al. 2022 LoRA · Galanti & Wolf 2020 NeurIPS

## §4.3 Harsanyi 类比：主-客通路的分解依据（~1 500 字）

> 本节以 Harsanyi（1967）不完全信息博弈的经典结构为参照，说明 DualHyperNetwork 双路分解在方法论层面的内在依据。Harsanyi 的核心贡献在于将不完全信息博弈统一为完全但不完美信息博弈：每个 agent 持有对世界物理规律的共同知识（common knowledge），同时持有仅属于自身的类型信息（type）以及基于观测形成的对他者类型的信念（beliefs over others）[10]。这一"公共—私有"二元结构，与本文 DualHyperNetwork 的双路设计存在自然的对应关系，**可作为方法选择的理论参照系**。
>
> 具体而言，主通路（objective pathway）以上下文编码 c_ctx 为输入，经 hyper_trans 生成转移函数参数 θ_state，刻画所有 agent 共同认可的物理动力学——对应 Harsanyi 框架中的共同知识部分。客通路（subjective pathway）则进一步分为两个层次：其一是 agent 的自身类型 role_i = [id_emb, cap_emb, type_emb]，描述固有身份与能力禀赋；其二是对他者类型的信念 belief_i = [ĉ_i, Pool({ẑ_{i,j}})]，以 GRU 编码的历史推断与跨 agent 池化聚合来近似 Harsanyi 意义下的异质私人信念 [10]。hyper_rew 与 hyper_pred 在上述角色与信念的联合作用下生成各 agent 的奖励参数 θ_reward 与策略参数 θ_pred，使主观偏好以结构化方式注入功能网络权重。
>
> 在方法论层面，这一设计与奖励塑形（reward shaping）存在范式上的分野。奖励塑形通过外加不平等厌恶项或社会福利项来干预 agent 的即时激励，如 Fehr & Schmidt（1999）[40] 的不平等厌恶模型在 Hughes 等人（2018）[11] 的序贯社会困境框架下被用作内在奖励项——其心理偏好以数值常数的形式直接叠加于环境奖励之上。本文的方法论承诺则有所不同：agent 的心理偏好由 role_i 与 belief_i 在参数空间中隐式编码，保持结构固定而非对每一步奖励施加修正；合作或竞争行为模式作为涌现结果，而非被显式规定。下一节将在此基础上详述双路结构的具体网络实现及各子模块的参数规格。

**核心引用**：[10] Harsanyi 1967 · [40] Fehr & Schmidt 1999 · [11] Hughes 2018

## §4.4 DualHyperNetwork v2 架构（D3 完整代数+工程纪律，~7 500 字）

> 本节系统展开 DualHyperNetwork v2 的完整架构设计。v1 版本已验证超网络生成函数参数这一基本路径，但其上下文编码仅采用单一规则嵌入，无法区分同一上下文下不同 agent 的主观视角，亦无法动态估计 c_t 切换的置信度；v2 针对这三点不足分别引入对应机制，构成本节的论述主线。
>
> **上下文编码**是 v2 的第一个关键扩展。v1 的规则嵌入被拆分为三路并行编码器：负责捕捉环境客观规则的 c_encoder（16 维）、捕捉 agent 角色身份的 role_encoder（32 维），以及动态估计 c_t 置信度的 belief_encoder（32 维）。三路输出拼接为 80 维增强上下文 c_aug，为后续双路超网提供差异化输入。其中 BeliefNet 以 GRU 为骨干，附接两个预测头：ĉ 头（sigmoid 标量）输出 c_t 置信度估计，ẑ 头（2-way softmax）在 Oracle 监督模式下给出他人类型的硬预测。这一设计使模型在无标注时仍可通过历史轨迹形成软置信，而无需强制依赖外部类型标签。
>
> **双路超网**的设计体现了客观性与主观性的分离。hyper_trans 仅接收 c_encoder 的 16 维客观上下文嵌入作为输入，生成状态转移功能网的参数 θ_state——状态动力学本质上与观察该状态的 agent 身份无关，因而不引入角色信息。相比之下，hyper_rew 与 hyper_pred 接收完整的 c_aug，分别生成奖励头与策略-价值头的参数，以捕捉不同 agent 在同一 c_t 下的主观差异。为在计算代价与生成精度之间取得平衡，v2 提供四档 partial generation 模式：full 模式生成全部参数（约 3.09M），film_head 仅更新 AdaLN 调制系数，lora_fc2 仅生成 LoRA 低秩增量，base_gen 则退化为固定基础网络（约 694k），四档覆盖的参数量差异超过四倍，可根据计算预算灵活切换。
>
> 在**参数稳定性**方面，v2 沿用并强化了 v1 的四层稳定性栈：small_init 限制超网输出初始幅度，LayerNorm 与 GroupNorm（Wu & He 2018）分别作用于功能网各层与超网权重分组，梯度裁剪防止超网路径的爆炸传播，Consistency loss（参考 BYOL [58]）约束 EMA 目标网络与在线网络的表示一致性。AdaLN 调制采用 (1+γ)⊙h 的残差形式（Peebles & Xie 2023），其中 1+ 项保证小初始化下信号不消失；权重增量的 grouped RMS 归一化使 ΔW 的有效幅度满足近似标度律 ‖ΔW‖_RMS ≈ output_scale²·√r，与 LoRA（Hu et al. 2022）低秩初始化纪律共同约束生成权重的初始谱范数。以下各小节依次对上述机制逐一展开。

**核心引用**：Peebles & Xie 2023 ICCV DiT · Karras 2019 CVPR StyleGAN · Wu & He 2018 ECCV GroupNorm · [58] Grill 2020 BYOL · Hu 2022 LoRA

## §4.5 规划层：Per-Agent Coordinate Descent + CRN（B 几何+实测，~2 500 字）

> 本节将建立规划层的两项核心技术：Per-Agent 协调下降（Coordinate Descent）与公共随机数（Common Random Numbers，CRN），并说明二者如何在结构上形成互补，共同使模型执行（MVE）规划在多智能体非平稳环境中具备实用意义。
>
> 多智能体规划面临两个相互独立却叠加的困难。其一为**组合爆炸**：若每位 agent 的离散动作数为 A，则 N 个 agent 的联合动作空间规模为 A^N，在本文 Medium 配置（N=4, A=6）下即 1296 个候选联合动作，穷举评估成本在每步重复展开时迅速变得不可承受。其二为**信噪比崩溃**：在多智能体随机策略下对候选动作进行蒙特卡洛估值时，其他 agent 的策略采样引入的方差量级远大于目标动作本身带来的价值差异，经测量基础 MVE 的信噪比（SNR）仅约 0.02，此时候选排序几乎等同于随机。
>
> **协调下降**将搜索方式从联合枚举改为逐 agent 轮询：固定其余 N−1 位 agent 的当前动作，对第 i 位 agent 枚举 A 个候选并取最优，再依次轮转，总评估次数降至 O(N·A)。轮询收敛后的不动点在博弈意义上对应一个 ε-纳什均衡，与联合最优解存在理论上可界定的偏差。**CRN** 则针对上述第二个困难：令同一展开步 0 的随机种子在所有候选动作间共享，其他 agent 的环境随机性在候选间严格对齐，差分估计量 ΔG = G(a_i) − G(a_i') 中的无关方差项经差分消去，方差由独立采样时的 2σ²_{a_-i} + 2σ²_{a_i} 缩减至 2σ²_{a_i}，对应 SNR 从约 0.02 提升至约 1.0。最终，对候选得分施加 z-score 归一化后再经 softmax 转换为动作概率，使规划输出对绝对奖励尺度保持不变性。下一节将给出上述两项技术的完整形式化定义及伪代码。

## §4.6 训练算法：Type-aware K 步展开 + 三阶段课程（~2 000 字）

> 本节给出本文核心训练算法的完整表述。在 MuZero 风格的基础框架之上，本算法融合了类型感知奖励分支、一致性辅助损失与三阶段课程调度，以处理 RNS-MMG 下的多智能体值估计问题。为保证各实验组在同等预算下的可比性，本节同时引入 μP 学习率对齐协议，与第五章公平对比实验的承诺相呼应。
>
> 算法主干采用 **K=5 步展开**配合 n-step return，并维护以指数移动平均（EMA，衰减系数 τ=0.99，等效更新率 0.01）更新的目标网络。每个展开步均调用表示网络与动力学网络，在共享潜状态 s^k 上估计价值与奖励；目标价值通过 n 步 Bellman 算子折叠后与 EMA 目标网络的输出做自举，折扣因子取 γ=0.95。这一结构将长时序信用分配与训练稳定性统一在同一展开过程中。
>
> 奖励头采用**类型感知（type-aware）双路径**设计：α 路径输出基础个体奖励 u_i，β 路径在 α 的基础上叠加 Fehr-Schmidt 调制项 φ(c_t)ψ(Δ_i)，其中 c_t 为当前共享上下文、Δ_i 为 instantaneous 不平等差。两路径共享主干编码层，仅最终线性头独立，使得模型在 c_t 处于 φ(c)≈0 区段时退化为标准 MuZero 奖励头，在 c_t 偏离中点时激活调制分支。
>
> 在辅助损失方面，本文引入 **BYOL 风格一致性损失** [58]：L_consist = −CosSim(proj(s^{k+1}), sg(proj(RepNet(o^{t+k+1}))))，以约束动力学网络预测的潜状态与表示网络观测编码之间的方向一致性，权重 w_consist=0.5。完整损失权重经 v4-opt 2026-06 勘正后固定为 w_policy=1.0、w_value=0.25、w_reward=3.0、w_belief=1.0。
>
> **BeliefNet 的训练调度遵循三阶段课程**：前 30% 迭代（Phase 1）中将真实他人类型标签直接注入信念网络（Oracle 强制），使早期梯度信号稳定建立；30%–70% 迭代区间（Phase 2）依照 Bengio 等人 [49, 51] 的渐进调度思路，对 Oracle 输入占比作线性退火；最终 30% 迭代（Phase 3）完全切换为自推断模式，令信念网络在无外部标签辅助下独立估计他人类型。这一设计在降低早期训练崩溃风险的同时，保证收敛阶段的推断能力得到充分锻炼。各超参数的取值逻辑与消融结果将在第五章展开讨论。

**核心引用**：[58] BYOL · [49] Bengio 2009 · [51] Bengio 2015 · Yang & Hu 2021 μP
