## §6.1 贡献总结与断言验证

本文的工作围绕**关系非平稳混合动机博弈（RNS-MMG）**这一问题设定推进，沿"问题—算法—规划—实证"四个层面展开，每一层面对应一项贡献。在**问题层面**，本文给出 RNS-MMG 的形式化，明确引入共享上下文 $c_t$ 作为博弈关系动态切换的载体，三条约束 (C1)–(C3) 分别刻画物理转移的 agent-同构性与上下文内禀演化性、奖励函数的类型-上下文联合调制、以及 $c_t$ 的物理不可控性，并据此构建 **ResourceCommons** 仿真环境，该环境以 `c_visible` 开关支持可见-$c$ 与隐藏-$c$ 两档实验。在**算法层面**，本文提出 **DualHyperNetwork v2**：客观通路（`hyper_trans`）仅消费共享上下文嵌入 $c_{ctx}$ 生成所有 agent 共用的状态转移参数 $\theta_{state}$，主观通路（`hyper_rew` / `hyper_pred`）消费三联上下文 $[c_{ctx}, role_i, belief_i]$ 生成 per-agent 的奖励与预测参数。该结构分解借用 Harsanyi [10] 不完全信息博弈中"共同知识 / 私人信息"的二分作为方法选择的理论参照系，与之在结构上类似。在**规划层面**，本文将 Per-Agent Coordinate Descent 与 CRN 注入相结合，前者将联合动作搜索从 $A^N$ 压缩至 $N \cdot A$ 解决多 agent 规划的计算可行性，后者通过共享第 0 步随机种子使候选动作间的真实差异不被其他 agent 随机性掩没。在**实证层面**，本文以四项可证伪断言 A / B′ / C / D 作为预登记的验证锚点，并就当前实验的支持程度据实报告如下。

## §6.2 局限

本节就本文方法与实验设计的适用边界作如实说明，旨在帮助读者准确把握所得结论的有效范围。本文的局限性可从 agent 规模、消融覆盖度、社会偏好建模、理论完备性四个维度梳理，并附加一项独立的 P0 工程披露。

在 **agent 规模**方面，本文的主要实验均在 N = 4 的 Medium 配置下完成，N = 8 的 Hard 配置仅作初步 Scale-up 验证，未系统考察更大种群规模下联合动作空间扩张对 MVE 规划器与超网络参数量的双重压力；CRN 的方差压制效果与超网容量能否随 N 线性扩展在本文范围内未给出充分实证回答。具体而言，当 N 增至 8 以上时，Per-Agent Coordinate Descent 的顺序更新步数随之线性增长，单步规划耗时进入 wall-clock 敏感区间；同时其他 agent 随机性的累积方差 $\mathrm{Var}(R_{others})$ 随 N 增长，CRN 在第 0 步抵消其他 agent 随机种子的方差压制效率是否仍能保持 SNR ≈ 1.0 需独立验证。在**消融覆盖度**方面，四项预登记断言中 B′ 与 D 仅获部分支持，A 与 C 的关键消融（消融 2、消融 3）尚未执行，因而 §6.1 表格中两项"未支持"严格意义上是覆盖度局限而非否定证据，但实证义务本身未完成的事实需如实承认。在**社会偏好建模**方面，本文以 Fehr-Schmidt 不平等厌恶模型 [40] 作为类型 β 的偏好实例化依据，未对 Charness 与 Rabin [45] 的效率-公平权衡模型、Bolton 与 Ockenfels 的 ERC 框架等平行流派作系统覆盖；Charness-Rabin 模型对最低收益者赋予额外权重，与 Fehr-Schmidt 的对称不平等惩罚在中性区段（$c \approx 0.5$）外的预测可能分歧，所得结论在偏好规范选择上带有单一性。在**理论完备性**方面，BeliefNet 在隐藏-$c$ 档下推断 $\hat{c}_i$ 的收敛性目前仅依赖经验曲线，GRU 上下文编码器的辨识条件与收敛速率尚未建立形式化证明；同样，Per-Agent Coordinate Descent 的不动点对应 $\varepsilon$-Nash 均衡这一陈述（§4.5）依赖 K 步 value 估计精确的假设，模型误差有限时 $\varepsilon$ 的上界形式化尚未完成。

此外作为独立的工程层局限，本文披露 BeliefNet 训练管道的 P0 问题：在 18 个隐藏-$c$ 档运行中有 14 个观察到 `loss/belief ≤ 1e-5`，表明该模块在当前优化设置下未能形成有效的梯度流。该问题的根因排查（损失尺度、梯度截断阈值、上下文编码器的归一化层位置）尚在进行中，§5.10 信念质量协议的硬验证因此暂以可见-$c$ 档实验作为替代锚点。该问题不影响 §6.1 中断言 B′ 与 D 的部分支持结论（两者依赖可见-$c$ 档实验），但断言 C 的完整验证需在 P0 修复后重新进行。上述局限既界定了本文贡献的适用范围，也为下节的展望提供具体的工作锚点。

## §6.3 展望

本节在全文结论的基础上，就 Hyper-MuZero 框架的两条可执行扩展路径展开讨论，并以 Ostrom [16] 制度治理愿景作长期收束。

**第一条路径面向工业规模的 8–16 agent 扩展**。当前实验在 N = 4、12×12 网格的 ResourceCommons 配置下完成，将场景推进至 24×24 网格、N ∈ {8, 16} 的工业规模时，Per-Agent Coordinate Descent 的顺序更新复杂度随 N 线性增长，可通过分布式实现按 agent 并行化加以消解；HyperNet 在每个决策步动态生成全量参数的方式在大规模场景下存在显著计算冗余，可预先按 type × $c_t$ bucket 离线展开参数并在推理时查表，将参数生成开销与在线规划解耦；环境侧将本框架与真实渔场仿真器对接，将使博弈涌现的实验结论向现实公地治理场景的可行性迁移提供直接验证。该方向的可行性瓶颈集中于 CRN 在大 N 设定下的方差压制效率是否随 $\sigma_{others}$ 量级增长仍能保持 SNR ≈ 1.0，相关压力测试构成 N = 16 配置下的核心实验设计。此外，BeliefNet 的私人信念维度 $|belief_i|$ 在工业规模下需重新校准——当 N 增至 16 时，每个 agent 需对其余 15 个 agent 的类型分布作联合推断，简单的 per-other-agent 类别分布建模将面临 $|\mathcal{T}|^{N-1}$ 状态空间组合爆炸，更现实的实现路径是引入分组（grouping）或共享种群分布先验以约束 BeliefNet 输出维度。

**第二条路径面向离线强化学习与历史公地数据的结合**。在线采集成本高昂且受限于探索覆盖，若能利用渔场、牧场等历史采集记录作为经验回放的主体，BeliefNet 需适配回放轨迹中固有的 OOD 推断问题。具体而言，可参考 OMAR、ICQ 等离线 MARL 方法对保守约束的处理思路（具体引用待写作时补充至 CITATION_REGISTRY），同时将当前由在线观测驱动的 $c_t$ 估计替换为从历史采集量反推的代理信号。该方向的关键挑战在于：历史数据的 $c_t$ 分布相对静态、与本文 RNS-MMG 设定下 $c_t$ 在 episode 内的持续演化不完全吻合，需要在保守离线目标与上下文外推之间建立校准协议；同时主观通路 $\theta_{rew}$ 与 $\theta_{pred}$ 在离线设定下的生成需附加分布外正则项以避免外推到训练分布以外的 $c_{ctx}$ 区段时输出参数发散。

两条路径的交汇处，是 Ostrom [16] 所倡导的"设计原则驱动的公地自治"愿景：当 Hyper-MuZero 框架中的共享上下文 $c_t$ 不再由研究者外生给定、而是与机制设计过程共演化，本文的技术框架便获得了与制度经济学接轨的潜在空间——agent 群体的类型分布 $\rho$、上下文动力学 $P_c$ 与制度规则一并进入策略搜索空间，形式上对应一个嵌套的 bi-level 优化问题，其内层是 RNS-MMG 下的多 agent 策略均衡，外层是规则设计的社会福利目标。该愿景的实现需要前两条路径作为前置技术储备，因而构成长期而非中期工作。

## §6.4 结语

本节对全文研究路径作简要回顾，并重申本论文的方法论立场。从 v3 NonStationaryTag（毕设汇报阶段已完成的可行性验证）到 v4 ResourceCommons（结构升级与四项断言预登记），本文沿一条相对集中的技术线索推进：以超网络在条件化机制下重写主观奖励与预测通路、以 Per-Agent MVE + CRN 在多 agent 规划层抑制方差累积、并以可证伪断言把方法层声明与实验结果硬绑定。v3 阶段证明了"超网络条件化博弈视角"在零和阵营翻转任务上的可行性，v4 阶段把同一思路延伸至偏好异质的混合动机场景，并通过 DualHyperNetwork v2、BeliefNet 三阶段课程与 Per-Agent MVE + CRN 规划器三项机制对 RNS-MMG 的 (C1)–(C3) 三条约束作架构层面的联合回应。

四项断言 A / B′ / C / D 之间存在层级依赖关系：A 检验类型条件化机制对反向梯度撕裂的缓解作用，B′ 检验条件化谱内部最优点的存在，C 检验三联通路的语义正交性，D 检验规划器双重技术的不可分割性。任一断言在实验中未支持预期方向，均按 §1.5 预登记方案触发对应贡献的降级或重定位。§6.1 表格中"2 项部分支持 + 2 项未支持"的当前状态对应"实验补完前不主张完整验证"的实证立场，而非对方法的否定。

在**研究定位**上，本文不主张开拓新的研究方向。非平稳多智能体强化学习、超网络权重生成与基于模型的规划各自均有成熟的文献积累，本文所做的是将三者在 RNS-MMG 这一具体问题设置下加以组合，并在内部保持一致性：问题形式化（§1.2 三条约束）、方法选择（§4 双路超网络 + Per-Agent MVE + CRN）、实验设计（§5 主对比 + 五项消融 + 零样本泛化 + hidden-c 双档信念质量）之间的对应关系是明确的，各设计选择的依据在正文相应章节均有交代。这种**内部一致性**——问题 ↔ 方法 ↔ 实验三者间的对应关系，而非单项技术的新颖性——构成本文方法论贡献的主要形式。换言之，本文不主张 DualHyperNetwork 在 MARL 文献中具有独立的架构贡献，仅主张其与 (C1)/(C2) 的客观-主观分解在结构上对应；不主张 Per-Agent MVE + CRN 的组合具有原创性，仅主张该组合在 RNS-MMG 设定下从计算-信号双失败模式的角度具有独立的必要性证据。预登记失败回退机制把这一立场具象化为可被否定的承诺：当 A / B′ / C / D 中两项及以上同时降级至最弱版本时，方法层贡献整体重定位为"对 RNS-MMG 设定下若干架构与规划选择的初步探索性比较"，§6 章贡献复述与未来工作章节相应整体改写。这一整体失败门槛存在于预登记承诺中，是本文实证规范的核心，也是本文与可被任意 hedge 的方法论叙述之间的关键区别。
