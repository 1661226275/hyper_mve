## §2.1 混合动机多智能体强化学习问题谱系

多智能体强化学习的早期工作多聚焦于两类极端假设之上：纯合作（所有 agent 共享单一团队奖励）与零和（一方收益等于另一方损失）。在纯合作设定下，Lowe 等人 [5] 的 MADDPG（其原始论文标题即 "Mixed Cooperative-Competitive"，严格意义上属于混合合作-竞争范畴而非纯合作）通过集中训练-分散执行（centralized training, decentralized execution, CTDE）框架推进了多 agent actor-critic 的样本效率；Rashid 等人 [4] 的 QMIX 通过单调价值分解使联合 Q 函数在保持单调性的前提下分解为个体 Q 函数之和；Yu 等人 [3] 的 MAPPO 系统性地评估了 PPO 在合作 MARL 上的有效性，并在 SMAC 等 benchmarks 上取得与专门设计的 CTDE 方法相当的表现。这一脉络的共同假设是 agent 间的支付结构由环境一次性给定，且在整个训练过程中保持不变；当支付结构随状态切换时，CTDE 框架本身并不提供对该切换的自适应机制。

混合动机博弈则放松上述两个极端，把"个体最优与集体最优不一致"的张力作为研究对象。Leibo 等人 [15] 把经典两步囚徒博弈推广为序贯社会困境（Sequential Social Dilemma, SSD），通过 Harvest（资源采集）与 Cleanup（污染清理）两个空间扩展环境刻画"短期个体收益 vs 长期集体可持续性"的张力——SSD 自此成为混合动机 MARL 最常被引用的实验载体。沿 SSD 范式向前的工作通常落在三类不同机制之一。**第一类是 reward shaping**：Hughes 等人 [11] 在 SSD 奖励函数中显式加入 Fehr-Schmidt 不平等厌恶项作为内在合作激励，把"个体不愿处于显著劣势或显著优势"这一行为经济学观察转化为可微的内在奖励；该机制的有效性建立在 shaping 强度在所有状态区段一致这一前提之上。**第二类是 intrinsic motivation regularizer**：Jaques 等人（2019）的 Social Influence 把因果影响——一个 agent 的动作对其他 agent 策略分布的因果作用——作为内在动机项加入策略目标，与博弈支付结构正交而非对其修改；该机制依赖于"对手策略在估计窗口内保持平稳"的假设。**第三类是 peer reward gifting**：Yang 等人（2020）的 LIO 让每个 agent 学习一个对其他 agent 发放奖励的元策略，通过元梯度优化"何时给他人奖励"以促进合作；该机制在 SSD 静态支付结构下的元目标方向是稳定的，但若博弈关系随状态切换则元目标方向可能在不同区段相反。

向静态混合博弈下的策略冲突问题方向，Kim 等人 [13] 的 Conflict-Aware Gradient Adjustment（CAGA）观察到不同 agent 的梯度方向在混合博弈中常常冲突，通过对梯度做方向感知的投影来缓解策略震荡。CAGA 与本文方法的相似性在于二者都明确"梯度方向冲突"作为方法层痛点，差别在于 CAGA 在 model-free 策略空间内做梯度调整，而本文沿 §1.3 已展开的论证，把冲突归因于共享 RewardHead 上的反向传播，并在世界模型的功能网生成层而非策略层做条件化分解。

向更系统化的环境评测方向，Leibo 等人 [14] 的 Melting Pot 把 SSD 思路扩展为多场景套件，引入 substrate（基础环境）+ scenario（参与者组合）两层结构以评估泛化能力。Melting Pot 的 substrate 集合涵盖 Cleanup、Harvest 等经典 SSD 任务，但每条 rollout 内部物理上下文保持静态——场景切换发生在 episode 间或 substrate 间，而非 episode 内。

与 SSD 谱系正交，非平稳 MARL 谱系处理"博弈支付随时间变化"这一更一般问题。Hernandez-Leal 等人 [21] 的综述把非平稳 MARL 的应对策略组织为对手建模、元学习、自适应学习率三类——其中 Bowling 与 Veloso [20] 的 WoLF 系列在策略空间内做 best-response dynamic 的学习率自适应，处理的是博弈策略层而非偏好结构层的非平稳。这一谱系上的工作在 §1.3 已分类讨论，本节只需补充说明其与混合动机谱系的边界：非平稳 MARL 通常不假设支付结构的异质性，混合动机 MARL 通常不假设支付结构随时间切换，二者交叉处的"博弈关系随物理状态切换 × 类型异质性"两要素同时成立的子区段，是 §1.2 RNS-MMG 形式化所定位的具体情形。

值得一并指出的是，上下文化决策过程家族——Contextual MDP（Hallak 等人，2015）、Hidden-Parameter MDP（Doshi-Velez 与 Konidaris，2016）、Latent-MDP / BAMDP——对"博弈/MDP 随外部上下文调制"问题有相对成熟的工具集。Contextual MDP 引入潜在任务索引调制单一 agent 的转移与奖励；HiP-MDP 假设潜变量按 episode 静态采样且 episode 内保持不变；BAMDP（贝叶斯自适应 MDP）显式建模 agent 对潜变量的后验更新过程。这三类工作的共同假设是单 agent 设定下的潜变量调制，与 §1.2 形式化的 RNS-MMG 存在两点差别：其一，上下文化决策家族不直接处理多 agent 类型异质性下的 (C2) 联合调制；其二，HiP-MDP / BAMDP 假设潜变量在 episode 内静态，与 RNS-MMG 的 c_t 按 intra-episode 动力学持续演化的设定不符。本文方法的 BeliefNet 在思路上与 BAMDP 的后验更新有相似动机——把对潜变量的在线推断作为方法层组件——但具体实现层级不同（BAMDP 在策略层做后验更新，本文 BeliefNet 在世界模型的功能网生成层做推断）。

回到本文 RNS-MMG 设定，上述五类工作（[15][11][14][13]、Jaques 2019、Yang 2020）对 §1.2 的 (C1)-(C3) 三条约束各自有局部覆盖但没有联合回应。SSD 与 Melting Pot 共享"博弈关系在 episode 内静态"前提，与 RNS-MMG 中 c_t 沿 intra-episode 动力学演化的设定不兼容；不平等厌恶 shaping 把偏好结构注入瞬时支付层，与本文把偏好结构作为类型变量条件化生成 RewardHead 的方案在层级上不同；Social Influence 与 LIO 的假设——对手策略平稳、元目标方向稳定——在 c_t 切换处不成立；CAGA 的梯度投影机制不依赖博弈关系的可观测调控变量，与 (C3) c_t 的内禀演化设定正交。本文不在 §2.1 主张 RNS-MMG 对上述谱系做出"补全"，而是把它定位为该谱系上"博弈关系随物理状态动态切换 × 类型异质性 × intra-episode 演化"三要素同时成立的一个子区段——子区段之外的设定（如 SSD 的静态支付）已有有效方法，本文方法的针对性仅限于该子区段。

## §2.2 多智能体世界模型方法

基于学习世界模型的规划方法在单 agent 场景下已取得突破性表现。Schrittwieser 等人 [24] 的 MuZero 用学到的潜在动力学模型——表征网络（representation）、动力学网络（dynamics）、预测网络（prediction）三件套——替代真实模拟器进行 MCTS 搜索，在 Atari、围棋、国际象棋上同时达到 SOTA；Hafner 等人 [6] 的 Dreamer 以学到的递归状态空间模型支持策略学习，DreamerV3 [7] 进一步通过 symlog 预测与归一化层组合在跨领域上取得统一的 hyper-parameter 设定。沿 model-based value estimation 一脉的工作，Feinberg 等人 [67] 的 MVE 把 K 步学到模型 rollout 与剩余 critic bootstrap 拼接成低偏差-低方差的价值估计——本文 §4.5 的 Per-Agent MVE planner 沿此思路推广到多 agent 场景。

把这一范式扩展到多智能体场景的代表性工作有三类不同程度的架构调整。**MA-MuZero**（[30]，AAAI 2024 候选条目，作者列表与精确发表场所详见注册表）把 MuZero 推广到多 agent 联合动作空间，针对 $A^N$ 组合爆炸问题采用 Gumbel 采样部分缓解；其奖励预测头通常仍共享，因为目标应用场景偏向合作设定下环境奖励本身共享。**MAMBA**（Egorov 与 Shpilman，[8]，AAMAS 2022）采用 CTDE + Transformer 融合多 agent 观测的设计，每个 agent 有各自的 prediction head 但 head 间无显式条件化通路；其针对的核心痛点是多 agent 观测融合的可扩展性而非偏好异质性。**MARIE**（Liu 等人，[17]，ICML 2024）的核心卖点是 role-aware encoding——按 agent 在博弈中担任的位置（如 Hunter、Prey 等任务角色）做条件化编码，使共享 backbone 在异质任务角色上能更稳定地学习。MARIE 与本文方法在动机上最接近，差别在于其 role 编码"在博弈中担任何种位置"，本文 type 编码"偏好结构属于何种家族"——二者在 RNS-MMG 下需联合作用，本文 §4.3 三联通路 [c_ctx, role_i, belief_i] 的 role_i 通路与 MARIE 的 role 编码在功能上同源，但本文方法在该通路之外还增加了 belief_i 通路以覆盖部分可观测下的他人类型推断。三类系统在 RNS-MMG 设定下共享 §1.3 已论证的容量瓶颈——类型异质 agent 在共享 RewardHead 上产生方向相反的反向传播梯度——其差别在于该瓶颈在每类系统上的具体形式不同，本文统一称之为"类型梯度撕裂"。

理解条件化机制谱是把方法层选择放置到统一坐标上的关键。**Input Conditioning**（CAVIA，Zintgraf 等人 [43]）在共享权重之上拼接上下文向量作为输入的一部分，参数容量在 agent 间完全共享，调制能力来自输入空间的扩展；该机制的优点是参数高效，缺点是当不同类型的最优响应在功能层差异较大时，输入侧的拼接无法充分区分。**FiLM**（Perez 等人 [44]）在共享主干的中间层做对角调制（feature-wise linear modulation, $\gamma \odot h + \beta$），通过低维调制向量实现轻量条件化；FiLM 在视觉问答等任务上证明了对角调制即可显著改变网络功能，但其调制空间维度受限于通道数。**LoRA**（Hu 等人，2022）通过秩-r 增量 $\Delta W = BA$ 实现中等容量的条件化——保留共享 backbone $W_0$ 的同时为每个上下文学习一个低秩偏移，参数量随秩 r 线性增长；该机制在大语言模型适配领域已成为标准做法。**HyperNetworks**（Ha 等人 [42]）则处在谱的另一端——一个 hypernet 完整生成目标网络的所有参数，调制能力最强但优化代价也最大；其后续工作如 Galanti 与 Wolf（2020）讨论了模块化 hypernet 的稳定性问题，von Oswald 等人（2020）把 hypernet 用于持续学习场景以缓解灾难性遗忘。

在本文实验套件内部，沿这一条件化机制谱的实证比较呈现清晰的非单调结构。**Input Conditioning** 端的 `main_comparison_easy`（3 seeds, 137k steps）planner 收益 105 ± 5、cos_pred_cross 0.72 ± 0.02——cos_pred_cross 接近 1 表明不同 agent 视角下的 prediction 网络输出在方向上几乎一致，对应的视角分离能力非常有限；同一谱位置的 `zero_shot_easy`（3 seeds, 200k steps）planner 收益 104 ± 3、cos_pred_cross 0.71 ± 0.01 进一步确认了 105 一线的收益天花板。沿谱向中间移动，**LoRA on duo（无 FiLM）** 的 `lora_duo_base` 单 seed 上 planner 收益 263、cos_pred_cross 0.08——cos_pred_cross 从 0.72 降至 0.08 意味着视角分离能力显著增强；**FiLM-only 头部条件化** 的 `lora_duo_film`（2 seeds, 240k steps）planner 收益 250 ± 2、cos_pred_cross 0.09，与 LoRA 端在同一性能区段。继续沿谱向中等容量方向移动，**FiLM + LoRA on fc2** 的 `lora_duo_film_fc2`（3 seeds, 240k steps）planner 收益 272 ± 18、cos_pred_cross 0.03、planner_prior_gap +19.6 ± 6.7——在本文已完成的所有 gen_scope 变体中达到收益峰值。这一组数字在本节作为前向参考给出，具体的实证比较与方差检验见 §4.2 与 §5.5；本文不主张该比较已穷尽条件化谱所有位置，谱右端（base_gen、full）的方向坍缩现象——FULL gen_scope 在早期开发中观察到的 cos_pred_cross 0.61 → 0.998 训练演化——属于 v4-opt 优化阶段的工程观察 [证据待补 EVIDENCE PENDING — FULL gen_scope 谱右端坍缩的预登记复现，待 §5.5 补完]，在 §2.2 仅作为方法谱的边界提示，不在本章作为正式断言。

社会偏好建模为本文偏好层设计提供了直接的理论参照。Fehr 与 Schmidt [40] 在 1999 年提出不平等厌恶模型，用 ($\lambda_{\text{disadv}}, \lambda_{\text{adv}}$) 两个非负参数刻画 agent 对劣势状态与优势状态的非对称反感——劣势厌恶通常显著强于优势厌恶（实验经济学经典值 $\lambda_{\text{disadv}} = 2.0, \lambda_{\text{adv}} = 0.6$），本文 §3.5 偏好层直接沿用这两个经典值。Charness 与 Rabin [45] 进一步通过一系列简单博弈测试表明，被试的社会偏好不能由单一的"利他系数"刻画，需要同时包含不平等厌恶、互惠性、社会效率三类成分；本文 §3.5 在偏好层只保留 Fehr-Schmidt 不平等厌恶项作为类型 β 的偏好成分，把更广义的社会偏好建模留作未来工作。

Harsanyi [10] 在 1967 年提出不完全信息博弈框架，把每个 player 拆解为两层：一层是**共同知识**（所有 player 都同意的物理规律、他人的理性程度、可能的类型空间），另一层是**私人信念**（每个 player 对他人类型的后验估计）。Harsanyi 进一步证明，任何不完全信息博弈都可以被转换为一个等价的具备类型变量的完全信息博弈——所谓"Harsanyi 变换"——通过引入 nature 在博弈开始时按先验分布抽取每个 player 的类型这一辅助步骤，使所有 player 在结构上面对同一个共同知识层，仅在类型层有私人信息差异。这一二分在 RNS-MMG 设定下具有直接的语义对应：环境上下文 $c_t$ 是所有 agent 都可观测（在 c_visible=True 档下）或可推断（在 c_visible=False 档下）的物理变量，属于共同知识层；每个 agent 自身的类型 $\tau_i$ 由 agent 自身已知，但其他 agent 对该类型只有先验或基于历史的后验估计，属于私人信念层。本文 §4.3 把 DualHyperNetwork 的双路分解——客观通路 hyper_trans 仅消费共享上下文 c_t（共同知识）生成所有 agent 共用的状态转移权重，主观通路 hyper_rew 与 hyper_pred 消费三联上下文 $[c_{\text{ctx}}, \text{role}_i, \text{belief}_i]$（共同知识 + 自身类型 + 对他人类型的信念）生成 per-agent 权重——与 Harsanyi 二分做结构类比，作为方法选择的理论参照系。结构类比的三点对应分别如下：(i) 客观通路对应 Harsanyi 的共同知识层——物理转移是所有 agent 都同意的规律，hyper_trans 不依赖 agent-specific 输入，与 §1.2 (C1) agent-同构性形成对应；(ii) 主观通路的 role_i 输入对应 agent 自身类型——agent 自己知道自己是类型 α 还是类型 β，与 Harsanyi 框架中 player 知晓自身类型的设定一致；(iii) 主观通路的 belief_i 输入对应 agent 对他人类型的私人信念——在 c_visible=False 与 self-info-only 观测档下，agent 对其他 agent 的类型只有基于交互历史的后验估计，由 BeliefNet 在线推断。需要明确的是，本文不主张这一类比是 Harsanyi 框架在深度世界模型中的等价"实现"，也不主张它在架构层与该框架形成形式化对应。Harsanyi 框架是博弈论层的概念性二分，本文是神经网络架构层的工程实现；二者的对应仅是结构相似，无形式化等价证明。在第 4 章给出双路超网络架构时，这一类比仅作为方法选择动机的说明工具，不在贡献声明中出现。本节就此把 Harsanyi 框架与本文方法的关系刻画完毕：借用其"共同知识/私人信念"二分作为分解依据，不主张更强的对应主张。

## §2.3 基准与评测

现有 mixed-motive MARL 基准可沿两条正交的维度做分类——"博弈关系是否在 episode 内动态切换"与"偏好层是否显式异质"——本文据此把代表性基准与本文 ResourceCommons 的关系组织如下表。Harvest 与 Cleanup（Leibo 等人 [15]、Hughes 等人 [11]）作为最早的 SSD 实例，在物理层提供资源采集/污染清理的空间博弈，但博弈关系（合作压力的强度）在整个 episode 内由固定的支付矩阵给出，且所有 agent 共享同一奖励函数（同质偏好）。在 Hughes 等人 [11] 的不平等厌恶变体中，agent 的内在奖励项虽然引入了对劣势状态的反感系数，但该系数在所有 agent 间相同，未引入类型异质。Melting Pot [14] 在前述基准之上引入 substrate + scenario 两层结构，把若干 SSD 任务统一为多场景套件，使泛化能力评测成为可能；但单条 rollout 内部博弈关系仍保持静态，场景切换发生在 episode 间。Kim 等人 [13] 的 CAGA 工作针对静态混合博弈下的类型差异问题，引入若干带类型变量的合成基准，但其类型仅影响策略冲突的方向，未引入 c_t 这样的可观测博弈关系调控变量。

本文构建的 ResourceCommons（§3.3 详述）沿两条维度同时引入新元素：物理层由 c_t 调控博弈关系的动态切换（c_t ∈ [0, 1] 表示资源丰度，低 c 区段下博弈关系偏向竞争，高 c 区段下偏向合作，c 中性区段下两类博弈关系近乎并存），偏好层引入类型 α / 类型 β 的显式异质——类型 α 是利己个体（瞬时奖励梯度恒为 $+1$），类型 β 是带不平等厌恶的社会偏好个体（瞬时奖励梯度在 $(c, \Delta)$ 不同区段取值于 $\{0, 0.7, 1.3, 2.0\}$，具体取值表见 §4.1.1）。这两条维度同时引入使 ResourceCommons 成为现有基准矩阵中尚未被填充的格位——但这并非 §2.3 的主张，本文不把"新基准"作为独立贡献声明（§1.4 贡献 4 是把基准作为可证伪断言的实证载体），仅说明 ResourceCommons 的设计在现有基准坐标上的相对位置。

评测指标家族沿用 SSD 工作的核心指标并补充 RNS-MMG 特有指标。沿用部分包括：**社会福利** $V_{\text{total}} = \sum_i R_i$ 作为聚合性能指标；**可持续性指标**（如回合末资源存量、Hughes 等人 [11] 提出的 sustainability metric）评估长期合作维护能力；**Gini 公平** 评估个体回报分布的均匀性，避免社会福利单一指标掩盖少数 agent 系统性受损。RNS-MMG 特有指标包括三类。**零样本 c 泛化**——训练时见 $c \in \{0.2, 0.5, 0.8\}$ 三档，测试 $c \in \{0.0, 0.35, 0.65, 1.0\}$ 四档，评估方法在未见 c 值上的策略一致性；本文 `zero_shot_easy` cell（3 seeds, 200k steps）已完成此项验证，registry return_zero_shot_unseen ≈ 130.88（TB 端 planner 收益 104 ± 3.3），且 regret_mean = 0.0（三个 seed 在未见 c 上的策略与训练 c 上的策略相比无系统性 regret），作为断言 B′ 谱内最优变体的零样本预览（详见 §5.5）。**隐藏-c 信念质量**——在 c_visible=False 档下评估 BeliefNet 推断的 $\hat{c}_i$ 与真实 $c_t$ 的 MSE 与 Pearson 相关系数，是断言 B′(ii) 与断言 C belief 通路的核心硬验证指标；需要诚实声明的是，本文当前实验套件中 belief pipeline 存在 P0 级问题——`loss/belief ≤ 1e-5` 在 18 个 run 中的 14 个出现（`lora_medium_base` 是唯一接近 $10^{-3}$ 的 run 且该 cell 在 66k steps 处失败），`loss/lambda_b ≡ 1.0` 处处成立表明 belief lambda 未被实际激活，§5.10 信念质量协议不能从当前数据正面支持，须在 §5.11 失败案例中如实披露 [证据待补 EVIDENCE PENDING — belief pipeline 激活后的信念质量评估，待 §5.10/§5.11 补完]。**类型梯度对齐**——学习到的 $\partial \check{r}/\partial u_i$ 与理论值（类型 α 恒为 $\{1\}$，类型 β 在不同区段取值 $\{0, 0.7, 1.3, 2.0\}$）的距离，是断言 A 类型梯度撕裂的可视化证据；该指标的具体可视化方案——热图 vs 区段散点——在 §6.11 与附录 C 定位决策后补完 [证据待补 EVIDENCE PENDING — 类型梯度 ∂ř/∂u_i 热图，待 §6.11/附录 C 决定位置后补完]。

公平对比协议方面，本文采用 Yang 与 Hu（2021，μP）提出的 maximal update parametrization 对学习率做宽度无关的自动缩放——μP 的核心结论是当网络在不同宽度上做训练时，存在一个宽度无关的"最优学习率"如果按 μP 协议做参数化与学习率缩放，则该最优学习率不随宽度变化。本文在主对比与每条 baseline 的训练中独立执行 5×3 LR sweep（5 个 LR 候选 × 3 个 seeds），并按 μP 协议对 LoRA、FiLM、Input Conditioning 三类条件化机制做宽度对齐，确保 baseline 不会因 LR 调优不充分而显得弱——这一公平性承诺在 §5.1.4 双指标协议（HyperNet 参数量 + 上下文相关子空间维度）中进一步加固。统计检验方面，每项断言对应的核心指标差异通过 Welch's t-test（异方差不等样本量两组比较）评估，配合显式效应量阈值（如断言 A 主预测的"峰差 ≥ 5%、p < 0.05"），使结果可在不依赖审稿主观判断的情况下被验证。

需要特别说明三项与现有 mixed-motive MARL 评测惯例不同的协议安排。**其一是双指标对照协议**——HyperNet 类方法相对 baseline 的参数量优势是常见的对照混淆源，本文在 §5.1.4 中独立报告两列对照指标：HyperNet 总参数量（含 hyper_trans / hyper_rew / hyper_pred 三路径主干）与上下文相关子空间维度（衡量条件化机制在主干网络上的有效调制维度），使评测既不被"参数量打平"这一过度严格的对照所束缚，也不被"参数量任意放大"这一过度宽松的对照所污染。**其二是 baseline 的双向加固**——baseline 在每次 LR sweep 中独立选择其最优学习率，且 baseline 网络宽度按 μP 协议放大到与 HyperNet 主干网络可比的规模，避免"baseline 没调好"成为后续比较的可争议因素。**其三是 seed 数量与统计功效**——主对比 cell 与零样本 cell 均使用 3 个 seed 完成完整训练，对断言 A 钟形曲线 5 个 ρ_β 设定（0/4、1/4、2/4、3/4、4/4）每点配置 3 seed 以支持 Welch's t-test 在 5% 效应量阈值下的统计功效；具体的 power 计算与 seed 数量上界在 §5.1.5 给出。三项协议共同回应"评测中如何使方法层增益与对照公平性同时成立"这一系统性问题。

总结评测谱系：现有 mixed-motive MARL 基准中没有任何一个同时覆盖"博弈关系 intra-episode 动态切换 × 偏好层显式类型异质"这两条维度，ResourceCommons 在这一未覆盖格位上的实例化是本文实证基础，但本文不主张这是基准设计的"突破"，仅作为支撑四项可证伪断言的工程载体。评测指标家族沿用 SSD 工作的社会福利-可持续性-公平三指标，并按 RNS-MMG 特有维度补充零样本 c 泛化、隐藏-c 信念质量、类型梯度对齐三项。公平对比协议（μP 学习率缩放、跨方法相同 LR sweep、双指标对照）确保实验结果对 baseline 的不利倾向被最小化。

## §2.4 小结：本文位置

把本章三层式综述聚合到一句话即：本文在问题谱系上、方法谱系上、评测谱系上分别沿用已有工作的骨架，并仅在每条谱系上做局部增量。**问题谱系**沿用 Leibo 等人 [15] 的资源公地骨架与 Hughes 等人 [11] 的不平等厌恶偏好结构，把博弈关系作为可观测物理状态 c_t 的函数，引入 §1.2 形式化的 RNS-MMG 子设定——三条约束（C1 物理同构 / C2 类型-上下文联合调制 / C3 c_t 内禀演化）的合取，是已有混合动机 MARL 工作未联合覆盖的情形，但本文不主张该子设定是混合动机 MARL 的总体重构，仅是该谱系上一个被精确刻画的子区段。**方法谱系**沿用 Schrittwieser 等人 [24] MuZero 的世界模型 + 学到模型规划范式与 Ha 等人 [42] HyperNetworks 的权重生成思路，把双路超网络在客观/主观通路上的分解作为对 RNS-MMG 三条约束的方法层回应——分解结构与 Harsanyi [10] 不完全信息博弈中"共同知识 / 私人信念"二分形成结构类比，但本文借用 Harsanyi 框架仅作为方法选择的理论参照系，不主张这是 Harsanyi 定理在深度世界模型中的形式化对应。**评测谱系**沿用 SSD 的社会福利-可持续性-公平指标家族与 Yang 与 Hu 的 μP 学习率对齐协议，把零样本 c 泛化、隐藏-c 信念质量、类型梯度对齐三项作为 RNS-MMG 特有指标补充；ResourceCommons 在现有基准的动态切换 × 类型异质两维度未覆盖格位上的实例化，仅作为四项可证伪断言的工程载体而非独立基准贡献。

本文不主张提出新的研究方向，仅主张三件具体事项。其一，把 RNS-MMG 这一在现有混合动机 MARL 工作中尚未被系统讨论的子设定写清楚——包括三条约束的形式化、与相邻问题家族（Contextual MDP、HiP-MDP、Melting Pot substrate 切换）的边界、以及该子设定在已有方法范式下的具体局限。其二，给出一套与该子设定约束相对应的 DualHyperNetwork v2 架构与 Per-Agent MVE + CRN 规划器——前者对应 (C1)-(C2) 的客观结构同构 + 主观偏好按类型条件化，后者对应 (C3) 部分可观测下多 agent 联合动作评估的可计算性与信噪比。其三，用四项可证伪断言 A / B′ / C / D 完成对方法层贡献的实证验证，并预登记失败回退方案使方法可信度有写作层的硬绑定保障。在第 1 章已论述四项断言的内部结构与失败回退后，本章三层式综述把这些断言放置到更大的文献坐标上：断言 A 的类型梯度撕裂对应方法谱系上"共享 RewardHead 在偏好异质设定下的容量瓶颈"，断言 B′ 的条件化谱内部最优对应方法谱系上 Input → FiLM → LoRA → HyperNet 的系统性比较，断言 C 的三联通路必要性对应 Harsanyi 共同知识 / 私人结构 / 私人信念三层语义在方法层的分解，断言 D 的规划器双重技术对应 MVE 系工作 [67] 在多 agent 场景下的两项扩展（计算压缩 + 信号噪声）。

本文与 §2.1-§2.3 综述中代表性工作的关系可以再做一次总览。与 Lowe [5] / Rashid [4] / Yu [3] 等 CTDE 工作：本文方法在世界模型层而非策略层做条件化，与 CTDE 框架正交而非替代。与 Leibo [15] / Hughes [11] / Leibo [14] 等 SSD 工作：本文沿用其资源公地骨架与社会福利指标，把博弈关系从静态支付矩阵升级为 c_t 的函数；不主张 ResourceCommons 替代 Harvest/Cleanup/Melting Pot 在 SSD 评测中的位置。与 Jaques 2019 / Yang 2020 等 reward shaping / intrinsic motivation 工作：本文不在瞬时奖励层注入合作激励，而是把偏好结构作为类型变量条件化生成 RewardHead；二者机制层级不同。与 Schrittwieser [24] / Hafner [6][7] / Egorov [8] / Liu [17] 等世界模型工作：本文沿用其潜在动力学 + 规划的范式骨架，针对 RNS-MMG 的类型异质性引入双路超网络分解；MAMBA、MARIE 等多 agent 世界模型在本文方法层是直接对比的 baseline，但本文不主张取代这些工作，仅在 RNS-MMG 设定下相对它们呈现性能优势——具体的实证比较在 §5.4 主对比与 §5.7-§5.8 消融中给出。与 Ha [42] / Zintgraf [43] / Perez [44] / Hu 等条件化机制谱工作：本文沿其工作组成的连续谱做系统性比较，在 §5.5 给出谱内最优变体（FiLM + LoRA fc2）的实证支持。与 Fehr-Schmidt [40] / Charness-Rabin [45] 等社会偏好建模工作：本文沿用 Fehr-Schmidt 不平等厌恶的两参数偏好结构（$\lambda_{\text{disadv}}=2.0, \lambda_{\text{adv}}=0.6$）但放在 §3.5 偏好层而非物理层，把社会偏好的更广义形式（互惠性、社会效率）留作未来工作。与 Harsanyi [10] 不完全信息博弈框架：本文借其共同知识 / 私人信念二分作为 DualHyperNetwork 双路分解的结构类比，不主张更强的对应主张。

本章至此把本文工作在三条谱系上的相对坐标给出。第 3 章将在此基础上展开 RNS-MMG 的形式化（§3.1）、v3 NonStationaryTag 的初步研究（§3.2）、ResourceCommons 基准（§3.3–§3.7）；第 4 章将给出 DualHyperNetwork v2 与 Per-Agent MVE + CRN 规划器的完整方法实现；第 5 章按本章评测谱系所述的协议-主对比-消融-鲁棒性-失败案例次序展开实验，每个消融节对应一项可证伪断言。
