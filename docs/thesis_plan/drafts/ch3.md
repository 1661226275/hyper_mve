## §3.1 RNS-MMG 形式化（~1 500 字）

> 第 1.2 节给出 RNS-MMG 的非形式描述：博弈关系由可观测物理状态 c_t 动态调控。本节将其形式化为 N 个 agent 的元组 G = ⟨N, S, {A_i}, P, {R_i}, {O_i}, C, P_c, ρ_c, γ⟩。N 个 agent 各自从 A_i 中选择动作；S 与 {O_i} 分别是全局状态与每个 agent 的部分观测；C ⊆ ℝ 是共享上下文空间，P_c 与 ρ_c 分别是 c_t 的转移核与初始分布；γ 是折扣因子。在该元组之上施加三条结构性约束。**约束 C1（物理转移上下文不变性）**：转移函数 P(s'|s, a) 的函数式不依赖共享上下文 c_t；c_t 通过资源场动力学 q_{k,t+1} = f(q_k,t; α(c_t)) 间接调控博弈结构，本身作为状态分量参与转移但不作为函数参数。**约束 C2（博弈关系的类型-上下文联合调控）**：奖励函数 R_i(s, a; c_t, τ_i) 由 c_t 与类型 τ_i ∈ {α, β} 联合调制，且类型异质 agent 在某些 c_t 区段表现出结构性相反的奖励梯度方向（∂R^α/∂u_i 与 ∂R^β/∂u_i 在 c_t 低区段符号相反）。**约束 C3（上下文物理不可控性）**：c_t 由环境内禀动力学演化，agent 动作对其只有间接或缓慢影响。RNS-MMG 与一般非平稳 MDP 的区别在于其非平稳源自一个具体的物理变量；与静态 mixed-motive 的区别在于博弈关系本身随 c_t 变化；与领域随机化的区别在于 c_t 在 episode 内有明确的时间演化规律。

## §3.2 初步研究：v3 NonStationaryTag（~1 100 字 / 约 2 页，G2 中等版）

> 本论文方法的实证起点是作者在 v3 阶段构建的 NonStationaryTag 环境与 DualHyperNetwork 原型。该工作已在毕设中期汇报中给出初步结果，本节简要复述以承接 §4 的方法设计。**任务设定**：4 个 agent 在 2D 连续空间中追捕，其中 Agent 0/1 为固定猎人、Agent 3 为猎物、Agent 2 为可变角色；规则变量 REL ∈ {0.0, 0.5, 1.0} 控制 Agent 2 的阵营归属——REL=1 时 Agent 2 与猎人合作围剿，REL=0 时 Agent 2 反过来保卫猎物。**DualHyperNetwork v3 原型**：rule_emb（由 RELEncoder 生成）与 id_emb（agent id 嵌入）联合编码为增强上下文 C_aug，经 hyper_trans / hyper_rew / hyper_pred 三路超网分别生成 (θ_state, θ_rew^i, θ_pred^i)。**Blocking Point 奖励正交化**（v4.3 引入）：Agent 2 在护卫模式下的奖励信号通过阻截点 b_i = (1−α)·p_hunter_i + α·p_prey 计算，距离阻截点近则得分，从而使"猎人模式奖励"与"护卫模式奖励"指向不同物理位置——两者不产生符号对冲。**实证结果**（毕设汇报）：REL=1.0 下 Infer 模型捕获率 79.0%（Baseline 10.1%）；权重余弦相似度显示猎人-猎物对立角色的 cos_rew_0v3 从 0.37 持续下降至 0.28，cos_pred_0v3 从 0.65 下降至 0.50，表明 DualHyperNetwork 在零和阵营翻转任务上成功实现了不同角色的策略与奖励分化。**v3 的局限与 v4 的起点**：v3 通过 Blocking Point 处理了基本对称性问题（同一物理事件不在不同角色奖励中出现相反符号），但所有 agent 仍共享 RewardHead 训练目标的"事件类型"集合；当问题进一步推广到偏好结构异质的混合动机博弈时（如 ResourceCommons），共享 RewardHead 会被类型 α 与类型 β 的反向梯度直接撕裂。v4 三个容量瓶颈（§4.1）正是从 v3 的这一局限出发提出。

## §3.3 ResourceCommons 基准：物理层 + 偏好层二层分离（~1 700 字）

> 为研究 RNS-MMG 这一问题类，本文构建 **ResourceCommons** 基准环境。该环境的核心设计原则是物理层与偏好层的严格二层分离。**物理层自利同构**：每个 agent 在物理层只有一项可获得量——自身的物理采集量 u_{i,k} = min(η_i, q_{k,t}/|H_{k,t}|)，其中 η_i 是采集能力上限，q_{k,t} 是 patch k 在时刻 t 的资源量，|H_{k,t}| 是当时正在采集 patch k 的 agent 数量。物理层不引入任何 reward shaping、协同加成或 gifting 机制——这意味着仅从物理层看，所有 agent 都是完全自利同构的。**偏好层显式异质**：在物理采集量之上引入 agent 类型 τ_i ∈ {α, β}，类型 α 的总奖励 R^α_i = u_i 严格自利；类型 β 的总奖励 R^β_i = u_i + φ(c_t)·ψ(Δ_i) 在自利项之上加入 Fehr-Schmidt 不平等厌恶项（§3.5 展开）。**博弈涌现于交互**：合作-竞争激励通过两条正交通道涌现——(a) 资源时序动力学（高 c_t 下资源再生快，留种采集长期收益高于竭泽）；(b) 类型 β 偏好结构（φ(c) 在 c 低区段放大不平等厌恶，c 高区段反向）。两条通道无人为耦合，命题 3.1 的 Gap(c) 单调性是真实的涌现性质。**与现有 mixed-motive 基准的对比**：Harvest [15] 与 Cleanup [11] 通过 reward shaping 显式注入合作信号（Cleanup 中清污获得集体奖励）；Melting Pot [14] 提供多场景但博弈关系仍是静态的；ResourceCommons 是同时引入"博弈关系动态切换"与"偏好层类型异质"两个维度的基准。**与 v3 NonStationaryTag 的差异**：v3 用阵营标签 REL 显式声明博弈关系，v4 用类型偏好与 c_t 联合调制让博弈关系从结构中涌现；v3 是零和（猎人 vs 猎物），v4 是混合动机（公地资源博弈）。

## §3.4 资源场与上下文动力学：α(c) 单通道控制（~1 400 字）

> ResourceCommons 的物理状态由 K 个空间分布的资源 patch 与 N 个 agent 的位置构成。**资源再生动力学**采用离散时间 logistic 增长加邻域影响项：q_{k,t+1} = clip(q_{k,t} − Σ_i u_{i,k,t} + α(c_t)·f(q_{N(k),t})·(Q_max − q_{k,t}), 0, Q_max)。其中 α(c_t) 是再生强度系数（c_t 高时 α 大，资源恢复快），f(q_{N(k),t}) 是邻域影响因子（邻居 patch 富裕时该 patch 再生加快，鼓励"留种"行为）。**公平分配采集**：u_{i,k,t} = min(η_i, q_{k,t}/|H_{k,t}|) 保证多 agent 同时采集同一 patch 时按头平均分配，物理上是严格对称的。**v3 → v4 关键演化**：v3 设计中除 α(c) 外还有 β(c)·(|H|−1) 协同采集加成（β(c) 在 c 高时为正、鼓励合作采集），这是物理层的 reward shaping。v4 砍除 β(c)，让 c_t 对物理动力学的唯一作用通道仅剩 α(c)；合作激励的责任完全交给类型 β 的 φ(c)ψ(Δ) 偏好项。这一演化使 ResourceCommons 的物理层达到真正的自利同构，命题 3.1 的"两条正交通道"才能成立。**c_t 演化模式**：本环境支持三种 c_t 时间演化模式——(A) 静态（episode 内 c_t 恒定，多 episode 间从 ρ_c 采样）；(B) 周期（c_{t+1} = 0.5 + 0.5·sin(2πt/T_period)）；(C) 随机走（c_{t+1} = clip(c_t + N(0, σ²), 0, 1)）。**c_visible 开关**：本环境提供 c_visible ∈ {True, False} 配置。可见-c（默认）档下 c_t 直接写入观测 o_i^t 的全局块；隐藏-c 档下 c_t 在全局块中被常数替换，BeliefNet 必须从资源场动力学中推断 ĉ_i。后者用于 §5.10 信念质量验证（断言 B′(ii)）。

## §3.5 偏好层：类型 α / 类型 β 与 Fehr-Schmidt 结构（~1 600 字）

> 偏好层是 ResourceCommons 引入异质性的唯一通道。每个 agent 在 episode 开始时被指派类型 τ_i ∈ {α, β}，类型分配在 episode 内保持不变。**类型 α（纯自利）**：R^α_i = u_i，即奖励完全等于物理采集量。**类型 β（Fehr-Schmidt + φ 调制）**：R^β_i = u_i + φ(c_t)·ψ(Δ_i)，其中 ψ 是标准 Fehr-Schmidt 非对称分段函数 ψ(Δ) = −[λ_disadv·max(0, −Δ) + λ_adv·max(0, Δ)]，λ_disadv = 2.0 与 λ_adv = 0.6 沿用 Fehr & Schmidt [40] 经典实验估计值；Δ_i 是 instantaneous 不平等差 Δ_i^(t) = u_i^(t) − (1/(N−1))·Σ_{j≠i} u_j^(t)（与 Hughes 等人 [11] 的 per-step 形式对应）。**φ(c_t) 调制函数**：φ(c) = κ·(1 − 2c)，κ = 0.5。该形式使 c=0 时 φ=κ>0（放大 Fehr-Schmidt：β 极度厌恶被甩开）、c=1 时 φ=−κ<0（反向 Fehr-Schmidt：β 反而厌恶超过他人，鼓励向中间靠拢）、c=0.5 时 φ=0（β 与 α 行为相近）。**心理偏好不变 / 行为模式涌现**：类型 β 的心理偏好结构（Fehr-Schmidt + 固定 λ）在所有 c_t 区段保持不变，变化的只有偏好的强度与方向（由 φ(c) 调制）。行为现象——荒年 (c 低) 表现为"激进追赶/剥削"、丰年 (c 高) 表现为"协同采集/合作"——是 RL 在固定偏好结构下找到的最优策略响应，而非对行为模式的显式编码。这一设计与 v1 阶段的"直接对合作/竞争做 reward shaping"路线根本不同。**观测设定**：ResourceCommons 提供两档可观测性。**Self Info（默认）**：agent 自己的类型对自己可见（编码到 role_i 通路）、他人的类型对自己不可见（由 BeliefNet 在线推断 ẑ_{i,j}）；这与 Harsanyi [10] 的"own type + belief over others"结构对应。**Full Info（Oracle 上界对照）**：所有 agent 的类型都可见，作为方法性能上界。本文 §5.6 在两档下分别评测以分离 belief 通路的贡献。

## §3.6 命题 3.1：合作-竞争切换的涌现性（~1 200 字，P3：正文陈述 + 附录证明）

> 本节给出 ResourceCommons 唯一形式化命题。**命题 3.1（Gap(c) 单调性）**：在二人单资源简化博弈下（N=2, K=1, 离散时间, 类型分配 1α1β），设 V^Pareto(c) 为社会福利最大化策略对的累积奖励、V^Nash(c) 为非合作 Nash 均衡策略对的累积奖励，则 Gap(c) := V^Pareto(c) − V^Nash(c) 关于 c 单调递减。该命题在 c 低区段（荒年）给出"合作优势大"的结论，在 c 高区段（丰年）给出"合作优势趋零"的结论。**证明思路**（详见附录 A）：分两步——(i) 资源时序动力学项：c 高时 α(c) 大，资源再生快，留种行为的长期收益与竭泽行为的差距缩小；(ii) Fehr-Schmidt 项：c 高时 φ(c) < 0，类型 β 反而厌恶超过对方，与类型 α 的自利行为趋于一致，Nash 均衡向 Pareto 解靠拢。两项叠加后 Gap(c) 单调递减。**涌现性的关键**：Gap(c) 单调性不是定义内蕴的恒等关系，而是两条正交通道（资源动力学 × 偏好结构）交互的结果。如果环境像 v3 那样在物理层引入 β(c) 协同加成，Gap(c) 单调性就会变成定义后的直接推论而非涌现性质——这是 §3.4 v4 砍除 β(c) 的设计依据。**多步博弈下的处理**：完整多步博弈下命题 3.1 的闭式难以求出，本文将其留作 §5.4 ResourceCommons 主对比与 §5.7 类型扫描的实验观察项。**与断言 A 钟形曲线的联系**：命题 3.1 预测合作优势在 c 低区段最大，钟形曲线峰值位置因此预期落在"两类 agent 共存且 c 平均偏低"的区段附近，但精确位置依赖学习动态，不由命题直接给出。

## §3.7 评测指标（~1 100 字）

> ResourceCommons 评测指标分四大类。**(1) 社会福利与个体公平**：V_total = Σ_i R_i 衡量整体效用；个体福利的 Gini 系数与累积分布函数（CDF）评估分配公平性。**(2) 可持续性**：episode 末资源总存量 Σ_k q_{k,T}（与 Hardin [9] 公地悲剧叙事直接对照）与采集量的时序方差（衡量"竭泽"程度）。**(3) RNS-MMG 特有指标**：(i) 零样本泛化——训练 c ∈ {0.2, 0.5, 0.8}，测试 c ∈ {0.0, 0.35, 0.65, 1.0} 上的福利保留率（断言 B′(i) 的硬指标）；(ii) 隐藏-c 信念质量——BeliefNet 推断的 ĉ_i 与真实 c_t 的 MSE 与 Pearson 相关系数（断言 B′(ii) 的硬指标）；(iii) 对手类型推断准确率——ẑ_{i,j} 与真实 τ_j 的 2-way 分类准确率（§5.6 课程有效性的中间指标）。**(4) 类型梯度对齐**：从训练完的模型中数值估计学习到的 ∂ř/∂u_i，与理论值（类型 α 恒为 1、类型 β 在 (c, Δ) 区段表中取 {0, 0.7, 1.3, 2.0}）的 L2 距离。该指标用于 §5.7 6.11 可视化：Hyper-MuZero 期望每条 type 通路贴近对应理论值；MA-MuZero 期望落入两类型之间的"折中区"。**指标分级**：主对比（§5.4）报告社会福利 + 可持续性 + Gini 三主指标；零样本与信念质量作为 §5.5 / §5.10 的章节专属指标；类型梯度对齐作为 §5.7 的可视化补强指标。所有指标的统计协议：5 seeds × 蛇形曲线均值与标准差报告；Welch's t-test 用于关键对比的显著性检验。
