## §5.1 实验协议：基线、公平性与算力规划（~1 500 字）

> 本节系统确立第五章所有对比实验共用的协议框架，包括基线选取逻辑、公平性保证措施、环境配置分级，以及端到端的算力规划方案。实验设计需要在"比较的充分性"与"条件的可控性"之间取得平衡：基线过少则无法定位 Hyper-MuZero 的相对优势，基线过多而缺乏公平性约束则会使结论失去可信度。
>
> 在**基线选取**方面，本章引入六类对比方法，覆盖多智能体规划与多智能体强化学习两条主线。规划侧选取 MA-MuZero [30] 与 MAMBA（Egorov & Shpilman 2022），二者分别代表多智能体 Gumbel 采样与 Transformer-based 多 agent 世界模型路线；学习侧选取 MARIE（Liu et al. 2024）与 Conflict-Aware Gradient Adjustment（CAGA, Kim et al. 2025 [13]），前者通过 type token 处理异质 agent，后者引入显式梯度冲突调整机制；此外纳入广泛使用的 MAPPO（Yu et al. 2022）与 QMIX（Rashid et al. 2018）作为 actor-critic 与值分解基准，用于衡量规划增强相对于纯学习方法的实际收益。
>
> **公平性保证**遵循两条底线。第一，类型可观测性匹配原则（Self Info 原则）要求所有基线与 Hyper-MuZero 在输入信息量上保持对等：各方法均仅可访问同等粒度的自身类型信息，不引入额外的对手类型先验。第二，所有方法均在相同条件下独立执行 μP 学习率扫描（Yang & Hu 2021），采用 5 个学习率档位各运行 3 个随机种子的搜索协议，以消除因超参数配置差异导致的性能偏差。
>
> **环境配置**按难度分为三级。Easy 级（N=2）仅激活决策门链的第 1 与第 4 门，主要用于验证基本收敛性与断言 D 的完整 2×2 矩阵；Medium 级（N=4，2α+2β）为主对比配置，是五章核心结论的来源；Hard 级（N=8）用于鲁棒性验证，检验方法在规模扩大后的性能保持能力。六类评测指标对应六个维度：社会福利、可持续性（回合末资源存量）、Gini 系数、零样本跨 c_t 迁移、类型梯度对齐，以及信念质量。
>
> **算力规划**方面，主对比实验（Medium 配置，六类基线 × 5 seeds）预计消耗约 180 GPU 小时，μP 学习率扫描约 90 GPU 小时，Easy 配置验证约 30 GPU 小时，合计约 300 GPU 小时。下一节将正式给出条件化谱预筛（决策门 0）的实验结果，为 §5.4 主对比锁定 thesis-default gen_scope cell。

## §5.2 决策门 0：条件化谱预筛（~1 800 字，独立前置实验）

> 本节在正式引入双超网络变体之前，首先建立一项面向条件化生成范围的预筛实验，以确定后续所有实验所采用的默认生成域（gen_scope cell）。所谓"条件化谱"，是指将超网络对功能网络的参数生成范围从最窄（仅共享偏置，Shared）到最宽（全参数重生成，FULL）连续排布后，形成一条可量化对比的设计轴线；不同位置的 cell 在表达能力与训练稳定性之间的权衡存在本质差异，因此在投入大规模 sweep 之前需要经由受控实验加以校准。
>
> 实验在 duo 环境上展开（N=2, c_t 服从随机游走），使 agent 无法通过记忆固定 c_t 来规避条件化挑战。待评价的 6 个 cell 依生成宽度递增排列为：Shared、Input-Wide、film_head、lora_fc2、base_gen、FULL，每个 cell 在 3 个独立随机种子下各运行约 11k 步，合计耗时约 30 GPU 小时。为确保实验结论的可信性，**判据在运行前预登记**：agent 须在收敛后维持持续熵值 H(π) > ln A，跨 agent 余弦相似度须满足 cos_pred_cross < 0.95，且训练全程不得出现单调方向坍缩。基于条件化表达能力与参数效率的理论分析，预登记预测认为峰值性能应落于 film_head 叠加 LoRA 至 lora_fc2 区间之内。
>
> 此外，本节还单独对 FULL cell 进行可复现性验证，以核实断言 B′ 所描述的方向坍缩现象：在 FULL 条件下，**cos_pred_cross 由初始的 0.61 单调攀升至 0.998**，表明两名 agent 的策略预测方向趋于完全对齐，条件化表征实质上退化为与 c 无关的公共嵌入，从而印证了过宽生成域对表征独立性的破坏作用。上述 sweep 结果将最终锁定一个 thesis-default cell，作为 §5.4 起所有 DualHyperNet 变体的统一基础配置，确保后续各消融实验在相同生成域前提下具备横向可比性。

## §5.3 v3 NonStationaryTag 迁移验证（Genesis 验证，~1 200 字）

> 本节将 v4 完整方法迁移回 v3 NonStationaryTag 任务，对二者进行等价条件下的基准比对，以验证版本升级的纵向一致性。v3 NonStationaryTag 是本课题最初构建的阵营重对齐场景：4 个 agent 在连续二维场地中按派系分组，环境规则 REL ∈ {0.0, 0.5, 1.0} 控制 Agent 2 的阵营归属，形成猎人（Hunter）与猎物（Prey）角色的非平稳切换。v3 阶段的方法以直接拼接 agent 身份编码为上下文输入，未引入三联上下文与 BeliefNet 机制，其训练指标已在毕业设计中期汇报阶段完成记录，构成本节比对的参照基线。
>
> v4 方法的核心设计是三联上下文（c_ctx、role_i、belief_i）通过 DualHyperNetwork v2 动态生成功能网络权重，同时引入 Coord+CRN 协调机制以抑制 MVE 规划器在候选动作评估时的方差。将 v4 方法部署至 v3 任务时，REL 直接对应 c_t（仅 3 个离散值），三联上下文中 c_ctx 通路保留，但 belief_i 通路对应"对手类型推断"在 v3 零和阵营场景中退化为"REL 推断"。
>
> 本节的核心对比指标为 Capture Rate（捕获率）、cos_rew_0v3（猎人-猎物奖励头余弦相似度）与 cos_pred_0v3（策略头余弦相似度）。设计预期为：v4 在 v3 任务上的 Capture Rate 不低于 75%，即不劣于 v3 原版方法的表现水平（毕设汇报中 REL=1.0 下 Infer 模型 79%），从而证明 v4 是对模型结构的实质性升级，而非通过替换任务形态换取表观指标改善。反之，若最优配置下 Capture Rate 仍低于 70%，则表明三联上下文设计在零和任务上引入了冗余的归因复杂度，需回溯至 §4.3 对上下文融合方式进行针对性调整。以下各小节依次呈现迁移配置、实验结果与误差分析，并在节末给出对 v4 结构泛化边界的综合判断。

## §5.4 ResourceCommons 主对比（Medium, N=4, 2α+2β，~2 200 字）

> 本节在 Medium 配置（N=4，2α+2β）下对 Hyper-MuZero 与六类基线方法展开系统性主对比实验，旨在为本文贡献 2 提供核心实证支撑。所选配置兼顾场景规模与角色异质性：4 个 agent 中同时包含 2 名类型 α（纯自利）与 2 名类型 β（Fehr-Schmidt 调制），二者在目标函数上既存在公共物品博弈的合作压力，又因分配份额产生竞争性张力，能够较为充分地暴露各方法在混合动机场景下的行为差异。
>
> 六类基线涵盖从值分解到规划增强的主流 MARL 范式：QMIX（Rashid et al. 2018）以联合值分解为代表；MAPPO（Yu et al. 2022）作为 actor-critic 基线；CAGA（Kim et al. 2025 [13]）引入冲突感知梯度调整；MAMBA（Egorov & Shpilman 2022）以 Transformer-based 多 agent 世界模型为核心；MARIE（Liu et al. 2024）融合 type token 与角色感知；MA-MuZero [30] 则将基于模型的树搜索规划拓展至多智能体设定。每类方法运行 5 个独立随机种子，在相同 Medium 主配置下统一训练，保证比较的公平性。
>
> 评测维度围绕四个互补指标展开。**社会福利**（所有 agent 累计奖励之和）衡量群体协作效率；**可持续性**以回合末资源存量量化公共池资源的长期维护能力；**Gini 系数**刻画个体间分配公平性；**零样本泛化**测试则在训练集 c ∈ {0.2, 0.5, 0.8} 之外的 c ∈ {0.0, 0.35, 0.65, 1.0} 下评估策略鲁棒性。综合这四个维度，可以区分"短期博弈收益高但耗竭资源"与"长期可持续均衡"两种截然不同的策略模式。基于第 4 章的机制分析与第 5.2 节预实验观测，预期 Hyper-MuZero 在社会福利指标上相对最强基线 MA-MuZero 取得 15%–30% 的提升，整体性能序列呈现 Hyper > MA-MuZero ≈ MARIE > MAMBA > CAGA > MAPPO > QMIX 的梯度分布。若实际提升幅度低于 10%，则相应将贡献 2 的表述收窄为"特定 c_t 区段优势"，以保持论断的诚实性。以下各小节依次呈现学习曲线、汇总指标与失败回退分析的完整结果。

## §5.5 消融 1 + 零样本泛化 → 断言 B′（~2 300 字）

> 本节旨在对断言 B′（条件化谱内部最优）给出硬验证：通过七种结构变体的系统消融与零样本上下文泛化测试，在三分级判据 B′(i)/(ii)/(iii) 下确定 DualHyperNetwork 的功能网络条件化机制是否在可行变体集内部达到最优配置。断言 B′ 的核心主张在于：既非共享参数基线（Shared）、亦非全权重注入（Input-Wide / Input-Deep），而是以超网络生成功能网权重的中间方案（film_head / lora_fc2 / base_gen），能够在条件化容量与参数效率之间取得最优平衡——这一主张需要对比实验而非理论论证来支撑。
>
> 消融设计以**参数对齐为前提约束**：七个变体在功能网总参数量上严格持平，以排除容量差异对性能的混淆；超网络参数规模与上下文子空间维度则单独列出，作为理解每种条件化路径的结构依据。七个变体覆盖三类条件化策略——参数共享（Shared）、宽窄两档直接拼接（Input-Wide / Input-Deep）、轻量适配器（FiLM 调制头 film_head、低秩适配 lora_fc2）、以及基础生成器 base_gen 与完整超网络 full——形成从"无条件化"到"全权重生成"的完整谱系，使三分级判据得以逐点落地。经 [v4-opt 2026-06] 加固后，B′ 的双指标报告协议（功能网总参数对齐 + 超网络参数与上下文子空间维度单列）确保了变体间比较的公平性，并与第四章关于 EMA 衰减系数 τ=0.99、Adam ε=1e-5、折扣因子 γ=0.95 等超参数锁定保持一致。
>
> **零样本泛化测试**在训练集 c ∈ {0.2, 0.5, 0.8} 与测试集 c ∈ {0.0, 0.35, 0.65, 1.0} 的分布错位设定下评估各变体的外推能力，为 B′(iii) 内部峰值的泛化稳定性提供额外佐证。若三分级判据中任一子项 B′(i)（左端局部条件化优于 Input 类基线）、B′(ii)（右端全权重注入发生性能塌缩）、B′(iii)（内部峰值在变体谱中唯一存在）出现失败，本节遵循**预登记降级方案**，在不调整结论方向的前提下修正主张强度。以下依次呈现消融结果与零样本测试数据，并在 §5.6 中进一步分析峰值区间的边界成因。

## §5.6 消融 2：Context 路径拆分 → 断言 C（~1 600 字）

> 本节建立断言 C 的实证依据，即超网络输入中的三条 context 通路——环境上下文嵌入 c_ctx、角色身份编码（type_emb 与 cap_emb）以及 agent 自身标识 id_emb 和信念向量 belief_i——对最终性能的贡献不可相互替代，缺少任意一条均会带来显著且独立的性能退化。消融 1 已从超网络整体有无的角度验证了动态权重生成机制的必要性；而在超网络内部，各路 context 信号的分工是否清晰、退化是否近似正交，则是 §5.6 希望回答的更细粒度问题。
>
> 为此，本节设计了**五组零置条件**：分别将 c_ctx、type_emb、cap_emb、id_emb 及 belief_i 在超网络输入端逐一置零，其余结构与训练超参数（EMA τ=0.99、Adam ε=1e-5、γ=0.95）保持与主配置完全一致。单路退化数据收集完毕后，进一步构造若干多路联合零置条件，检验累积退化量是否近似等于各单路退化之和；若近似可加性成立，则支持各通路在功能上互不冗余的理论推断。
>
> 考虑到 belief_i 的作用在可见-c（c_visible=True）与隐藏-c（c_visible=False）两种设定下可能存在本质差异——前者 agent 无需依赖信念推断即可感知当前 c_t，后者则需要通过历史轨迹积累推断——本节在 hidden-c 档下重复执行消融 2 的全部条件，以分离 belief_i 在 c_t 不可观测时的独立贡献，避免将该通路的必要性误估为仅在困难设定下才体现。此外，若实验发现 No-type 与 No-belief 条件下的退化曲线高度相近，则补充 No-self-type 对照组，进一步区分 agent 自身类型与对手类型对策略生成的差异影响。下文依次报告各条件的量化结果，并在节末对断言 C 的成立程度给出综合判断。

## §5.7 消融 3 + 类型梯度可视化 → 断言 A（~2 000 字）

> 本节通过类型比例扫描实验与梯度可视化两类证据，共同验证断言 A：在类型异质配置下，Hyper-MuZero 的奖励梯度 ∂ř/∂u_i 呈现具有诊断价值的钟形分布，而非单调递增或随机散布。
>
> **消融实验**在 β 类型 agent 比例 ρ_β ∈ {0/4, 1/4, 2/4, 3/4, 4/4} 五个锚点上逐一扫描，同时纳入"1α+3β"作为非对称对照点，共构成六组配置。这一设计的出发点在于：若奖励超网络确实编码了类型差异，则随着 ρ_β 从 0 单调递增至 1，模型对混合配置的适应收益应先升后降，峰值出现在类型分布最具张力的对称区域（ρ_β = 2/4）或略偏向少数方的非对称区域（ρ_β = 1/4）。两者均属理论上合理的 informative result，并非偏离预期的失效信号——非对称峰值意味着主动学习少数类型视角对总体适应收益的边际贡献更大，这本身即具研究意义，故在结果报告中予以如实呈现而不作事后修正。
>
> 配合比例扫描，§6.11 节所得的 **∂ř/∂u_i 梯度热图**提供了更细粒度的结构性证据。具体而言，Hyper-MuZero 的 α/β 奖励通路在各扫描点上梯度分布均贴近理论解析值（α 恒为 1、β 在 (c, Δ) 区段表中取 {0, 0.7, 1.3, 2.0}），而 MA-MuZero 基线在相同配置下梯度集中于"折中区"——即对全体 agent 一视同仁的均值附近——无法区分类型身份对奖励结构的差异性贡献。这一对比从参数梯度层面补充了行为层面的性能差距，构成断言 A 的双重佐证。
>
> 本节同时设置**决策门 1**：若在最易分辨的 Easy N=2 二类型设置上，ρ_β = 2/4 与 ρ_β = 0/4 之间的峰值差距低于 5%，则钟形曲线可能因任务难度不足而被压平，届时将触发 §6.2 贡献 2 的条件性重定位，对超网络在简单场景下的必要性重新定性。以下各小节依次呈现扫描结果、峰位分析与梯度可视化对比。

## §5.8 消融 4：规划器双重技术 → 断言 D（~1 800 字）

> 本节通过受控消融实验建立断言 D——坐标下降规划（Coordinate Descent，CoordDesc）与公共随机数技术（Common Random Numbers，CRN）在 MVE 规划器中构成不可分割的组合，缺失任一组件均将导致规划质量显著退化。MVE 规划器在推断阶段面临的核心困难在于：多智能体联合动作空间随 agent 数量指数膨胀，而各候选动作方案的奖励估计在蒙特卡洛采样下存在不可忽视的方差，两者共同压缩了动作评估的信噪比（SNR）。若二者皆未控制，规划器输出退化为接近均匀分布的策略，其行为价值与随机动作无实质差异。
>
> 消融设计分两个规模展开。**在 Easy N=2 场景**，实验构建完整的 2×2 矩阵：规划策略取坐标下降（CoordDesc）与联合穷举（Joint）两轴，CRN 取开启与关闭两轴，并附加顺序随机化对照组，以排除坐标更新次序引入的偏差。配套 SNR 实测结果显示，基线（CRN 关闭）下候选动作奖励估计的 SNR 仅约 0.02，开启 CRN 后上升至约 1.0，量化了方差控制的实际效果。从期望性能序来看，Joint 搜索在 CRN 关闭时表现最差（Joint+IndepRand），仅启用坐标下降而不配合 CRN 可获得局部提升（CoordDesc-only），而二者联用（CoordDesc+CRN）方能达到本组最优，验证了组合必要性的充分性方向。
>
> **在 Medium N=4 场景**，联合穷举策略面临 5^4 = 1296 量级的动作组合数，计算上不具可行性，因此仅保留坐标下降框架下的 CRN 开/关二轴对比，构成必要性方向的独立验证。两个规模的实验相互补充，形成"Easy 充分性 + Medium 必要性"的混合论证结构，共同支撑断言 D 的成立。下一节将汇总所有四个断言的消融结果，并讨论各组件间的交互效应对整体系统性能的累积贡献。

## §5.9 消融 5 + Scale-up + 鲁棒性（~1 500 字）

> 本节围绕三类正交扰动构建鲁棒性验证体系，以检验第 4 章提出的 Hyper-MuZero 框架在超出训练分布的参数设定与规模配置下能否维持稳定性能。前几节的消融实验主要在标准配置（N=4、Fehr-Schmidt 参数 κ=0.5、λ_disadv=2.0）下进行，所得结论是否对偏好参数的连续变动保持鲁棒、对更大规模场景保持可迁移，尚未得到实证支持。为填补这一验证空缺，本节从三个维度依次展开。
>
> 第一，**Fehr-Schmidt 社会偏好参数敏感度扫描**：在 κ ∈ {0.3, 0.5, 0.7} 与 λ_disadv ∈ {1.0, 2.0, 3.0} 构成的 3×3 参数网格上重复运行实验，考察超网络生成的策略权重对偏好强度偏移的容忍区间。第二，**Scale-up Hard 配置**（N=8 agent、24×24 地图、40 个资源点、5 个热点区域、振荡式 c_t）作为规模外推压力测试，评估协调机制在联合动作空间急剧扩张时的退化速率。第三，通过**关闭 MVE Planner** 并将其替换为纯策略网络输出（planner-off），实证演示规划器对蒸馏信号的必要性，与 §4.5 INSIGHT 中的自蒸馏退化引理形成呼应闭环——当 planner-off 时，策略熵回升至 ln(A) 不动点、协调效率显著下降，证实规划-蒸馏通路并非冗余设计而是性能的关键支撑路径。上述三组实验共同构成本方法的鲁棒性证据链，为第 6 章总结中关于框架适用边界的讨论提供直接的实验依据。

## §5.10 信念推断质量 + 三阶段课程有效性（~1 500 字）

> 本节围绕两个相互关联的子问题展开评估：其一，BeliefNet 所学到的对手类型表示 ẑ_{i,j} 是否在统计层面上忠实地反映了真实类型 τ_{-i}；其二，三阶段课程训练能否在可见-c（c_visible=True）与隐藏-c（c_visible=False）两种信息可及性条件下，分别保证信念质量与主任务福利的协同收敛。回答这两个问题，是对第四章所提出方法在实验意义上的完整闭环。
>
> 评估协议采取**双档设计**。可见-c 档作为上界参照：agent 在每一时刻均可直接获取 c_t 编码，BeliefNet 的 ĉ 头退化为恒等映射，此时任何课程阶段的 ẑ 准确率下界均应趋近于理论上限；隐藏-c 档则关闭 c_t 输入通路（c_visible=False），要求 BeliefNet 仅凭观测历史 o_{1:t} 推断 ĉ_i，以 MSE 和 Pearson 相关系数为指标评估信念通路的实际信息传递能力。两档对照将解耦"课程设计本身"与"c_t 可见性"对最终性能的各自贡献。
>
> 在**课程阶段划分**上，Stage 1 以推断精度为主导目标，期望 ẑ 分类准确率达到 80% 以上，再进入 Stage 2；Stage 2 在保持 ẑ 准确率稳步提升至 90% 的同时，监控主任务社会福利是否随之稳定；Stage 3 要求 ẑ 准确率维持在 85% 以上、主任务福利不发生显著退化，以此验证联合优化的稳健性。与之对照的 no-curriculum baseline 在相同超参数（Adam ε=1e-5，γ=0.95，EMA τ=0.99）下跳过阶段门控、直接端到端训练，用于量化课程调度对收敛速度与最终性能的净增益。
>
> 本节余下部分依次呈现：§5.10.1 给出各阶段 ẑ 准确率的训练曲线与阶段转换时间步；§5.10.2 对比隐藏-c 档下 ĉ 的 MSE 与 Pearson 系数，论证信念通路的有效性；§5.10.3 以 no-curriculum baseline 为锚点分析课程有效性；结论汇入第六章对系统整体局限性与后续工作的讨论。

## §5.11 失败案例与训练诊断（~1 600 字）

> 任何系统方法的有效性，最终都需在其失败边界处得到充分审视。本节围绕本研究训练过程中系统性记录的典型失败模式展开诊断分析，并对当前实现的未完工程项作出透明说明，旨在为后续复现与改进提供可操作的参照。
>
> 在所有已观察到的失败信号中，**表示方向坍缩**（representation directional collapse）是出现最早、影响范围最广的一类。以 FULL gen_scope 的一次典型训练运行为例，跨 agent 预测余弦相似度 cos_pred_cross 在约 500k 步内从初始值 **0.61 单调攀升至 0.998**，意味着不同 agent 的预测网络在表示空间中几乎完全退化为同一方向，使得超网络为各 agent 生成个性化权重的意义丧失殆尽。这一演化曲线并非孤例，而是在表示网络梯度范数持续低于阈值、AdaLN 的 γ 参数向零收敛时可重复出现的系统性现象。
>
> 围绕此类坍缩以及同期观察到的其他四类失败模式——即**奖励信号爆炸**、**ẑ 准确率周期性震荡**、**策略熵钉死于 ln|A| 附近**、以及 **agent 角色功能性坍缩为同质行为**——本节逐一给出触发条件与对应的处理协议，包括分组 RMS 梯度裁剪（group RMS clipping）、奖励课程退火、表示一致性损失（consistency loss）的引入时机，以及规划器强制探索的介入条件。各项协议并非事后补丁，而是在 v4-opt 2026-06 阶段依据具体观测数据确定并锁定的配置，与 τ=0.99（EMA 目标网络）、ε=1e-5（Adam）、γ=0.95（折扣因子）等超参数设定共同构成当前训练稳定性的基础。
>
> 在**工程完整性**方面，本节亦明确列出两项已承诺但尚未完工的实现：其一为 Pkg-02 中 EnvConfig.c_visible 开关的补齐方案，其二为 Pkg-05 MVE planner 中 planner_mode=joint_enum 的 Easy N=2 模式枚举实现。同时给出实际算力消耗的账本记录：包含失败重跑在内，本研究总计消耗约 300 GPU 小时，相关运行日志已存档备查。以上内容共同构成本章方法与实验评估之外的诚实补充。
