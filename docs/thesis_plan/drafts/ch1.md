## §1.1 研究背景：从纯合作/零和到混合动机的真实世界（~1 100 字）

> 多智能体强化学习（Multi-Agent Reinforcement Learning，MARL）研究通常基于两类极端假设之一：完全合作（所有 agent 共享同一奖励函数）或严格零和（一方收益等于另一方损失）。然而，现实中的多智能体系统大多并不落在这两个极端之上：自然资源采集中的渔民群体、电网调度中的发电节点、共享带宽中的网络节点，其个体目标既不完全一致也不严格对立，而是在合作与竞争之间存在持续的张力。这一类问题在博弈论中被归为**混合动机博弈（mixed-motive games）**。
>
> 在 MARL 研究中，针对混合动机博弈已有较为活跃的工作积累。Leibo 等人 [15] 将经典囚徒博弈推广为序贯社会困境（Sequential Social Dilemma），并构造 Harvest、Cleanup 等环境作为研究载体；Hughes 等人 [11] 在该框架上引入 Fehr-Schmidt 不平等厌恶作为内在奖励项以促进合作；Leibo 等人 [14] 进一步构建 Melting Pot 多场景套件用于评估泛化能力。这些工作的共同前提是：**博弈关系本身（合作-竞争的相对强度）在整个学习过程中保持静态**——一旦环境被设定为"合作主导"或"竞争主导"，相应的支付结构在所有 episode 中不再发生结构性改变。
>
> 这一前提与许多真实场景并不相符。在渔场中，资源丰度的高低直接决定渔民之间是合作维护渔场可持续性，还是竞争性过度捕捞；在电网调度中，可再生能源出力的波动会改变发电节点之间合作与竞争的相对比重。换言之，**博弈关系本身是可观测物理状态（尤其是资源丰度）的函数**，并随时间动态变化。本论文聚焦于这一在现有 mixed-motive MARL 工作中尚未被系统讨论的情形，将其形式化为关系非平稳混合动机博弈（Relation Non-Stationary Mixed-Motive Game，RNS-MMG）。

**本节 beats**：

1. 多智能体研究两极假设的局限：纯合作过简化、零和不映射真实
2. 真实多智能体系统大多在"合作-竞争张力"区段
3. 渔场、带宽、电网作为公地博弈的工业对应（→ Hardin/Ostrom 文献支撑）
4. mixed-motive MARL 社区已活跃但被**静态博弈结构假设**束缚（伏笔到 §1.2）

**核心引用**：[9] Hardin 1968 Science · [16] Ostrom 1990 · [15] Leibo 2017 AAMAS · [11] Hughes 2018 NeurIPS · [14] Leibo 2021 ICML

## §1.2 问题陈述：关系非平稳混合动机博弈 (RNS-MMG)（~1 400 字）

> 第 1.1 节指出，现有 mixed-motive MARL 工作的共同前提是博弈关系在整个学习过程中保持静态。本节将"博弈关系随可观测物理状态动态切换"这一情形形式化，记作**关系非平稳混合动机博弈**（Relation Non-Stationary Mixed-Motive Game, RNS-MMG）。
>
> 在 N 个 agent 的标准马尔可夫博弈 G = ⟨N, S, {A_i}, P, {R_i}, {O_i}, γ⟩ 之上，引入共享上下文变量 c_t ∈ C 及其分布 P_c，并对博弈结构施加三条约束。**(C1) 物理转移上下文不变性**：物理转移函数 P(s'|s,a) 的函数式不依赖共享上下文 c_t；c_t 作为部分可观测的状态分量，通过资源场动力学间接调控博弈结构。**(C2) 博弈关系的类型-上下文联合调控**：奖励函数 R_i(s,a;c_t,τ_i) 由 c_t 与 agent 类型 τ_i 联合调制，类型异质 agent 在不同 c_t 区段表现出结构性相反的奖励梯度方向。**(C3) 上下文的物理不可控性**：c_t 由环境内禀机制演化，agent 动作对其只有间接或缓慢影响。
>
> RNS-MMG 与几类相邻问题有清晰的边界。与一般非平稳 MDP / Markov Game 相比，RNS-MMG 显式假设非平稳源自一个可被观测或推断的物理变量 c_t，而非时间显式索引；与静态 mixed-motive（Cleanup, Harvest）相比，RNS-MMG 允许博弈关系随 c_t 动态切换；与领域随机化相比，RNS-MMG 中的 c_t 在单条 episode 内有明确的演化规律，而非每个 episode 重新独立采样。

**本节 beats**：

1. RNS-MMG 形式定义：博弈关系由可观测物理状态 c_t 动态调控
2. C1 物理同构 / C2 类型-上下文联合调制 / C3 部分可观测且不可控
3. 与静态 mixed-motive、零和非平稳、领域随机化的边界区分
4. 共享上下文 c_t 三性质：物理实在性、关系调制性、部分可观测且不可控

**核心引用**：[10] Harsanyi 1967 · [13] Kim 2025 NeurIPS · Bowling & Veloso 2002 AIJ（非平稳 MARL 经典）

## §1.3 现有方法四个范式的系统性局限（~1 600 字）

> 围绕 RNS-MMG 这一问题设定，本节从四个方法范式分别考察现有工作的局限性。
>
> **Model-free 合作型 MARL**（MAPPO [Yu 2022]、QMIX [Rashid 2018]、MADDPG [Lowe 2017]）通过集中训练-分散执行框架获得了广泛应用，但其网络权重隐式拟合特定环境转移与奖励结构，当博弈关系随 c_t 切换时缺乏自适应机制，需要重新收集大量数据。**单智能体世界模型**（MuZero [Schrittwieser 2020]、DreamerV3 [Hafner 2023]）在 Atari 等单 agent 任务上取得 SOTA 表现，但扩展到多 agent 时通常仍假设环境平稳；近期的 **多智能体世界模型**（MA-MuZero [30]、MAMBA [Egorov 2022]、MARIE [Liu 2024]）显式处理多 agent 联合动作，但其 RewardHead 在所有 agent 间共享，在偏好结构异质的 RNS-MMG 下会被类型 α 与类型 β 的反向梯度撕裂，进入类型平均策略。**社会困境专用方法**（Social Influence [Jaques 2019]、LIO [Yang 2020]、Conflict-Aware GA [Kim 2025]）面向静态社会困境设计内在奖励项或梯度调整机制，本质仍是 reward shaping，不直接处理"博弈关系作为 c_t 的函数"这一非平稳特征。
>
> 四类方法各自处理 mixed-motive MARL 的某一个侧面，但均未同时回应 RNS-MMG 的三条约束：(C1) 客观状态预测在所有 agent 间共享、(C2) 主观奖励/价值按类型条件化生成、(C3) c_t 的部分可观测性需要在线推断。本文方法的设计直接对应这三条约束。

**本节 beats**：

1. Model-free 合作型 MARL：忽略非平稳博弈关系
2. 单智能体世界模型扩展到多 agent：未处理类型异质
3. 多智能体世界模型：共享 RewardHead → 类型梯度撕裂
4. 社会困境专用方法：依赖 reward shaping 或静态博弈

**核心引用**：[24] MuZero (Schrittwieser 2020 Nature) · [30] MA-MuZero · MAMBA (Egorov 2022 AAMAS) · MARIE (Liu 2024 ICML) · Yu 2022 NeurIPS MAPPO · Rashid 2018 ICML QMIX · Hafner 2020/2023 Dreamer · Jaques 2019 ICML · Yang 2020 NeurIPS LIO · [13] CAGA

## §1.4 研究目标与四项贡献（~1 600 字，承诺级表述）

```
围绕第 1.2 节的 RNS-MMG 问题，本文做出以下四项贡献：

(1) 问题层面
   针对博弈关系由可观测资源丰度 c_t 动态调控、且 agent 群体偏好结构存在差异的多智能
   体场景，本文给出 RNS-MMG 形式化（C1 物理同构 / C2 类型-上下文联合调制 / C3 部
   分可观测且不可控），并在该形式化之上实现 ResourceCommons 开源基准（含 c_visible
   开关支持可见-c 与隐藏-c 两档实验）。

(2) 算法层面
   面向 RNS-MMG 下"类型异质 agent 在共享 RewardHead 上产生反向梯度"的架构难
   点，本文提出 DualHyperNetwork v2：客观通路（hyper_trans）仅消费共享上下文，生
   成所有 agent 共用的状态转移权重；主观通路（hyper_rew / hyper_pred）消费三联上下
   文 [c_ctx, role_i, belief_i] 生成 per-agent 权重。结构分解与 Harsanyi 不完全信
   息博弈中"共同知识 / 私人信念"的二分形成类比，可作为方法选择的理论参照系。

(3) 规划层面
   面向多智能体 MVE 中的两个困难（联合动作空间 A^N 组合爆炸；其他 agent 随机性导
   致的 SNR 塌陷至 0.02），本文提出 Per-Agent Coordinate Descent + CRN 双重技
   术。前者把搜索空间压到 N·A 并对应 ε-Nash 均衡；后者使第 0 步候选评估的 SNR 恢
   复到 1.0。两项技术互为前提，缺一则整套规划信号失效。

(4) 实证层面
   本文给出四项可证伪断言 A / B′ / C / D 及其预登记失败回退方案。在 ResourceCommons
   与 v3 NonStationaryTag 两个环境上完成主对比、五项消融、零样本泛化与 hidden-c 双
   档信念质量验证。承诺：任一断言在实验中未能成立，对应贡献相应降级或重定位。
```

## §1.5 可证伪断言与论文论证结构（~1 400 字）

> 本文方法层贡献（贡献 2、3）由四项可证伪断言 A / B′ / C / D 完成验证：
>
> **断言 A（类型梯度撕裂的钟形曲线）**：在类型异质设定下，共享 RewardHead 的社会福利显著低于按 type 条件化生成的 per-agent θ_rew；优势在类型混合比例 ρ_β ≈ 50/50 处达峰，在 0/4 与 4/4 同质设定下趋于零，构成钟形曲线。**断言 B′（条件化谱内部最优）**：在条件化谱 Input → FiLM → LoRA → base_gen → full 上，左端因容量平均化、右端因优化方向坍缩（cos_pred_cross 0.61→0.998）双面失败，峰值位于谱内部（预注册预测：film_head + LoRA 至 lora_fc2 之间）。**断言 C（三联通路缺一不可）**：c_ctx、role_i、belief_i 三通路对主观通路缺一不可，且三路径退化效应正交可加。**断言 D（规划器双重技术不可分割）**：Per-Agent Coordinate Descent 与 CRN 的 2×2 矩阵在 Easy N=2 上完整展示——CoordDesc 单独使用受 SNR 塌陷拖累，CRN 单独使用受联合搜索空间爆炸所限，双重启用最优。

## §1.6 论文组织（~900 字）

> 全文共六章。第 2 章梳理 mixed-motive MARL、多智能体世界模型、条件化机制谱与社会偏好建模四方面相关工作，并在 §2.4 给出本文方法的位置。第 3 章在给出 RNS-MMG 形式化（§3.1）之后，把 v3 NonStationaryTag 作为初步研究（§3.2，承接毕设汇报）显式继承，再展开 ResourceCommons 基准（§3.3–§3.7）。第 4 章是主方法章，依次给出三个容量瓶颈的形式化动机（§4.1）、条件化谱（§4.2）、Harsanyi 类比下的 DualHyperNetwork v2 架构（§4.3–§4.4）、Per-Agent MVE+CRN 规划器（§4.5）与训练算法（§4.6）。第 5 章按"协议 → 主对比 → 五项消融 → 鲁棒性 → 失败案例"展开实验，每个消融节均对应一项可证伪断言。第 6 章总结贡献、局限与展望。
