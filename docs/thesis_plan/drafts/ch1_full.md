## §1.1 研究背景：从纯合作/零和到混合动机的真实世界

多智能体强化学习（Multi-Agent Reinforcement Learning，MARL）研究通常基于两类极端假设之一：完全合作（所有 agent 共享同一奖励函数）或严格零和（一方收益等于另一方损失）。然而，现实中的多智能体系统大多并不落在这两个极端之上：自然资源采集中的渔民群体、电网调度中的发电节点、共享带宽中的网络节点，其个体目标既不完全一致也不严格对立，而是在合作与竞争之间存在持续的张力。这一类问题在博弈论中被归为**混合动机博弈（mixed-motive games）**。

在 MARL 研究中，针对混合动机博弈已有较为活跃的工作积累。Leibo 等人 [15] 将经典囚徒博弈推广为序贯社会困境（Sequential Social Dilemma），并构造 Harvest、Cleanup 等环境作为研究载体；Hughes 等人 [11] 在该框架上引入 Fehr-Schmidt 不平等厌恶作为内在奖励项以促进合作；Leibo 等人 [14] 进一步构建 Melting Pot 多场景套件用于评估泛化能力。这些工作的共同前提是：**博弈关系本身（合作-竞争的相对强度）在整个学习过程中保持静态**——一旦环境被设定为"合作主导"或"竞争主导"，相应的支付结构在所有 episode 中不再发生结构性改变。

这一前提与许多真实场景并不相符。在渔场中，资源丰度的高低直接决定渔民之间是合作维护渔场可持续性，还是竞争性过度捕捞；在电网调度中，可再生能源出力的波动会改变发电节点之间合作与竞争的相对比重。换言之，**博弈关系本身是可观测物理状态（尤其是资源丰度）的函数**，并随时间动态变化。本文聚焦于这一在现有 mixed-motive MARL 工作中尚未被系统讨论的情形，将其形式化为关系非平稳混合动机博弈（Relation Non-Stationary Mixed-Motive Game，RNS-MMG）。

公地博弈（Commons Dilemma）作为该现象的工业对应早有制度经济学层面的讨论。Hardin [9] 的"公地悲剧"论证在资源稀缺压力下个体理性如何聚合为集体非理性；Ostrom [16] 反向论证了治理机制如何在资源丰度的时序变化下稳定合作。从 MARL 视角观察，这两类截然相反的结论恰好对应同一资源稀缺-丰盈坐标的两个区段：稀缺区段（"荒年"）下个体激励指向竞争性采集，丰盈区段（"丰年"）下个体激励指向合作维护。现有 Sequential Social Dilemma 框架 [15][11] 的固定支付矩阵无法捕捉这一区段间的结构性切换，因为支付矩阵一旦设定即在整个 episode 中保持不变。

理解这一从"两极假设"向"混合动机张力"再向"关系非平稳"的递进，是本章后续各节展开的语境前提：§1.2 将给出 RNS-MMG 的形式化定义并与几类相邻问题划清边界；§1.3 进一步审视 model-free 合作型 MARL、单/多智能体世界模型、社会困境专用方法四类范式在 RNS-MMG 设定下的具体局限；§1.4 据此给出本文的方法回应。

## §1.2 问题陈述：关系非平稳混合动机博弈 (RNS-MMG)

第 1.1 节指出，现有 mixed-motive MARL 工作的共同前提是博弈关系在整个学习过程中保持静态。本节将"博弈关系随可观测物理状态动态切换"这一情形形式化，记作**关系非平稳混合动机博弈**（Relation Non-Stationary Mixed-Motive Game, RNS-MMG）。需要先行声明的是，RNS-MMG 在此作为术语锚点用于精确指代后文将要刻画的子类设定，而非主张建立新的理论范畴。

在 N 个 agent 的标准马尔可夫博弈 $G = \langle \mathcal{N}, \mathcal{S}, \{\mathcal{A}_i\}, P, \{R_i\}, \{O_i\}, \gamma \rangle$ 之上，引入共享上下文变量 $c_t \in \mathcal{C}$ 及其分布 $P_c$，并对博弈结构施加三条约束。**(C1) 物理转移的 agent-同构性与上下文内禀演化性**：物理转移函数 $P(s'|s,a)$ 在所有 agent 间共享（agent-invariant），其函数式由环境本身固定（不随 $c_t$ 切换为不同的转移规则）；$c_t$ 作为状态的一部分按内禀动力学演化，并通过资源场动力学间接调控博弈关系。**(C2) 博弈关系的类型-上下文联合调控**：奖励函数 $R_i(s,a;c_t,\tau_i)$ 由 $c_t$ 与 agent 类型 $\tau_i$ 联合调制；本文在 §4.1 给出一个具体的偏好实例化（基于 Fehr-Schmidt 不平等厌恶 [40] 并由 $c_t$ 进行强度调制），其中类型异质 agent 在不同 $c_t$ 区段呈现结构性相反的奖励梯度方向——该"相反梯度"是 §4.1 建模选择下的可检验性质而非 (C2) 的定义部分，(C2) 本身仅要求类型与上下文联合非平凡地调制偏好。**(C3) 上下文的物理不可控性**：$c_t$ 由环境内禀机制演化，agent 动作对其只有间接或缓慢影响。

RNS-MMG 与几类相邻问题有清晰的边界。与一般非平稳 MDP / Markov Game [20][21] 相比，RNS-MMG 显式假设非平稳源自一个可被观测或推断的物理变量 $c_t$，而非时间显式索引；与静态 mixed-motive（Cleanup, Harvest）[15][11] 相比，RNS-MMG 允许博弈关系随 $c_t$ 动态切换；与领域随机化相比，RNS-MMG 中的 $c_t$ 在单条 episode 内有明确的演化规律，而非每个 episode 重新独立采样。

RNS-MMG 与上下文化决策过程家族也存在结构性差别，这一差别决定了直接套用该家族方法的局限。Contextual MDP（Hallak 2015）以一个潜在任务索引调制单一 agent 的转移与奖励，标准设定下不涉及多 agent 类型异质与 (C2) 所要求的"类型-上下文联合调制"。Hidden-Parameter MDP（Doshi-Velez & Konidaris 2016）与 Latent-MDP / BAMDP 一脉相承，其潜变量按 episode 静态采样，episode 内部保持不变；而 RNS-MMG 的 $c_t$ 在单条 episode 内按内禀动力学演化，agent 需在线感知其变化并据此调整策略。Melting Pot 套件 [14] 的 substrate 变化属于 episode 间或场景间的设定切换，单条 rollout 内部物理上下文同样静态。综合而言，RNS-MMG 在概念上可记作"Contextual MARL + (C2) 类型异质性 + (C3) $c_t$ 不可控性 + intra-episode 上下文演化"四要素的合取——任一要素单独存在均落入已有家族，本文方法的针对性来自这四要素的同时成立。

三条约束的物理意义可以用资源采集场景说明。约束 (C1) 强调资源开采的物理机制不随上下文改变——无论资源丰度如何，单位努力获得的物理产量服从同一规律；变化的是各 agent 的偏好结构而非物理转移。约束 (C2) 是 RNS-MMG 与一般非平稳 MARL 的关键差别：在 §4.1 的偏好实例化下，同一 $(s, a)$ 下不同类型 agent 的瞬时奖励梯度可能符号相反——例如类型 α agent 的瞬时奖励梯度 $\partial R^\alpha/\partial u_i$ 恒为正（个体收益最大化），而类型 β agent 在资源稀缺区段对劣势状态表现出强反向梯度（本文借用 Fehr-Schmidt 不平等厌恶偏好结构 [40]，并由上下文 $c_t$ 通过 $\phi(c_t)$ 调制其强度——后者是本文方法层设计，Fehr-Schmidt 1999 原工作不含上下文调制）；同时承认在中性区段（$c \approx 0.5$）两类 agent 的瞬时梯度近乎重合。约束 (C3) 把上下文显式标记为环境内禀变量，避免与 agent 动作的耦合干扰对偏好层的因果归因，使 RNS-MMG 的设定与 Harsanyi [10] 不完全信息博弈框架在结构上相容——agent 类型属于私人信息，上下文属于共同知识。

三条约束的联合作用解释了为何 RNS-MMG 在方法层面不可简单退化为已有范式。若仅保留 (C1) 而放弃 (C2)，问题退化为同构非平稳 MARL，多智能体世界模型（如 MAMBA [8]、MA-MuZero [30]）已足以处理；若仅保留 (C2) 而放弃 (C1)，问题与"具有异质支付的非合作博弈"等价，可由传统博弈论分解处理；若放弃 (C3) 的内禀演化（如把 $c_t$ 退化为 episode 级静态潜变量），则可由 HiP-MDP / Latent-MDP 多 agent 扩展直接处理；只有当三条约束同时成立、且 $c_t$ 在 episode 内持续演化时，"博弈关系随物理状态切换 × 类型异质性 × 部分可观测性 × intra-episode 演化"这一组合才出现，使现有方法的容量假设受到实质挑战。

需要强调的是，三条约束并非对所有"非平稳 + 异质"问题的描述，而是对一个**可分离子类**的精确刻画——本文据此设计的方法对该子类有针对性，对该子类之外的设定（如博弈关系随 agent 动作直接切换、或类型在 episode 内变化）不主张优势。这一边界的明确是 §1.3 现有方法局限分析与 §1.4 方法贡献声明的共同前提。

## §1.3 现有方法五个范式的系统性局限

围绕 RNS-MMG 这一问题设定，本节考察 model-free 合作型 MARL、单智能体世界模型、多智能体世界模型、社会困境专用方法、以及非平稳 MARL 通用应对策略五个相邻方法范式的局限性。五类方法各自对 (C1)-(C3) 的某一两条有局部回应，但没有一类同时对三条约束都有架构层面的设计；本文方法的针对性正来自把这三条约束作为联合设计起点。

### Model-free 合作型 MARL 与 CTDE 框架

MAPPO [3] / QMIX [4] / MADDPG [5] 通过集中训练-分散执行（CTDE）框架获得广泛应用——其中 MADDPG 原始论文标题即 "Mixed Cooperative-Competitive"，严格而言属于混合合作-竞争设定，MAPPO 与 QMIX 则更偏向合作设定。三者的网络权重隐式拟合特定环境转移与奖励结构，当博弈关系随 $c_t$ 切换时缺乏自适应机制，需要重新收集大量数据。具体到 RNS-MMG 下，类型异质 agent 共享 critic 时，bootstrap target 在 α / β 两类奖励梯度方向相反的设定下方差显著增大，样本效率严重退化；$c_t$ 切换处更需要从头收集 on-policy 样本。需要明确的是，critic 的此类方差退化与 §1.3 后文将讨论的 RewardHead 类型梯度撕裂在机制上不同：critic 退化源于 bootstrap target 的方差放大，RewardHead 撕裂源于反向传播梯度方向冲突——二者不应混为一谈，本文"类型梯度撕裂"术语严格保留给 RewardHead 上的反向传播代数现象。

### 单智能体与多智能体世界模型

单智能体世界模型 MuZero [24] / Dreamer [6] / DreamerV3 [7] 通过学到的潜在动力学在 Atari 等任务上取得 SOTA 表现，但其奖励预测在多 agent 扩展时通常仍假定共享奖励函数。常见的多 agent 扩展模式是 centralized critic + per-agent representation，应用于偏好异质 agent 时单一 RewardHead 无法同时表征 α / β 两类奖励梯度方向相反的偏好。

多智能体世界模型族——MA-MuZero [30]、MAMBA [8]、MARIE [17]——架构上有显著差别但在 RNS-MMG 设定下共享同一类容量瓶颈，需要分级讨论而非笼统归类。**MA-MuZero** 推广 MuZero 到 multi-agent 场景，通常共享 reward head 因为目标合作设定下环境奖励本身共享，扩展到偏好异质场景时缺少 per-type 条件化设计；**MAMBA** 采用 CTDE + 集中-分布式编码 [8]，agent 各自有 prediction head 但 head 间无显式 type 条件化通路；**MARIE** 的核心卖点是 role-aware encoding——其 role 指任务角色（如 Hunter / Prey），与本文 type-aware 条件化在动机上接近但语义不同：role 编码"在博弈中担任何种位置"，type 编码"偏好结构属于何种家族"，二者在 RNS-MMG 下需联合作用（§2.2 详述本文与 MARIE 的具体差别）。本文将这三类系统在 RNS-MMG 下共享的容量瓶颈称为**类型梯度撕裂**——类型 α 的奖励梯度恒为 $+1$，类型 β 的瞬时梯度在 $(c, \Delta)$ 不同区段取值于 $\{0, 0.7, 1.3, 2.0\}$（详见 §4.1.1 类型梯度量化表），共享 RewardHead 训练目标等价于在这两类方向间求加权平均，结果是任何单一类型策略均偏离其偏好最优响应。该瓶颈在 §5.7 通过预登记消融实验予以检验（断言 A）。需要强调的是，"撕裂"机制依赖于 baseline 与 HyperNet 在参数量及上下文相关子空间维度上的对照设定（详见 §5.1.4 双指标协议）；若 baseline 容量显著扩大，撕裂强度会减弱但不消失——反向传播方向冲突属于梯度层而非容量层现象。

### 社会困境专用方法

社会困境专用方法面向 Cleanup、Harvest 等静态社会困境设计，但具体机制分属三类不同范式，与 RNS-MMG 的兼容性差异明显，应分别评估：（i）**Hughes 等 [11] 不平等厌恶**是 reward shaping 范式，把 Fehr-Schmidt 偏好作为内在奖励项注入；其与 RNS-MMG 的冲突在于 $c_t$ 切换下需要不同 shaping 强度，而 reward shaping 项一旦设定即在所有 $c_t$ 区段统一作用。（ii）**Social Influence [18]**（Jaques 2019）是 intrinsic motivation regularizer——其 causal influence 项最小化 $\mathrm{KL}(\pi_{\text{self}} \| \pi_{\text{others}})$，与博弈支付矩阵正交而非 reward shaping；其与 RNS-MMG 的冲突在于因果作用估计依赖 stationary opponent policy 分布，$c_t$ 切换破坏该假设。（iii）**LIO [19]**（Yang 2020）是 peer-to-peer reward gifting via meta-gradient——其 meta-objective 在 $c_t$ 切换处的两个区段方向可能相反，无法在单一学习过程中保持稳定。（iv）**Conflict-Aware Gradient Adjustment [13]** 的冲突感知梯度调整在博弈关系随 $c_t$ 切换时缺乏可识别的"冲突方向"。三类机制在文献中通常被并称为"社会困境专用方法"，但其内部机制差异显著——把它们不分级合并为同一类 reward shaping 不准确；本文在 §2.1 详细比较这四类方法的内禀机制与 RNS-MMG 兼容性。

### 非平稳 MARL 通用应对策略

非平稳 MARL 已有相当系统化的应对策略综述 [21]，主要分三类：（i）**对手建模**（opponent modeling，如 Rabinowitz 2018 ToMnet 与 Foerster 2018 LOLA）——假设对手策略平稳或慢速变化；在 RNS-MMG 中 $c_t$ 显式切换博弈关系时对手最优响应同时变化，对手建模的预测目标不稳定。（ii）**元学习**（meta-RL，如 RL² 与 MAML 的 task-conditioned 变体）——在 episodic 任务切换上有效但要求每个 episode 内 stationary，与 RNS-MMG 的 intra-episode 上下文演化不符。（iii）**自适应学习率** [20]（Bowling-Veloso WoLF 系列）——基于 best-response dynamic 而非 type-conditioned generation，处理的是博弈策略层非平稳而非偏好结构异质。本文 BeliefNet 在功能上接近对手建模，DualHyperNetwork 在功能上接近 meta-learning 的 task-conditioned 变体，但本文方法对 (C2) 类型异质性与 (C3) intra-episode $c_t$ 演化的联合回应使其与上述三类策略形成结构性差别：本文不假设对手策略平稳（与 (C3) 兼容），不假设任务在 episode 内静态（与 intra-episode 演化兼容），且把"类型条件化"作为奖励/价值生成的架构维度而非元目标。

### 五范式批评的综合

五类方法各自对 (C1)-(C3) 中某一两条有局部回应，但没有一类同时对三条约束都有架构层面的联合设计。本文第 4 章将给出一个把三条约束作为联合设计起点的方法——双路超网络在客观 / 主观通路上的分解直接对应 (C1) 的 agent-同构性与 (C2) 的类型-上下文联合调制；BeliefNet 在线推断对应 (C3) 的部分可观测性与 intra-episode 演化。§1.4 将先以贡献声明的形式给出该方法的概要。

## §1.4 研究目标与四项贡献

围绕第 1.2 节的 RNS-MMG 问题，本文做出四项贡献，分别覆盖问题、算法、规划、实证四个层面。前两节定位的现有方法局限——Model-free 合作型对非平稳博弈缺乏自适应、多智能体世界模型的共享 RewardHead 受类型梯度撕裂、社会困境专用方法依赖静态博弈假设——共同要求新方法分别回应 §1.2 的 (C1)/(C2)/(C3) 三条约束：客观结构在 agent 间共享、主观偏好按类型条件化、上下文 $c_t$ 在线推断。四项贡献的设计正是对这一组合需求的直接回应。

```
   术——两类互补机制：前者解决多 agent 联合动作的计算可行性 (A^N → N·A)，其不动
   点在 K 步 value 估计为精确时对应于 ε-Nash 均衡（形式陈述见 §4.5）；后者解决其
   他 agent 随机性下的信号-噪声比 (SNR 0.02 → 1.0)。两者面向不同失败模式（计算
   vs 信号），目标部署区段（Medium N=4 及以上）需联合启用；§5.8 在 Easy N=2 上
   的 2×2 矩阵分别量化两轴的边际贡献。

(4) 实证层面
   本文给出四项可证伪断言 A / B′ / C / D 及其预登记失败回退方案。在 ResourceCommons
   与 v3 NonStationaryTag 两个环境上完成主对比、五项消融、零样本泛化与 hidden-c 双
   档信念质量验证。承诺：任一断言在实验中未能成立，对应贡献相应降级或重定位。
```

四项贡献的内部依赖关系明确：贡献 1（问题形式化）是后三项的语境前提，贡献 2 与 3 是方法层对 RNS-MMG 的两条独立回应——前者面向偏好异质的奖励/价值学习，后者面向规划阶段的多 agent 联合动作评估——贡献 4 通过预登记可证伪断言把方法层声明硬绑定到实验。这一**贡献-断言-实验**的硬绑定结构本文称为"承诺级表述"，是方法可信度的写作层保障。本文承诺：若任一断言在第 5 章实验中未能成立，对应贡献按 §1.5 的预登记方案降级或重定位。

需要明确若干范围限定。**贡献 1 不主张** RNS-MMG 是对 mixed-motive MARL 的总体重构，仅声明这是在现有工作下尚未被系统讨论的一类设定，其形式化为后续算法设计提供锚点。**贡献 2 不主张** DualHyperNetwork 是 Harsanyi 博弈论在深度世界模型中的"实现"——本文将其与 Harsanyi 二分做结构类比，仅作为方法选择的理论参照系，无形式化等价主张。**贡献 3 的 ε-Nash 对应**针对 Per-Agent Coordinate Descent 的不动点而非全局均衡。形式陈述（ε 关于 K, γ, 模型误差的具体表达式）见 §4.5；规模较大场景下该对应作为可扩展性的理论充分条件，仍依赖 §5 的经验验证。**贡献 4 的实证范围**限于 ResourceCommons + v3 NonStationaryTag 两个环境，$N \in \{2, 4, 8\}$（其中 $N=8$ 在 P2 优先级），实验受 ~300 GPU hours 预算约束并按 P0/P1/P2 三优先级降级，详见 §5.1 实验协议。

贡献 2 与贡献 3 在工程层面有两项承诺待实现的开关。其一是 EnvConfig 的 `c_visible` 开关，用于支持隐藏-$c$ 档下 BeliefNet 对资源丰度的在线推断质量评估（影响 §5.10 信念质量协议与断言 B′(ii) 的硬验证）。其二是 MVE planner 的 `joint_enum` 模式，用于在 Easy N=2 (A=6, 36 joint actions) 配置下完整呈现协调下降 × CRN 的 2×2 矩阵（影响 §5.8 断言 D 的充分性证据）。两项工程开关均在 §5 实验执行前完成，并在 §5.11 失败案例节明示其在 §5 各实验中的具体作用域。

贡献 2 与贡献 3 在闭环中互为必要条件，这一互锁结构是四项贡献并列陈述的方法论基础：(i) 在 planner-off 设定下（§5.9），共享 RewardHead baseline 因方法层信号无法形成有效策略梯度，策略熵钉死于 $\ln A$——这证明缺贡献 3 时贡献 2 单独无法兑现规划层增益；(ii) 在双重技术规划但 baseline RewardHead 的设定下（§5.7 主对比 baseline 组），类型梯度撕裂使规划信号被类型平均奖励函数误导——这证明缺贡献 2 时贡献 3 的规划增益无法体现在偏好异质群体上。这一双向必要性把贡献 2 与贡献 3 从可分割工程组合升格为方法学层面的耦合设计。

四项贡献的实验绑定关系将在 §1.5 通过四项可证伪断言 A / B′ / C / D 给出明确陈述，每项断言均标注预登记的失败回退方案，确保贡献声明与实验结果之间的双向可追溯。

## §1.5 可证伪断言与论文论证结构

本文方法层贡献（贡献 2、3）由四项可证伪断言 A / B′ / C / D 完成验证：

**断言 A（类型梯度撕裂的钟形曲线）**：在类型异质设定下，共享 RewardHead 的社会福利显著低于按 type 条件化生成的 per-agent θ_rew；优势在类型混合比例 $\rho_\beta \approx 50/50$ 处达峰，在 0/4 与 4/4 同质设定下趋于零，构成钟形曲线。**断言 B′（条件化谱内部最优）**：在条件化谱 Input → FiLM → LoRA → base_gen → full 上，左端因容量平均化、右端 FULL 方向坍缩（cos_pred_cross $0.61 \to 0.998$）双面失败，峰值位于谱内部（预注册预测：film_head + LoRA 至 lora_fc2 之间）。**断言 C（三联通路缺一不可）**：c_ctx、role_i、belief_i 三通路对主观通路缺一不可，且三路径退化效应正交可加。**断言 D（规划器双重技术不可分割）**：Per-Agent Coordinate Descent 与 CRN 的 2×2 矩阵在 Easy N=2 上完整展示——CoordDesc 单独使用受 SNR 塌陷拖累，CRN 单独使用受联合搜索空间爆炸所限，双重启用最优。

本文承诺：任一断言在第 5 章实验中未能成立，对应贡献按预登记方案降级或重定位。这一**贡献-断言-实验**的硬绑定结构是本文方法论上的承诺。

| 断言 | 实验位置 | 失败回退 |
|---|---|---|
| A | §5.7 消融 3 + §6.11 可视化 | 主预测：钟形曲线峰值落在 ρ_β ∈ [1/4, 3/4]（即非两端同质设定），峰值与端点 (0/4 或 4/4) 的社会福利差距 ≥ 5% 且 p < 0.05（Welch's t-test，与 Ch6 §6.6.5 阈值一致）。失败回退：若峰差 < 8% 或 p ≥ 0.05 → 贡献 2 降级为「特定区段优势」 |
| B′ | §5.5 消融 1 + 零样本 + hidden-c | 三分级降级，最差降为相关工作分析视角 |
| C | §5.6 消融 2 + §5.10 信念质量 | 非正交 → 弱版本"三路径互补" |
| D | §5.8 消融 4（Easy N=2 三轴：CRN × Joint-vs-CoordDesc × order-rand；Medium 二轴 CRN × CoordDesc）| 若 Joint enumeration cell（pkg-08 未交付）缺失 → Easy 二轴 + ε-Nash 理论保证；若 Medium 二轴中 CRN 增益 < 30% → 断言 D 降级为 SNR 必要性证据 |

每项断言的机制层面解释如下（脚注：以下机制段中引用的具体数值——cos_pred_cross 0.61→0.998、SNR 0.02→1.0、类型 β 梯度 ∈ {0, 0.7, 1.3, 2.0}——均源自 v4-opt 2026-06 优化阶段开发观察（见 Review_v4_TheoryAudit_2026-06.md）；§5 实验在预登记协议下独立报告这些数值的复现确认）：

**断言 A 的代数根据**：类型 α 的瞬时奖励梯度 $\partial R^\alpha/\partial u_i \equiv 1$，类型 β 的瞬时奖励梯度 $\partial R^\beta/\partial u_i$ 在 $(c, \Delta_i)$ 的不同区段取值于 $\{0, 0.7, 1.3, 2.0\}$（详见 §4.1.1 类型梯度量化表）。共享 RewardHead 在反向传播中聚合这两组方向相反的梯度，等价于训练一个"类型平均"的奖励函数；该函数在群体类型混合处偏离任何单一类型的真实偏好最远，故社会福利差距在 $\rho_\beta \approx 50/50$ 处达峰。同质设定（$\rho_\beta = 0$ 或 $1$）下不存在反向梯度，per-agent 设计无优势，差距趋零。该机制使钟形曲线在 $\rho_\beta \in (0, 1)$ 内存在峰值成为反向传播的代数预测；类型 β 梯度 $\in \{0, 0.7, 1.3, 2.0\}$ 的非对称分布在第一原理上自然预测峰值偏向 α-多侧（具体值由 $\psi(\Delta)$ 与 $\phi(c_t)$ 参数化决定，详见 §3.5 偏好层与 §4.1.1 类型梯度量化表）。本文的预登记预测因此分为两层：（i）主预测——峰值在 $\rho_\beta \in [1/4, 3/4]$ 区间内存在且与端点差距 ≥ 5%；（ii）二级预测——峰值精确位置由实验决定。若主预测失败（峰差 < 8% 或 p ≥ 0.05），贡献 2 按表中预登记方案降级。

**断言 B′ 的几何根据**：条件化谱的左端（Input conditioning, FiLM）通过共享 SGD 基座加少量调制实现轻量条件化，参数容量在 agent 间平均化；右端（base_gen, full）让超网络生成全部目标参数，方向自由度过高导致优化阶段的方向坍缩——v4 优化阶段实测 cos_pred_cross 在训练中后期由 0.61 上升至 0.998，表明所有上下文输入被映射到几乎同一参数方向，等价于退化为输入条件化但额外承受超网生成的优化代价。两端失败模式不同——左端是容量不足，右端是优化路径退化——共同导致谱内部存在最优点。预登记预测峰值位于 film_head + LoRA 与 lora_fc2 之间，对应的 gen_scope 选择在第 5 章决策门 0（§5.2）独立前置实验中确定，并作为主对比的固定配置使用。

**断言 C 的正交性根据**：三联通路对应三类语义不同的输入——c_ctx（共同知识：环境状态）、role_i（私人结构：自身类型与能力）、belief_i（私人推断：他人类型估计）。三类输入在 Harsanyi 框架下属于不同语义层级（共同知识 / 自身私人信息 / 关于他人的私人信念），理论上其对主观通路的贡献应可分离。断言 C 通过依次移除各通路的消融实验予以检验：若三类退化效应正交可加，断言成立；若非正交（如移除 role 后再移除 belief 的额外退化与单独移除 belief 不同），则降级为"三路径互补"的弱版本，仍保留方法论上的合理性。

**断言 D 的信号-噪声比根据**：多智能体 MVE 中评估单个 agent 候选动作时，其他 agent 的随机性引入的方差量级为 $\mathrm{Var}(R_{\text{others}})$，而候选间真实差异为 $\Delta$。仅启用协调下降的方差比 $\mathrm{SNR} \approx \Delta / \sigma_{\text{others}} \approx 0.02$（实测，见 §5.1.2）；启用 CRN 共享其他 agent 第 0 步随机种子后，候选间差异中 $R_{\text{others}}$ 项在第 0 步上抵消，残留方差仅来自 $k>0$ 步的 $\gamma^k$ 折扣项，实测 SNR 恢复至接近 1.0。仅启用 CRN 但不做协调下降则需枚举 $A^N$ 联合动作，组合爆炸（Medium N=4, A=6 已是 1296，Hard N=8（假定 A=6）达 $6^8 \approx 1.68 \times 10^6$）使方法在 Medium 配置上不可执行。两类机制面向不同失败模式（计算 vs 信号），互补而非互为前提。

Assertion D 的验证遵循 Ch6 §6.7 v4-opt 2026-06 重定义的三轴设计：(a) CRN on/off——信号噪声比轴；(b) Joint enumeration vs Per-Agent CoordDesc——计算压缩轴（仅在 Easy N=2 上完整展示，pkg-08 工程开关交付为前置依赖）；(c) order randomization——控制项。Medium N=4 配置上仅呈现 CRN on/off × CoordDesc 两轴作为必要性证据，配合 §4.5 协调下降不动点对应 ε-Nash 均衡的理论分析作为可扩展性证据。在 planner-off 自蒸馏退化引理下，缺 CRN 时 $\pi_{\text{mve}}$ 因 SNR 塌陷退化为均匀分布并成为整个闭环的不动点，策略熵钉死在 $\ln A$（详见 §5.9 planner-off 演示）；缺协调下降则计算开销在 Medium/Hard 部署不可接受。

四项断言的预登记失败回退方案使本文遵循"可被否定也可被复现"的实证规范（详见 §5.1 实验协议）。第 5 章实验协议（§5.1）对每项断言提供独立显著性检验（Welch's t-test）+ 显式效应量阈值，确保实验结果可在不依赖审稿主观判断的情况下被验证。三项进一步的工程公平性承诺——μP 学习率对齐（详见 §5.1.4）、双指标对照协议（HyperNet 参数量 + 上下文相关子空间维度两列独立报告，加固于 v4-opt 2026-06）、跨方法的相同 LR sweep 协议——具体见 §5.1.4。

四项断言的失败回退方案之间存在结构性整体边界：若 A / B′ / C / D 中两项及以上同时降级到最弱版本（A 在 Easy N=2 峰差 < 8%、B′ 谱无内部最优峰值、C 三路径完全可分解、D 仅在 Easy N=2 上 CRN 必要性成立），方法层贡献整体从「DualHyperNetwork v2 + Coord+CRN 在 RNS-MMG 上的有效性证明」降级为「对 RNS-MMG 设定下若干架构与规划选择的初步探索性比较」，对应 §6 章贡献复述与未来工作章节的整体改写。这一整体失败门槛是预登记承诺的核心，避免四项断言之间的渐进 hedge 形成无法被否定的修辞结构。

## §1.6 论文组织

全文共六章。第 2 章梳理 mixed-motive MARL、多智能体世界模型、条件化机制谱与社会偏好建模四方面相关工作，并在 §2.4 给出本文方法的位置。第 3 章在给出 RNS-MMG 形式化（§3.1）之后，把 v3 NonStationaryTag 作为初步研究（§3.2，承接毕设汇报）显式继承，再展开 ResourceCommons 基准（§3.3–§3.7）。第 4 章是主方法章，依次给出三个容量瓶颈的形式化动机（§4.1）、条件化谱（§4.2）、Harsanyi 类比下的 DualHyperNetwork v2 架构（§4.3–§4.4）、Per-Agent MVE + CRN 规划器（§4.5）与训练算法（§4.6）。第 5 章按"协议 → 主对比 → 五项消融 → 鲁棒性 → 失败案例"展开实验，每个消融节均对应一项可证伪断言。第 6 章总结贡献、局限与展望。

全文使用中文撰写，关键术语保留英文原文。数学符号与缩写约定汇总于附录 B。

本文采用"v3 起源 → v4 结构升级"的双层叙事。v3 NonStationaryTag（毕设汇报阶段已完成）在零和阵营翻转场景下验证了"以超网络条件化博弈视角"这一基本思路的可行性——Capture Rate 75% vs 10% 基线、超网权重在阵营翻转处的显著分化（cos_rew_0v3 $0.37 \to 0.28$；cos_pred_0v3 $0.65 \to 0.50$）均已实测，作为 v4 方法的实证起点保留于 §3.2 与 §5.3。v3 NonStationaryTag 实验本身已构成在零和非平稳对抗任务上对"超网络条件化博弈视角"思路的独立实证贡献，并非仅为 v4 的预备工作；v4 不是对 v3 的修正，而是把同一思路在合作-竞争连续谱的另一端（混合动机偏好异质）上的延伸。v4 在 v3 基础上把研究问题推进到更具理论一致性的公地资源博弈：物理层严格自利同构、偏好层显式异质，让合作-竞争从动力学与偏好的交互中涌现，而非通过 reward shaping 显式注入。这一演进同时承认 v3 的局限——零和场景下不存在类型异质性，且 v3 的 β(c) 协同加成把合作激励直接注入到瞬时支付层而非偏好层——并把这些局限作为 v4 设计选择的反向动机（详见 §3.4 v3→v4 演化分析）。

v3 到 v4 的桥接通过两个独立机制完成。其一，§3.2 以约 2 页篇幅作为初步研究节给出 v3 核心实验数字 + 三大瓶颈分析（类型梯度撕裂、信念稀释、角色平均），使读者理解 v4 方法选择的实证起点。其二，§5.3 将 v4 完整方法（DualHyperNetwork v2 + Coord+CRN + 决策门 0 选定 gen_scope）部署回 NonStationaryTag 进行控制条件下的迁移实验，承诺 v4 在 v3 任务上不劣于 v3 原版（Capture Rate ≥ 75%）、在 RNS-MMG 上社会福利显著高于基线（具体判定阈值见 §5.1.4）。该迁移实验同时回应"v4 是否是回退"和"v4 是否只在新任务上工作"两类潜在质疑。为使 §5.3 迁移在 v4 架构层级可执行，role_i 与 belief_i 在 NonStationaryTag 上重新实例化：role_i ∈ {Hunter, Prey} ∘ 当前规则翻转状态（zero-sum 任务下 agent 阵营在规则切换时翻转），belief_i 由 BeliefNet 在线推断"当前博弈规则朝向"而非他人类型（在 NonStationaryTag 设定下他人阵营在 self-info 观测档下可观测）；c_ctx 由 rule_emb 替代——这与 v4 ResourceCommons 部署的三联通路结构同构，仅输入信号语义按任务重新绑定。若 §5.3 迁移实验中 v4 在 v3 任务上 Capture Rate 退化至 < 75%，双层叙事降级为"v3 与 v4 作为两个独立任务上的独立实证"，§1.6 结构相应改写。
