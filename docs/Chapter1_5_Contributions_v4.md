## 贡献 1(问题层面):RNS-MMG 的形式化与异构偏好公地的提出

本文首次将"博弈关系由共享环境上下文动态调控、且不同 agent 对该上下文的响应方式存在结构性差异"作为一类独立的 MARL 问题进行形式化,定义为 **关系非平稳混合博弈(Relation Non-Stationary Mixed-Motive Game, RNS-MMG)**,并通过三条结构性约束 (C1)-(C3) 严格界定其与一般非平稳 MARL、静态社会困境、领域随机化等相关问题的边界:

- **(C1) 物理转移上下文不变性**:物理转移函数 $P(s'\mid s,a)$ 的函数式不依赖共享上下文 $c$;$c_t$ 作为部分可观测的状态分量,通过资源场动力学间接调控博弈结构。
- **(C2) 博弈关系的类型-上下文联合调控**:博弈关系由 $c_t$ 与 agent 类型 $\tau_i$ 联合调控:类型异质 agent 在不同 $c$ 区段表现出结构性相反的奖励梯度方向。
- **(C3) 上下文的物理不可控性**:$c_t$ 由环境内禀机制演化,agent 动作对其只有间接或缓慢影响。

与 v3 版本相比,**v4 形式化的关键演进是把"类型异质"明确纳入问题定义**——RNS-MMG 不仅包含资源丰度的非平稳,还要求 agent 群体内存在偏好结构上的差异性。这一演进使 RNS-MMG 与 Hughes (2018) [11]、Leibo (2017) [15] 等纯同构社会困境严格区分:同构社会困境下合作-竞争由资源稀缺单一驱动,而 RNS-MMG 下合作-竞争由资源稀缺**与类型异质**联合驱动,博弈结构更接近真实社会(渔民群体里既有短期采捕者也有受社群规范约束的可持续派、电网调度中既有自利节点也有受合规约束的节点)。

该形式化为 mixed-motive MARL 研究开辟了一个被长期忽视的关键子方向。

## 贡献 2(算法层面):面向类型-信念条件化的双路超网络

针对 RNS-MMG 下"类型异质 agent 在共享世界模型上产生相反梯度方向"这一根本性架构挑战,本文提出 **DualHyperNetwork** 架构。其核心论断如下:

> **在异构偏好公地博弈中,不同类型 agent 在同一 (s, a) 下的瞬时奖励梯度方向在 $c$ 的部分区段相反(类型 α 永远 $\partial R/\partial u_i = +1$,类型 β 因 Fehr-Schmidt 不平等厌恶项 $\phi(c)\psi(\Delta_i)$ 在 c 低区段对劣势状态产生强反向梯度);共享 RewardHead/PredictionNet 在反向传播中被相反梯度撕裂为类型平均策略,社会福利显著低于 Pareto 上界。DualHyperNetwork 通过 per-agent (type, belief, capability) 条件化的参数生成,在**共享 SGD 基座 ⊕ 生成调制段**的分解下,为每种 (类型, 信念, 能力) 组合分配专属容量,从架构层面消除类型梯度撕裂、信念稀释与角色平均化三类容量瓶颈;生成范围(谱上从 FiLM 调制到全量生成)是该分配的科学变量,其最优位置由实验判定(断言 B′)。**

> **[v4-opt 2026-06 注]**:原表述"世界模型权重完全为该组合定制"对应全量生成(谱右端);优化阶段实证(FULL 方向坍缩,Ch4.3.5)表明全量定制在优化轴上失败,核心论断按"基座 ⊕ 调制"分解修订。

### 类型 β 的语义说明:心理偏好 vs 行为现象

类型 β 采用经典 Fehr-Schmidt (1999) [40] 不平等厌恶偏好,并由 $\phi(c)$ 调制其强度。**类型 β 的心理偏好结构在所有 $c$ 区段保持不变**(始终是 inequity-averse,且对劣势的反感系数 $\lambda_{\text{disadv}} = 2.0$ 强于对优势的反感系数 $\lambda_{\text{adv}} = 0.6$,与 Fehr-Schmidt 1999 经典值一致);**变化的只有偏好的强度与方向**(由 $\phi(c) = \kappa(1-2c)$ 调制,$c$ 低时 $\phi > 0$ 放大不平等厌恶,$c$ 高时 $\phi < 0$ 翻转为"反不平等厌恶")。

| $c$ 区段 | $\phi(c)$ 符号 | 心理偏好(类型 β) | 行为现象(涌现) |
|---|---|---|---|
| 荒年($c$ 低) | $\phi > 0$,放大 Fehr-Schmidt | 极度厌恶被甩开(劣势反感 $2\kappa$,优势反感 $0.6\kappa$) | **激进追赶 / 剥削**——看到他人在采时不能容忍自己落后 |
| 中性($c \approx 0.5$) | $\phi \approx 0$ | 不平等厌恶近乎沉默,纯自利 | 与类型 α 行为相近 |
| 丰年($c$ 高) | $\phi < 0$,翻转 Fehr-Schmidt | 不再约束自己向中间靠拢,对绝对收益敏感 | **协同采集 / 合作**——共采能让所有人都拿得多 |

**关键方法论:agent 的心理偏好不变,行为模式作为最优策略涌现**。这与 v1 版本"直接编码合作/竞争行为"的 reward shaping 路线根本不同——v2 给的是"该怎么感觉"而非"该怎么做",合作与剥削是 RL 在偏好空间中找到的最优响应。这一设计严格符合本文原则 I(自利偏好 + 涌现博弈)与 Hughes (2018) [11] 等不平等厌恶文献的标准做法。

### 贡献 2 承诺的三个可证伪断言

均在第六章消融实验中直接检验:

- **断言 A(类型梯度撕裂)**:在类型异质设定下,共享 RewardHead 的社会福利显著低于 per-agent θ_rew(由超网络生成);差距在类型混合比例 = 50/50 时最大,在同质设定(0% 或 100% 类型 β)下趋于零。**注**:若实际曲线峰值偏离 50/50(例如偏向 α-多侧),这本身是 informative 结果——它揭示了"DualHyperNetwork 优势来源于类型异质性 + 类型学习难度差异"的具体组合,论文写作中将作为正向发现报告,而非偏离预期。

- **断言 B′(生成范围谱上的容量分配,`[v4-opt 2026-06]` 重构自原断言 B)**:把条件化机制按上下文相关参数子空间的维度与秩排成谱(input conditioning ↔ FiLM/film_head ↔ lora_fc2 ↔ base_gen ↔ full,Ch4.1.2),则 (i) 谱左端因**容量平均化**在未见 $c$ 值的零样本泛化上显著劣于部分生成(原断言 B 方向保留);(ii) 谱右端因**优化失败**(权重估计方差与方向坍缩)显著劣于部分生成(FULL 坍缩作为发现报告);(iii) 性能峰值位于谱**内部**(预注册预测:film_head+LoRA 至 lora_fc2 之间)。三个失败面分别可证伪。对照实验按**双指标协议**(对齐功能网络总参数;HyperNet 参数与上下文相关子空间维度单列报告)执行,见贡献 4 实验协议。

- **断言 C(三联通路的不可替代性)**:c_ctx、role_i(含 type_emb + cap_emb + id_emb)、belief_i(含 $\hat{c}$ + $\hat{z}$)三联输入对主观通路 hyper_rew/hyper_pred 缺一不可;任一通路被移除均导致主指标显著下降,且三个通路的贡献相互正交、可累加。

DualHyperNetwork 的设计在数学结构上严格对应于 Harsanyi (1967) [10] 不完全信息博弈中"共同知识 / 私人信念"的二分,且在两个层级上同时成立:**通路层**——客观通路 hyper_trans 仅以 c_ctx 为输入,生成所有 agent 共享的 θ_state(共同知识);主观通路 hyper_rew / hyper_pred 接收完整三联输入,生成 per-agent 权重(私人信念);**参数层**(`[v4-opt 2026-06]` 强化)——共享 SGD 基座 = 共同知识先验,生成调制段(FiLM/头/ΔW)= 类型条件最优响应。新颖性主张落在 Harsanyi 二分的**架构化分解**本身(在文献中首次被实现为深度世界模型的架构性几何分解),FiLM 与 LoRA 是实现该分解的机制选择。

详细架构、三联通路设计、四层稳定性防线、Harsanyi 对应,见第四章。

## 贡献 3(规划层面):Per-Agent 协调下降 MVE + CRN 规划器

针对联合动作空间在多智能体场景下的组合爆炸 $|\mathcal{A}| = A^N$,以及评估单个 agent 动作差异时被其他 agent 随机性所淹没的方差陷阱,本文提出双重技术组合:

- **Per-Agent Coordinate Descent**:将联合搜索空间从 $A^N$ 压缩为 $N \cdot A$。基础配置 $N=4, A=6$ 下,搜索空间从 1296 降至 24,压缩比 54×;Hard 配置 $N=8$ 下压缩比达 35000×。该方案的不动点对应于 ε-纳什均衡,在混合动机博弈中是博弈论上合理的均衡概念。
- **Common Random Numbers (CRN)**:在评估 agent $i$ 的 $A$ 个候选动作时,共享其他 agent 在第 0 步的动作采样,使候选间回报差异中"其他 agent 随机性"项被完全抵消。理论上将第 0 步的信号-噪声比从 ≈ 0.02 提升至 1.0,实际实验中将 $\pi_{\text{mve}}$ 从近均匀分布提升至具备有效判别力的分布。

该贡献承诺一个可证伪断言:

- **断言 D(规划器双重技术的不可分割性)**:仅启用协调下降、仅启用 CRN、双重启用三种配置的对比应展示出层次清晰的性能差距;双重启用相对于仅协调下降的额外提升直接来源于 SNR 改善,而非额外的计算预算。

详见第五章。

## 贡献 4(基准与实验):ResourceCommons 与跨方法类对比

本文构建 **ResourceCommons** —— 面向异构偏好公地博弈的首个开源基准环境。其核心特性:

- **物理层完全自利同构**:每个 agent 的物理采集量 $u_{i,k} = \min(\eta_i, q_k / |H_{k,t}|)$ 仅取决于自身能力 $\eta_i$ 与公平共享上限;无 reward shaping、无协同加成、无 gifting 机制。

- **偏好层显式类型异质(Fehr-Schmidt 不平等厌恶 + φ 调制)**:类型 α(纯自利,$R^\alpha_i = u_i$)与类型 β(Fehr-Schmidt + φ 调制,$R^\beta_i = u_i + \phi(c_t) \cdot \psi(\Delta_i)$)共存,其中:

  $$\phi(c) = \kappa(1 - 2c),\quad \kappa = 0.5$$

  $$\psi(\Delta) = -\bigl[\lambda_{\text{disadv}} \cdot \max(0, -\Delta) + \lambda_{\text{adv}} \cdot \max(0, \Delta)\bigr]$$

  $$\lambda_{\text{disadv}} = 2.0,\quad \lambda_{\text{adv}} = 0.6 \quad \text{(Fehr-Schmidt 1999 经典值)}$$

  $$\Delta_i^{(t)} = u_i^{(t)} - \frac{1}{N-1}\sum_{j \neq i} u_j^{(t)} \quad \text{(instantaneous,与 Hughes 2018 [11] 对应)}$$

  合作-竞争张力从类型机制($\phi\psi$ 在 c 调制下的方向翻转)与资源时序动力学(留种 vs 竭泽)**两个正交通道**涌现。

- **上下文 $c_t$ 单通道调控**:仅通过资源再生率 $\alpha(c)$ 影响资源场动力学,**不**通过协同加成等瞬时支付通道引入合作激励——v3 版本中的 β(c) 协同加成被完全砍除,合作激励的责任完全交给类型 β 的 $\phi(c)\psi(\Delta_i)$ 社会偏好项。**记号说明**:Fehr-Schmidt 的劣势/优势反感参数本文写为 $\lambda_{\text{disadv}}, \lambda_{\text{adv}}$,以避免与资源再生率系数 $\alpha(c)$ 冲突。

- **Self Info 类型可观测设定**:自己的类型对自己可见(进入 role_i 通路),他人的类型对自己不可见(由 BeliefNet 的对手类型推断头 $\hat{z}_{i,j}$ 在线推断),与现实社会"我知道我是谁,但需要观察才能判断他人"的认知结构对应。

### 参数对照协议(Q4 加固版,`[v4-opt 2026-06]` 按断言 B′ 修订为双指标)

**断言 B′ 的硬验证依赖严格的对照实验设计**。生成范围谱上各变体的 HyperNet 参数量天然不等(film_head+LoRA ~694k ↔ full ~3.09M,Ch4.3.4),原"严格等参数量"声明不再适用,修订为:

- **加固 A(对齐范围,保留)**:功能网络通路(StateTransNet + RewardHead + PredictionNet 及其条件化机制)计入对照范围。BeliefNet、RepresentationNet、ContextEncoder 在所有 baseline 间完全共享、参数完全相同,不计入——避免稀释关键差异。

- **加固 B′(双指标报告,替代原"等参数量")**:每个变体报告两列独立指标——**HyperNet/条件化机制参数量**与**上下文相关子空间维度**(Ch4.1.2 谱表)。Input-Wide(加宽)与 Input-Deep(加深)对齐到预注册首选 cell(lora_fc2)的功能通路总参数;不做跨 gen_scope 的硬对齐(硬对齐在谱上会制造新的不公平)。仅当部分生成变体显著优于 Input-Wide 与 Input-Deep 两者时,断言 B′(i) 才算硬验证。

- **加固 C(μP 学习率对齐,保留)**:启用 Tensor Programs / μP (Yang & Hu, 2021) [41] 完整版本进行 hidden_dim scaling 时的学习率自动调整,并对每个 baseline 独立 LR sweep,取最佳 LR 再做主对比。这是顶会审稿标准的对照实验设计,确保参数对照不被优化动力学差异污染。

### 主对比配置标注

主对比固定为 **Medium 配置(N=4, 2α+2β)**,所有图表标题显式标注配置标签 "(N=4, 2α+2β, Medium)"。这是为了避免读者将"主对比的某个数字"误读为"算法的整体能力"——本文方法的性能依赖类型混合比例,这一依赖性本身是论文的核心发现之一,应当被显式而非隐式呈现。

## 贡献结构的内部一致性

四项贡献之间的关系如下:

```
贡献 1(问题形式化) ──┬─→ 贡献 2(双路超网络架构)
                       │       └─→ 贡献 4 消融 1, 2, 3
                       ├─→ 贡献 3(MVE+CRN 规划器)
                       │       └─→ 贡献 4 消融 4
                       └─→ 贡献 4(ResourceCommons 基准)
                               └─→ 主对比 + 零样本泛化 + 消融 5
```

贡献 1 是问题层面的开辟,贡献 2 与 3 是方法层面对该问题的回应,贡献 4 是实证验证。**每一项方法层贡献都至少绑定一个消融实验,确保贡献声明可证伪**。

**特别承诺**:贡献 2 的三个断言(A、B、C)与贡献 3 的断言 D 构成本文方法层贡献的完整可证伪集合——如果任一断言在第六章实验中未能成立,对应贡献需要降级或重新定位。这种**贡献-断言-实验**的硬绑定结构是本文方法论的核心承诺。
