# 第三章 ResourceCommons 环境设计(v4 最终版)

> **本章定位**:本章详细介绍本文为研究关系非平稳混合博弈(RNS-MMG)所构建的基准环境 ResourceCommons。该环境通过共享上下文变量 $c_t$ 单通道调控资源场动力学,并通过类型异质偏好(类型 α 纯自利 vs 类型 β Fehr-Schmidt 不平等厌恶 + φ 调制)使合作-竞争关系从偏好结构与资源动力学的交互中**涌现**,而非通过奖励工程显式指定。本章将完整定义环境的状态空间、动力学方程、类型机制、观测机制与奖励结构,并通过博弈论分析证明"纯自利物理 + 类型偏好结构"足以诱导合作-竞争的连续切换。
>
> **v4 关键演进**:相对 v3 版本,本章核心改动是(1)**砍除 v3 的 β(c) 协同采集加成系数**,采集量公式回归纯物理形式;(2)新增"3.5 类型机制与 Fehr-Schmidt 偏好"节,引入类型 α / 类型 β 异质偏好;(3)$c_t$ 双重含义降为单重含义(仅调控再生率);(4)观测函数加入 type_emb_i(Self Info 设定);(5)命题 3.1 重新论证,从"β 单调推 Gap"改为"类型偏好结构 + 资源时序动力学"双通道驱动。

## 3.1 设计哲学:从公地悲剧到涌现博弈

### 3.1.1 三条不可妥协的设计原则

在构建用于研究 RNS-MMG 的基准环境时,我们设立了三条**不可妥协的设计原则**,以确保环境既能严格反映第一章定义的问题特性,又能避免落入传统 mixed-motive 环境的常见陷阱。

**原则 I:物理层自利同构,偏好层显式异质,博弈涌现于交互**。

绝大多数现有的 mixed-motive 环境(如带 gifting 机制的 Cleanup [15]、带不平等厌恶奖励的迭代囚徒博弈 [11])通过**奖励工程**显式注入合作/竞争信号:为合作行为加分、为背叛行为减分。这种做法的根本问题在于,**博弈关系成为奖励函数的标签,而非环境的物理事实**——一旦换一组奖励权重,博弈结构就完全改变。

ResourceCommons 严格遵循**"物理层 + 偏好层"的二层分离**:

- **物理层**(资源场动力学 + 采集量公式 $u_{i,k} = \min(\eta_i, q_k/|H_{k,t}|)$):**完全自利同构**,所有 agent 的物理采集机制相同,无协同加成、无 gifting、无奖励重塑;
- **偏好层**(类型机制 + $\phi(c)\psi(\Delta)$):**显式异质**,类型 α 与类型 β 通过不同的偏好结构对物理采集量做不同的效用映射;
- **博弈关系**:从物理动力学与类型偏好的**交互**中涌现,合作或剥削作为最优策略响应,而不是被显式编码。

这一原则是 v4 相对 v3 的根本性升级。v3 中通过 β(c) 协同采集加成系数 $u_{i,k} \mapsto \eta_i[1 + \beta(c)(|H|-1)]$ 在物理层注入合作激励,严格地讲属于"按 c 切换的物理 reward shaping",违反原则 I。v4 砍除 β(c),物理层回归严格自利同构,合作激励的责任完全交给类型 β 的偏好结构。

**原则 II:上下文是环境状态,不是奖励标签**。

第一章的约束 (C3) 要求 $c_t$ 是真实物理状态,而非赋给奖励函数的标签。ResourceCommons 中,$c_t$ 直接对应于**全局资源再生强度**这一物理参数。它通过资源动力学方程影响 $r_k(t)$ 的演化,$r_k(t)$ 再通过"agent 在该点采集到多少资源"这一物理事实影响 $u_i$,$u_i$ 再通过类型 β 的 $\phi(c)\psi(\Delta)$ 进入偏好层。整条因果链上,$c_t$ 与奖励之间**只有间接通路**——$c_t$ → 资源场 → 物理采集量 → 偏好层效用。这与"把 c 直接作为 reward shaping 标签"形成本质区别。

**原则 III:物理转移上下文不变**。

第一章的约束 (C1) 要求 $P(s'|s,a)$ 不依赖于 $c$。在 ResourceCommons 中,这意味着:agent 的运动学(向北一步就是 $y$ 坐标加一)、动作执行的因果(执行"采集"动作就尝试采集)、碰撞规则(两个 agent 不能占据同一格)都**与 $c_t$ 无关**。$c_t$ 只通过资源再生方程影响"地里有多少资源",而不改变"agent 怎么走、怎么采"。

### 3.1.2 与公地悲剧的呼应

ResourceCommons 的命名直接致敬 Hardin 1968 的"公地悲剧"经典论文 [9],以及 Ostrom 1990 在《Governing the Commons》中对集体行动制度的研究 [16]。Hardin 指出,当多个自利个体共同使用一项可再生但容量有限的资源时,理性的自利行为会通向集体非理性的资源崩溃。Ostrom 则证明,某些社会机制(沟通、惩罚、产权)可以避免悲剧。

ResourceCommons 复现并扩展了这一经典张力:

- **同质纯自利场景**(全员类型 α):资源足够富时无干扰,资源稀缺时陷入零和争抢——这是 Hardin 经典悲剧的直接复现;
- **异质偏好场景**(类型 α + 类型 β 共存):类型 β 的 Fehr-Schmidt 不平等厌恶 + φ 调制在丰年表现为协同合作、在荒年表现为激进追赶,这与 Ostrom 对"社群规范成员"的描述高度对应——一部分人受社群规范约束,在丰年贡献合作、在荒年表现出对落后的不能容忍。

合作-竞争的连续切换由共享变量 $c_t$ 与类型机制共同调控,且**不需要任何瞬时支付层面的合作奖励**——它纯粹由资源动力学与偏好结构的交互决定。

## 3.2 环境的形式化定义

ResourceCommons 是 RNS-MMG 框架的具体实例,定义为元组

$$\mathcal{E}_{\text{RC}} = \langle N,\;\mathcal{G},\;\mathcal{R},\;\mathcal{T},\;\mathcal{S},\;\{\mathcal{A}_i\},\;P,\;\{R_i\},\;\{O_i\},\;\mathcal{C},\;P_c,\;\rho_c,\;\rho_\tau,\;T_{\max},\;\gamma \rangle$$

**与 v3 的差异**:新增类型集合 $\mathcal{T} = \{\alpha, \beta\}$ 与类型分布 $\rho_\tau$。其中各组成部分的物理含义如下:

### 3.2.1 智能体、世界结构与类型集合

- **$N$**:智能体数量。基础设置 $N = 4$,扩展实验中考察 $N \in \{2, 4, 8\}$。
- **$\mathcal{G} = \{0, 1, \ldots, L-1\}^2$**:$L \times L$ 的二维方格世界。基础设置 $L = 16$。
- **$\mathcal{R} = \{r_1, r_2, \ldots, r_K\}$**:固定的 $K$ 个资源点的位置集合,$r_k \in \mathcal{G}$。基础设置 $K = 20$。资源点位置在 episode 开始时按斑块化策略生成(详见 3.3.2 节),在 episode 内不移动。
- **$\mathcal{T} = \{\alpha, \beta\}$**:类型集合。每个 agent $i$ 在 episode 开始时按分布 $\rho_\tau$ 分配类型 $\tau_i \in \mathcal{T}$,episode 内类型固定不变。基础设置 $\rho_\tau$ 实现为 "2α + 2β" 固定分配(详见 3.5 节)。

### 3.2.2 状态空间

联合物理状态 $s_t \in \mathcal{S}$ 由以下组件构成:

$$s_t = \bigl(\;\{p_{i,t}\}_{i=1}^N,\;\{q_{k,t}\}_{k=1}^K,\;\{U_{i,t}\}_{i=1}^N,\;c_t,\;\{\tau_i\}_{i=1}^N\;\bigr)$$

- **agent 位置** $p_{i,t} \in \mathcal{G}$:智能体 $i$ 在时刻 $t$ 的格点位置;
- **资源存量** $q_{k,t} \in [0, Q_{\max}]$:资源点 $k$ 当前的可采资源量,$Q_{\max}$ 为单点存量上限(默认 10);
- **累积采集量** $U_{i,t} = \sum_{s \leq t} u_{i,s}$:智能体 $i$ 截至时刻 $t$ 的累积采集量。**注**:此项纳入状态主要是为了观测函数与负载容量 $\zeta_i$ 检查,**类型 β 的偏好项 $\psi(\Delta_i^{(t)})$ 使用 instantaneous $\Delta_i$ 而非 cumulative**(详见 3.5.2 节);
- **共享上下文** $c_t \in [0, 1]$:本 episode 的全局资源丰度参数(详见 3.4 节);
- **类型向量** $\{\tau_i\}$:agent 类型分配,episode 内固定。

### 3.2.3 动作空间

每个智能体的动作空间为 $\mathcal{A}_i = \{0, 1, 2, 3, 4, 5\}$,对应六个原子动作:

| 动作编号 | 含义 |
|---|---|
| 0 | NOOP(停留) |
| 1 | UP(北移一格) |
| 2 | DOWN(南移一格) |
| 3 | LEFT(西移一格) |
| 4 | RIGHT(东移一格) |
| 5 | HARVEST(尝试采集当前格资源) |

联合动作空间 $\mathcal{A} = \prod_{i=1}^N \mathcal{A}_i = 6^N$。在基础设置 $N = 4$ 下,$|\mathcal{A}| = 1296$,这正是第五章 Per-Agent Coordinate Descent MVE 所要解决的组合爆炸来源之一。

### 3.2.4 转移函数 $P$

$P(s_{t+1} \mid s_t, \mathbf{a}_t)$ 分解为四个相互独立的子转移:

$$P\;=\;\underbrace{P_{\text{pos}}\bigl(\{p_{i,t+1}\} \mid \{p_{i,t}\},\;\mathbf{a}_t\bigr)}_{\text{agent 运动}} \;\cdot\; \underbrace{P_{\text{res}}\bigl(\{q_{k,t+1}\} \mid s_t,\;\mathbf{a}_t\bigr)}_{\text{资源演化}} \;\cdot\; \underbrace{P_U(\{U_{i,t+1}\} \mid \{U_{i,t}\}, \mathbf{a}_t, s_t)}_{\text{累积量更新}} \;\cdot\; \underbrace{P_c\bigl(c_{t+1} \mid c_t\bigr)}_{\text{上下文演化}}$$

类型 $\{\tau_i\}$ 在 episode 内固定,不进入转移函数。

**关键性质**:$P_{\text{pos}}$ 与 $c_t$ **无关**(运动学不变),$P_{\text{res}}$ 与 $c_t$ 有关(资源动力学受丰度调控),$P_U$ 仅是 $u_{i,t}$ 的累加,$P_c$ 与 agent 动作无关(满足约束 C3 的不可控性)。详见 3.3 节(资源动力学)与 3.4.3 节($P_c$)。

## 3.3 资源场动力学

### 3.3.1 离散时间动力学方程

资源点 $k$ 的存量演化采用如下离散时间动力学:

$$q_{k,t+1} \;=\; \mathrm{clip}\!\left(\;q_{k,t} \;-\; \underbrace{\sum_{i \in \mathcal{H}_{k,t}} u_{i,k,t}}_{\text{消耗项}} \;+\; \underbrace{\alpha(c_t)\;\cdot\;f(\mathbf{q}_{\mathcal{N}(k),t})\;\cdot\;(Q_{\max} - q_{k,t})}_{\text{再生项}},\;\;0,\;Q_{\max}\;\right) \tag{3.1}$$

各项含义如下:

**消耗项 $\sum_{i \in \mathcal{H}_{k,t}} u_{i,k,t}$**:

- $\mathcal{H}_{k,t} = \{i : p_{i,t} = r_k \;\land\; a_{i,t} = \text{HARVEST}\}$ 是时刻 $t$ 在资源点 $k$ 上执行采集动作的智能体集合;
- $u_{i,k,t}$ 是智能体 $i$ 在时刻 $t$ 从资源点 $k$ 实际采集到的资源量,其计算见 3.3.3 节(**v4 中已无协同加成**,仅由公平共享上限决定)。

**再生项 $\alpha(c_t) \cdot f(\mathbf{q}_{\mathcal{N}(k),t}) \cdot (Q_{\max} - q_{k,t})$** 由三个因子相乘:

- **$(Q_{\max} - q_{k,t})$**:**存量越接近上限,边际再生越慢**,这是 logistic 增长的标准建模,防止资源无限累积;
- **$f(\mathbf{q}_{\mathcal{N}(k),t})$**:**邻居影响因子**,引入空间外部性(详见 3.3.4 节);
- **$\alpha(c_t)$**:**全局再生率系数**,由共享上下文 $c_t$ 调控(详见 3.4.1 节)。**v4 中这是 $c_t$ 对环境物理的唯一作用通道**。

### 3.3.2 资源点的空间分布(斑块化生成)

为实现"斑块化(patchy)分布",资源点位置在 episode 开始时按以下两步生成:

**步骤 1:Hotspot 中心采样**。 在 $\mathcal{G}$ 上独立均匀采样 $M$ 个中心点 $\{m_1, \ldots, m_M\}$,默认 $M = 3$(三个 hotspot)。

**步骤 2:资源点围绕中心生成**。 对每个 hotspot,以中心为基准,按各向同性高斯 $\mathcal{N}(m_j,\;\sigma_{\text{patch}}^2 I)$ 采样 $K/M$ 个候选位置,四舍五入到最近格点;若位置已被占用或越界则重采样,直到生成 $K$ 个不重合的资源点。默认 $\sigma_{\text{patch}} = 2.0$。

**生成结果的统计性质**:同一 hotspot 内的资源点空间临近(均距约 $1.5\sigma_{\text{patch}}$),不同 hotspot 之间相距较远。这造成两个博弈学层面的后果:

1. **同一 hotspot 内的资源点通过 3.3.4 节的邻居影响因子产生强空间外部性**——一个被采空,周围再生也会变慢,这鼓励"留种"行为;
2. **不同 hotspot 之间的争夺成为空间策略的核心**——智能体必须在多个 hotspot 间选择并迁移,而非简单地"原地等再生"。

### 3.3.3 采集动作与物理采集量(v4 简化版)

当智能体 $i$ 在时刻 $t$ 选择 HARVEST 动作且位于资源点 $k$ 时,其物理采集量为:

$$u_{i,k,t} \;=\; \min\!\Bigl(\;\eta_i,\;\;q_{k,t} \,/\, |\mathcal{H}_{k,t}|\;\Bigr) \tag{3.2}$$

各项含义如下:

- **$\eta_i$**:智能体 $i$ 的**单步采集能力**,是 agent 异质能力向量的一部分(详见 3.6 节),典型取值 $\eta_i \sim \mathcal{U}(0.5,\;1.5)$;
- **$|\mathcal{H}_{k,t}|$**:同时在 $k$ 点采集的智能体数量;
- **$q_{k,t} / |\mathcal{H}_{k,t}|$**:**公平共享上限**,确保多人采集时单点不会被超额采空(物理可行性约束)。

**与 v3 的差异**:v3 公式 (3.2) 中包含协同加成项 $[1 + \beta(c_t)(|\mathcal{H}_{k,t}|-1)]$,v4 完全砍除该项。理由:

1. **方法学纯粹性**:协同加成是物理层的合作激励注入,违反原则 I 的"物理层自利同构";
2. **职责清晰化**:合作-竞争激励完全由偏好层的类型 β 与 $\phi(c)\psi(\Delta)$ 承担,环境物理层只负责"一块资源就这么多,n 个人采每人分 1/n"这一不可争议的物理事实;
3. **实验信号清晰化**:类型 α 与 β 在共享物理机制下的行为差异完全归因于偏好差异,断言 A(类型梯度撕裂)的实验证据更干净。

**物理采集量的行为解读**:

- $|\mathcal{H}_{k,t}| = 1$ 时,$u = \min(\eta_i, q_{k,t}) = \eta_i$(假设 $q_k > \eta_i$),单人独占采集;
- $|\mathcal{H}_{k,t}| = n > 1$ 时,**资源被均分**:$u = \min(\eta_i, q_{k,t}/n) = q_{k,t}/n$(假设 $\eta_i > q_{k,t}/n$),无任何合作放大效应。

这意味着在物理层,多人共采**严格降低**每人的瞬时采集量(与单人独占相比),合作行为在物理层**不被奖励**。任何合作激励必须从类型 β 的偏好结构中涌现。

### 3.3.4 邻居影响因子

邻居影响因子 $f(\mathbf{q}_{\mathcal{N}(k),t})$ 通过资源点间的空间耦合引入生态学意义上的"留种"机制:

$$f(\mathbf{q}_{\mathcal{N}(k),t}) \;=\; \sigma\!\left(\;\kappa_f \cdot \frac{1}{|\mathcal{N}(k)|}\sum_{k' \in \mathcal{N}(k)} \frac{q_{k',t}}{Q_{\max}}\;-\;\theta_f\;\right) \tag{3.3}$$

其中:
- **$\mathcal{N}(k)$** 是资源点 $k$ 的邻居集合,定义为距离 $k$ 不超过 $d_{\text{nbr}} = 3$ 格的其他资源点;
- **$\sigma(\cdot)$** 是 sigmoid 函数;
- **$\kappa_f = 6.0$、$\theta_f = 0.3$** 是固定超参数(下标 $f$ 区分于类型 β 偏好中的 $\kappa$),使得当邻居平均归一化存量 $\geq 30\%$ 时 $f \approx 1$,当邻居被采空时 $f$ 衰减到 $\approx 0.1$。

**记号注**:这里的 $\kappa_f, \theta_f$ 是邻居因子的内部参数,与第 3.5 节类型 β 偏好中的 $\kappa$(φ 调制系数)是不同的量,请按下标区分。

**生态学解读**:邻居资源点的高存量保证了"种群健康度",该点的再生速率得以维持;邻居被全数采空时,即使本点存量未变,再生也会显著放缓——这模拟了生态系统中"周边种群崩溃导致核心种群繁殖率下降"的现象。

**对类型 β 偏好的间接影响**:留种行为在物理层不被瞬时奖励,但通过邻居因子在时序上回报——保留高存量邻居 → 维持高再生 → 长期可采量更高。这一时序机制在类型 α 下需要长期价值函数学习来捕捉,在类型 β 下被偏好结构进一步放大(因为 β 在丰年偏好均衡合作,与"留种"行为一致)。

### 3.3.5 动力学的稳定性条件

为防止资源场出现数值发散或退化,基础参数选择需满足:

**条件 1(单步消耗上限)**:$N \cdot \max_i \eta_i \leq Q_{\max}$,确保单点的极限消耗不会超过单点容量。基础设置下:$4 \times 1.5 = 6 < Q_{\max} = 10$,**v4 砍除协同加成后该条件自然满足**,无需额外的公平共享触发。但公式 (3.2) 中的公平共享上限项仍保留,作为防御性约束。

**条件 2(再生速率上限)**:$\alpha_{\max} \leq 0.2$,确保最快情况下也需多步才能填满空槽,避免"采完瞬间满血"。

**v3 中的"协同加成上限"条件已不适用**——v4 中无 β(c) 项。

## 3.4 共享上下文 $c_t$ 的作用(单通道版)

### 3.4.1 唯一作用通道:再生率调控 $\alpha(c)$

$$\alpha(c_t) \;=\; \alpha_{\min} + (\alpha_{\max} - \alpha_{\min}) \cdot c_t \tag{3.4}$$

基础参数:$\alpha_{\min} = 0.02$,$\alpha_{\max} = 0.20$。

**单调性**:$\alpha(c)$ 是 $c$ 的严格单调递增线性函数。$c_t = 0$ 时(荒年),$\alpha = 0.02$,资源再生缓慢,采空一点需约 50 步才能恢复;$c_t = 1$ 时(丰年),$\alpha = 0.20$,资源再生迅速,约 5 步即可恢复。

**与 v3 的差异**:v3 中 $c_t$ 通过 $\alpha(c)$ 与 $\beta(c)$ 两个通道作用,v4 砍除 $\beta(c)$,$c_t$ 对环境物理的唯一作用通道仅剩 $\alpha(c)$。这一简化:

1. **职责更清晰**:$c_t$ 严格对应"资源再生强度"这一单一物理量,符合原则 II 的"上下文是环境状态"语义;
2. **合作-竞争激励的来源更纯粹**:不再依赖人为指定的 $\beta(c)$ 形状,而是由资源时序动力学 + 类型 β 偏好共同涌现;
3. **实验信号的归因更干净**:消融 5(Fehr-Schmidt 参数敏感性)扫描 $\kappa$ 与 $\lambda_{\text{disadv}}$ 时,$c_t$ 通路的作用保持不变,结果可解释性增强。

### 3.4.2 合作-竞争激励的双通道涌现

砍除 β(c) 后,合作-竞争激励通过两个**正交通道**涌现:

**通道 1:资源时序动力学(对所有类型生效)**

公式 (3.1) 中的再生项与公式 (3.3) 中的邻居因子共同导致:**留种行为在多步时序中带来高累积收益**。这一通道对类型 α 与类型 β 都生效——任何理性 agent 在长期价值函数指引下都应学习留种。但类型 α 的"理性留种"完全由 RL 价值传播驱动,需要充分训练才能学到;类型 β 的"偏好驱动留种"在丰年由 $\phi < 0$ 翻转的 Fehr-Schmidt 偏好直接激励(详见 3.5 节)。

**通道 2:类型 β 的 Fehr-Schmidt 偏好(仅类型 β 生效)**

类型 β 通过 $\phi(c)\psi(\Delta_i)$ 项,在 c 高时偏好均衡共采(合作)、在 c 低时极度厌恶被甩开(剥削/激进追赶)。这一通道**绕过资源动力学的时序传播**,直接在瞬时偏好层激励合作或剥削行为。

**两通道的正交性**:通道 1 关注"留种 vs 竭泽"的时序选择,通道 2 关注"与他人的相对位置"的瞬时比较;两者在博弈空间上正交,可以独立消融。消融实验(第六章)将分别关闭两通道(纯类型 α + 无邻居因子的简化版本)验证各自的贡献。

### 3.4.3 $c_t$ 的演化模式

ResourceCommons 提供三种 $c_t$ 演化模式:

**模式 A:Episode 静态(基础模式)**。 $c_t \equiv c_0$,其中 $c_0 \sim \rho_c = \mathcal{U}([0, 1])$ 在 episode 开始时采样,episode 内保持不变。**用途**:主要训练与评估模式,验证算法在不同 $c$ 值下的策略适应能力。

**模式 B:周期性演化(振荡模式)**。 $c_{t+1} = 0.5 + 0.5\sin(2\pi t / T_{\text{period}})$,$T_{\text{period}} = 50$。**用途**:验证算法处理周期性环境节律的能力(如季节变化)。

**模式 C:随机游走(冲击模式)**。 $c_{t+1} = \mathrm{clip}(c_t + \mathcal{N}(0, 0.05^2),\;0,\;1)$,且每 50 步以概率 0.2 注入大幅冲击 $\Delta c \sim \mathcal{U}(-0.3, 0.3)$。**用途**:验证算法的在线适应能力(对应 BeliefNet 的核心考验场景)。

**关键性质**:三种模式下,$c_t$ 的演化均**与 agent 动作无关**(满足约束 C3 的不可控性),只依赖于环境的内禀机制。

## 3.5 类型机制与 Fehr-Schmidt 偏好(v4 新增节)

> **本节定位**:本节定义 v4 引入的核心新机制——agent 类型异质性。类型 α 与类型 β 共享相同的物理采集机制(公式 3.2),但通过不同的偏好结构对 $u_i$ 做不同的效用映射,从而产生 4.1.1 节展示的"梯度方向相反"现象。本节是 Chapter 1.5 贡献 4 与 Chapter 4.1.1 偏导对照表的环境侧落地。

### 3.5.1 类型集合与分配机制

类型集合 $\mathcal{T} = \{\alpha, \beta\}$:

- **类型 α(纯自利,Selfish)**:奖励函数为纯物理采集量,无任何社会偏好项;
- **类型 β(社会条件型,Socially-Conditioned)**:奖励函数为物理采集量加上 Fehr-Schmidt 不平等厌恶项,且不平等厌恶强度由 $c_t$ 调制。

**类型分配机制**:每个 agent $i$ 在 episode 开始时按类型分布 $\rho_\tau$ 分配类型 $\tau_i$,**episode 内固定不变**。

**默认分配协议(主对比配置)**:$N=4$ 下固定为 **2α + 2β**(agent 0 与 agent 1 为类型 α,agent 2 与 agent 3 为类型 β)。这一固定分配的理由:

1. **断言 A 信号最强**:50/50 混合在钟形曲线峰值附近,DualHyperNetwork 相对共享 RewardHead 的优势最显著(详见 Chapter 1.5 断言 A);
2. **消融可控**:固定分配避免类型随机化引入的额外方差,seed 间结果更稳定;
3. **图表标注强制规范**:所有主对比图表标题必须显式标注 "(N=4, 2α+2β, Medium)",防止读者误读为"算法的整体能力"。

**消融扫描配置**:第六章消融 3 扫描类型 β 比例 $\in \{0, 1/4, 2/4, 3/4, 4/4\}$ 五个数据点,加上 **1α+3β** 额外对照点(共 6 个数据点),用于检测峰值位置是否对称——若曲线偏向 α-多侧,则揭示"DualHyperNetwork 优势 = 类型异质 + 类型学习难度差异"的具体组合,作为正向发现报告。

### 3.5.2 类型 α 的奖励函数

类型 α 的奖励函数完全自利,无任何社会偏好项:

$$R_i^\alpha(s_t,\;\mathbf{a}_t) \;=\; \sum_{k} u_{i,k,t} \;-\; \epsilon \cdot \mathbb{1}[a_{i,t} \in \{\text{UP, DOWN, LEFT, RIGHT}\}] \tag{3.5}$$

其中 $\epsilon = 0.01$ 是微小的移动代价(防止 agent 随意瞎转),$\sum_k u_{i,k,t}$ 在任何时刻最多只有一项非零(agent 在某一格上)。

**梯度结构**:$\partial R^\alpha / \partial u_i = +1$,恒为正常数,所有 $c$ 区段相同。这是 Chapter 4.1.1 节偏导对照表中类型 α 列的来源。

### 3.5.3 类型 β 的奖励函数(Fehr-Schmidt + φ 调制)

类型 β 的奖励函数在物理采集量基础上加上 Fehr-Schmidt 不平等厌恶项,且该项强度由 $\phi(c_t)$ 调制:

$$R_i^\beta(s_t,\;\mathbf{a}_t) \;=\; \underbrace{\sum_{k} u_{i,k,t} \;-\; \epsilon \cdot \mathbb{1}[\text{moved}]}_{\text{物理项,与类型 α 相同}} \;+\; \underbrace{\phi(c_t) \cdot \psi(\Delta_i^{(t)})}_{\text{Fehr-Schmidt 偏好项}} \tag{3.6}$$

其中 Fehr-Schmidt 偏好项的各成分定义如下:

**φ 调制函数**:

$$\phi(c_t) \;=\; \kappa \cdot (1 - 2 c_t) \tag{3.7}$$

基础参数 $\kappa = 0.5$。**单调性与方向翻转**:

- $c_t = 0$(荒年):$\phi(0) = +\kappa = +0.5$,Fehr-Schmidt 不平等厌恶被放大;
- $c_t = 0.5$(中性):$\phi(0.5) = 0$,Fehr-Schmidt 项归零,类型 β 退化为纯自利;
- $c_t = 1$(丰年):$\phi(1) = -\kappa = -0.5$,Fehr-Schmidt 项翻转方向。

**Fehr-Schmidt 不对称分段函数**:

$$\psi(\Delta) \;=\; -\bigl[\,\lambda_{\text{disadv}} \cdot \max(0,\,-\Delta) \;+\; \lambda_{\text{adv}} \cdot \max(0,\,\Delta)\,\bigr] \tag{3.8}$$

基础参数 $\lambda_{\text{disadv}} = 2.0$,$\lambda_{\text{adv}} = 0.6$(Fehr-Schmidt 1999 [40] 经典值)。**关键不对称性**:$\lambda_{\text{disadv}} > \lambda_{\text{adv}}$,即"对劣势的反感强于对优势的反感"。

**Instantaneous 不平等差 $\Delta_i^{(t)}$**:

$$\Delta_i^{(t)} \;=\; u_{i,t} \;-\; \frac{1}{N-1}\sum_{j \neq i} u_{j,t} \tag{3.9}$$

其中 $u_{i,t} = \sum_k u_{i,k,t}$ 是 agent $i$ 在时刻 $t$ 的瞬时采集量(0 或某资源点的实际采集量)。**注意是 instantaneous,不是 cumulative**——按 Hughes 2018 [11] 的 per-step Fehr-Schmidt 形式,与 Chapter 4.1.1 节的偏导推导对应。

**记号警告**:$\lambda_{\text{disadv}}, \lambda_{\text{adv}}$ 是 Fehr-Schmidt 的劣势/优势反感系数,**与资源再生率 $\alpha(c)$ 和邻居因子的 $\kappa_f, \theta_f$ 是完全不同的量**。本文统一用 $\lambda$ 系列符号表示 Fehr-Schmidt 偏好参数,$\kappa$ 表示 φ 调制系数,$\alpha(c)$ 表示再生率系数,$\kappa_f, \theta_f$ 表示邻居因子参数。读者请按下标与上下文区分。

### 3.5.4 类型 β 在四种 c × Δ 场景下的瞬时奖励分析

将 (3.6)-(3.9) 代入,可得到类型 β 在四种典型场景下的 Fehr-Schmidt 项数值(假设 $|\Delta| = 1$ 作为单位):

| 场景 | $\phi(c)$ | $\Delta$ 符号 | $\psi(\Delta)$ | Fehr-Schmidt 项 $\phi\psi$ | 总奖励对 $u_i$ 变化的敏感性 |
|---|---|---|---|---|---|
| 荒年 + 自己优势 | $+0.5$ | $+1$ | $-0.6$ | $-0.3$ | 自己采得多反而扣 0.3,β 偏好均衡 |
| 荒年 + 自己劣势 | $+0.5$ | $-1$ | $-2.0$ | $-1.0$ | 自己采得少扣 1.0,β 强烈想追赶 |
| 丰年 + 自己优势 | $-0.5$ | $+1$ | $-0.6$ | $+0.3$ | 自己采得多反而加 0.3,β 不再约束领先 |
| 丰年 + 自己劣势 | $-0.5$ | $-1$ | $-2.0$ | $+1.0$ | 自己采得少反而加 1.0,β 在丰年偏好他人多采 |

**关键洞察**:

1. **荒年 + 自己劣势**(场景 2):Fehr-Schmidt 项扣 1.0,这意味着 agent 增加 $u_i$ 一单位会**同时**得到物理项 +1 和减少 Fehr-Schmidt 损失 +1(从 -1.0 移向 0),**总边际效用 = 2.0**,是类型 α 的 2 倍。**β 在荒年的劣势状态下产生异常强的"追赶"激励**,行为表现为剥削/激进追赶。

2. **丰年 + 自己劣势**(场景 4):Fehr-Schmidt 项加 1.0(因为自己劣势对应 β 喜欢的状态),agent 增加 $u_i$ 一单位会得到物理项 +1 但减少 Fehr-Schmidt 加成 -1(从 +1.0 移向 0),**总边际效用 = 0**。**β 在丰年的劣势状态下完全没有自己采集的激励**,行为表现为协同合作(让他人采得多,自己作为辅助)。

3. **中性 c = 0.5**:$\phi = 0$,所有 Fehr-Schmidt 项归零,类型 β 退化为纯自利,与类型 α 行为一致。

这一表格是 Chapter 4.1.1 节"瓶颈 1 类型梯度撕裂"偏导对照表的环境侧具体化版本,定量证明了"不同类型在同一物理状态下奖励梯度方向相反"的现象。

### 3.5.5 偏好不变,行为涌现:与方法学原则的对应

本节定义的类型机制严格遵循 Chapter 4.1.5 节方法学原则:

- **不变项**:Fehr-Schmidt 不平等厌恶结构 $\psi(\Delta)$ 在所有 $c$ 区段保持不变;$\lambda_{\text{disadv}}, \lambda_{\text{adv}}$ 在所有 episode 保持不变;
- **变化项**:不平等厌恶的强度与方向由 $\phi(c)$ 调制,但 $\phi$ 本身是环境 $c$ 的确定性函数,不依赖 agent 行为;
- **涌现项**:荒年表现为剥削/激进追赶、丰年表现为协同合作——这两种行为模式**不是被显式编码到奖励函数中**,而是 RL 在偏好空间中找到的最优响应。

**与"丰年合作激活,荒年剥削激活"的语义统一**:类型 β 的心理偏好结构在所有 $c$ 区段都是 inequity-averse 的(Fehr-Schmidt 1999 标准定义),只是不平等厌恶在 c 低时被放大、c 高时被翻转;行为现象上,放大的 inequity aversion 在荒年劣势状态下表现为激进追赶(看似剥削),翻转的 inequity aversion 在丰年表现为对他人收益的偏好(看似合作)。这种"心理偏好不变 + 行为涌现"的设计与 Hughes 2018 [11]、Charness & Rabin 2002 [45] 等不平等厌恶文献的标准框架一致。

## 3.6 异质智能体能力

### 3.6.1 能力向量的定义

每个智能体 $i$ 拥有一个**固定的能力向量** $\mathbf{cap}_i \in \mathbb{R}^4$,在 episode 开始时采样并在 episode 内保持不变:

$$\mathbf{cap}_i = (\;\eta_i,\;\phi^{\text{fov}}_i,\;\nu_i,\;\zeta_i\;)$$

| 能力维度 | 符号 | 物理含义 | 采样分布 |
|---|---|---|---|
| 采集速度 | $\eta_i$ | 单步可采集资源量 | $\mathcal{U}(0.5, 1.5)$ |
| 视野范围 | $\phi^{\text{fov}}_i$ | 局部观测的视野半径(格数) | $\mathcal{U}(2, 4)$,四舍五入到整数 |
| 移动速度 | $\nu_i$ | 单步移动概率(< 1 时移动失败) | $\mathcal{U}(0.8, 1.0)$ |
| 负载容量 | $\zeta_i$ | 累积采集上限(超过则禁用 HARVEST) | $\mathcal{U}(10, 30)$ |

**记号说明**:视野范围本文写为 $\phi^{\text{fov}}_i$ 以与 3.5 节的 φ 调制函数 $\phi(c)$ 区分。这是 v4 引入的记号调整,v3 中视野范围直接写为 $\phi_i$,与新引入的 φ 调制函数撞符号,故加上下标。

### 3.6.2 能力的双重作用

异质能力在两个层面影响博弈结构:

**层面 1:策略空间的塑造**。 $\eta_i$ 高的 agent 单步产出多,倾向于积极采集;$\phi^{\text{fov}}_i$ 大的 agent 视野广,更适合探索远距离 hotspot;$\nu_i$ 低的 agent 移动不稳定,倾向于守在富资源区域。**这些异质性使最优策略 $\pi_i^*$ 在 agent 间天然分化**——这是 Chapter 4.1.3 节辅层 2(瓶颈 3 角色平均化)的环境侧来源。

**层面 2:类型 × 能力的交叉异质性**。 v4 中,agent 的"身份"由 (类型 $\tau_i$, 能力 $\mathbf{cap}_i$) 联合决定:类型 α 的快采集者(高 $\eta$)倾向于贪婪垄断、类型 β 的快采集者倾向于在丰年带队合作、在荒年与他人维持均衡;同样,类型 α 的宽视野者擅长发现资源、类型 β 的宽视野者擅长发现"被甩开"的劣势状态从而触发追赶。**类型与能力的乘积异质性使最优策略空间维度增加一倍**,这进一步放大了共享 PredictionNet 的容量瓶颈。

### 3.6.3 能力的可观测性

异质能力对**自身**完全可观测(agent 知道自己的 $\mathbf{cap}_i$,进入观测块 $o_i^{\text{capability}}$);对**他人**仅部分可观测——其他 agent 的能力需要通过观测他们的行为序列**推断**,这与第四章 BeliefNet 中对手类型推断头 $\hat{z}_{i,j}$ 的设计动机一致(尽管 $\hat{z}$ 主要推断类型而非能力,但能力作为类型实施的载体也被间接覆盖)。

## 3.7 观测函数与部分可观测性(Self Info 设定)

### 3.7.1 单 agent 观测结构

智能体 $i$ 在时刻 $t$ 的观测 $o_i^t \in O_i$ 是一个结构化向量,由以下**六块**组成(v3 五块基础上新增 $o_i^{\text{type}}$):

$$o_i^t \;=\; \bigl[\;o_i^{\text{self}},\;o_i^{\text{resource}},\;o_i^{\text{neighbor}},\;o_i^{\text{global}},\;o_i^{\text{capability}},\;o_i^{\text{type}}\;\bigr]$$

| 观测块 | 内容 | 维度 |
|---|---|---|
| $o_i^{\text{self}}$ | 自身位置 $p_{i,t}$、累积采集量 $U_{i,t}$、距离上次采集的步数 | 4 |
| $o_i^{\text{resource}}$ | **视野内**所有资源点的相对位置 $(\Delta x, \Delta y)$ 与归一化存量 $q_k / Q_{\max}$ | 视野内点数 $\times$ 3,填零至 $K$ |
| $o_i^{\text{neighbor}}$ | **视野内**所有其他 agent 的相对位置与上一步动作 one-hot | 视野内 agent 数 $\times$ 9,填零至 $N-1$ |
| $o_i^{\text{global}}$ | 当前 $c_t$、剩余时间步数比例 | 2 |
| $o_i^{\text{capability}}$ | 自身能力向量 $\mathbf{cap}_i$ | 4 |
| $o_i^{\text{type}}$(**v4 新增**) | 自身类型 one-hot $\mathbb{1}[\tau_i = \alpha], \mathbb{1}[\tau_i = \beta]$ | 2 |

**Self Info 设定的体现**:$o_i^{\text{type}}$ **只包含自己的类型**,不包含他人类型——这正是 Chapter 1.5 贡献 4 与 Chapter 4.1.4 节 Harsanyi 对应表中 "Own Type" 通路的环境侧实现。他人类型对 agent 不可见,必须由 BeliefNet 在第四章通过对手类型推断头 $\hat{z}_{i,j}$ 推断。

### 3.7.2 视野机制

视野范围 $\phi^{\text{fov}}_i$ 是 agent $i$ 的异质能力之一,其作用为:

- agent $i$ 只能观测到距离自己 $\leq \phi^{\text{fov}}_i$ 格(切比雪夫距离)的资源点与其他 agent;
- 视野外的对象在 $o_i^{\text{resource}}$ 与 $o_i^{\text{neighbor}}$ 中以"零向量 + 不存在标志"填充。

**部分可观测的博弈学后果**:agent 必须**主动探索**才能发现 hotspot 的全貌;**对手位置的不确定性**直接对应了 BeliefNet 对手推断的必要性。

### 3.7.3 $c_t$ 的可观测性

按第一章约束 (C3) 的要求,$c_t$ 是物理状态,**部分可观测**。ResourceCommons 默认设置中,$c_t$ 在 $o_i^{\text{global}}$ 中**完全可见**——这看似与"部分可观测"矛盾,但实际上反映了"环境信号显式标志"的现实情形(如气象预报、市场指数)。

为支持更严格的部分可观测实验,环境提供**"$c_t$ 隐藏模式"**:将 $o_i^{\text{global}}$ 中的 $c_t$ 替换为常数,agent 必须从资源场的演化模式中**推断**当前丰度——这正是第四章 BeliefNet 的核心检验场景。BeliefNet 的 $\hat{c}_i^t$ 推断头在 $c_t$ 隐藏模式下被严格监督训练。

### 3.7.4 类型可观测性的方法学说明

Self Info 设定(自己类型可见,他人类型不可见)是本文的核心实验设定,其方法学基础如下:

- **现实对应性**:与人类社会"我知道我是谁,但需要观察才能判断他人"的认知结构对应;
- **博弈论对应性**:严格对应 Harsanyi 不完全信息博弈中"自己的 type 已知 + 对他人 type 的分布信念" 的标准设定;
- **架构意义**:对应第四章 role_i 通路(自己类型进入 type_emb)与 belief_i 通路(他人类型由 $\hat{z}_{i,j}$ 推断)的分工,这是 4.1.4 节 Harsanyi 表格的环境侧前提。

第六章实验中,所有主对比与消融实验均在 Self Info 设定下进行;附录会报告 "Full Info"(他人类型可见)与 "Hidden Info"(自己类型不可见)两个边界设定的对照,作为 robustness check。

## 3.8 自利物理 + 异质偏好的形式化分析

### 3.8.1 完整奖励函数的统一形式

按 3.5.2 与 3.5.3 节,智能体 $i$ 在时刻 $t$ 的瞬时奖励统一写为:

$$R_i(s_t,\;\mathbf{a}_t;\;\tau_i) \;=\; \underbrace{u_{i,t} \;-\; \epsilon \cdot \mathbb{1}[\text{moved}]}_{\text{所有 agent 共有的物理项}} \;+\; \underbrace{\mathbb{1}[\tau_i = \beta] \cdot \phi(c_t) \cdot \psi(\Delta_i^{(t)})}_{\text{仅类型 β 触发的 Fehr-Schmidt 项}} \tag{3.10}$$

其中 $u_{i,t} = \sum_k u_{i,k,t}$,$\mathbb{1}[\tau_i = \beta]$ 是类型指示函数。

**关键观察**:

1. **物理项对所有类型相同**:$u_{i,t}$ 完全只依赖于 agent $i$ 自身采集到的资源量,不包含任何关于其他 agent 收益或全局福利的项——原则 I 的"物理层自利同构"严格成立;
2. **Fehr-Schmidt 项仅类型 β 触发**:$\mathbb{1}[\tau_i = \beta]$ 是类型 α 与类型 β 唯一的奖励差异来源,且该项是**偏好层**而非物理层的;
3. **梯度撕裂的来源**:对相同的 $(s, a)$,类型 α 的奖励梯度 $\partial R^\alpha/\partial u_i = 1$,类型 β 的梯度受 $\phi(c)\psi(\Delta)$ 调制,在 4.1.1 节偏导表中可取 0 到 2 之间不同值——这是 Chapter 4.1.1 节断言 A 在环境侧的来源。

### 3.8.2 涌现博弈的形式化命题(v4 重写)

我们证明,基于公式 (3.10) 的类型异质偏好与公式 (3.1)-(3.4) 的资源动力学,**合作-竞争关系会随 $c$ 单调连续切换,且类型异质性放大这一切换的幅度**。形式化为以下命题:

**命题 3.1(异质偏好下的涌现合作-竞争切换)**。 考虑两人博弈 $N = 2$、单资源点 $K = 1$ 的简化版本,且类型分配为一类型 α + 一类型 β。定义**社会福利缺口**

$$\mathrm{Gap}(c) \;=\; V^{\text{Pareto}}(c) \;-\; V^{\text{Nash}}(c)$$

其中 $V^{\text{Pareto}}(c)$ 是 $c$ 下两人合作最大化总(物理 + 偏好)收益的福利,$V^{\text{Nash}}(c)$ 是两人各自利益最大化纳什均衡下的总收益。则存在 $c^* \in (0, 1)$ 使得:

- 对 $c < c^*$,$\mathrm{Gap}(c) > 0$ 且 $\frac{d}{dc}\mathrm{Gap}(c) < 0$(竞争占优区段,Gap 显著);
- 对 $c > c^*$,$\mathrm{Gap}(c) \approx 0$(合作占优区段,Nash 接近 Pareto);
- $\mathrm{Gap}(c)$ 在 $c$ 上是单调递减的(博弈关系连续切换)。

**证明思路(v4 双通道版)**:

在简化版本中,$N = 2$、$K = 1$,记 $q_t$ 为单点存量,$c$ 为静态丰度。类型 α agent 的最优响应完全由物理项驱动;类型 β agent 的最优响应同时受物理项与 $\phi(c)\psi(\Delta)$ 项驱动。

**Nash 福利的构成**:

- **类型 α 的 Nash 策略**:贪婪采集(在多步博弈中,只要资源够多就立即采),$V_\alpha^{\text{Nash}} \approx \min(\eta_\alpha, q_0/2)$ per step;
- **类型 β 的 Nash 策略**:在 $c$ 低($\phi > 0$)时,Fehr-Schmidt 项放大,β 极度厌恶被甩开 → 与 α 一同贪婪采集(剥削行为),$V_\beta^{\text{Nash}} \approx \min(\eta_\beta, q_0/2)$ per step;在 $c$ 高($\phi < 0$)时,Fehr-Schmidt 项翻转,β 偏好他人多采 → 倾向于让 α 主导采集,自己辅助维持均衡,$V_\beta^{\text{Nash}}$ 物理项较低但偏好项较高。

**Pareto 福利的构成**:

- **协同等再生 + 共采**策略:两人等待 $\tau$ 步让资源再生至接近 $Q_{\max}$,然后共采。物理福利 $\approx 2 \cdot \min(\eta, q_T/2) + \alpha(c) \cdot \tau \cdot Q_{\max}$(再生增益);
- **类型 β 在 Pareto 下的额外收益**:c 高时 $\phi < 0$ 使 β 喜欢均衡共采,Pareto 中 β 的偏好项为正贡献。

**$c \to 0$**:$\alpha(0) = 0.02$,$\phi(0) = +0.5$。
- Pareto:物理再生增益 $0.02 \tau$(很小);Fehr-Schmidt 项被放大,但 Pareto 要求均衡分配($\Delta = 0$),故 $\phi\psi = 0$;Pareto 福利主要来自再生增益,**很小**。
- Nash:β 在荒年极度厌恶被甩开,与 α 一同贪婪采集,但贪婪导致资源迅速崩溃,Nash 福利主要来自 episode 早期的一次性采集 + Fehr-Schmidt 项扣分(因为 Nash 下 $\Delta \neq 0$ 大概率成立,β 被 -2|Δ| 扣分)。
- **Gap(0) 主要来源**:Nash 的 Fehr-Schmidt 负贡献 + Nash 的资源崩溃损失,**显著大**。

**$c \to 1$**:$\alpha(1) = 0.20$,$\phi(1) = -0.5$。
- Pareto:物理再生增益 $0.20 \tau$(大);Fehr-Schmidt 项翻转($\phi < 0$),但 Pareto 均衡分配下 $\Delta = 0$,故 $\phi\psi = 0$;Pareto 福利主要来自再生增益,**大**。
- Nash:β 在丰年偏好他人多采,自己不积极采集,但 α 仍然贪婪采集 → 资源被 α 单方面消耗。β 的偏好项 $\phi\psi$ 在 $\Delta < 0$ 时为正($-0.5 \times -2|\Delta| = +|\Delta|$),Nash 福利包含 β 的偏好正贡献;同时 α 因为单独采集没有资源稀释,物理收益接近 $\eta_\alpha$。
- **Gap(1) 主要来源**:Pareto 与 Nash 都接近最大化(α 贪婪 + β 偏好辅助 = 接近 Pareto 均衡共采的总福利),**很小**。

故 $\mathrm{Gap}(c)$ 在 $c \in [0, 1]$ 上随 $c$ 增加而单调下降,存在切换点 $c^*$。$\blacksquare$

**与 v3 证明的关键差异**:

- **v3 证明依赖 $\beta(c)$ 协同加成的单调性**——这是套套逻辑,因为 $\beta(c)$ 本身是人为指定的单调函数;
- **v4 证明依赖资源时序动力学($\alpha(c)$ 在多步博弈中的累积效应)与类型 β 偏好结构($\phi(c)\psi(\Delta)$ 在 c 调制下的方向翻转)双通道**,两者无人为耦合,Gap(c) 的单调性是**真正的涌现性质**,而非定义后的直接推论。

**完整证明留作实验验证**:命题 3.1 给出了理论直觉,但实际多步博弈下的纳什均衡难以闭式求解。本文在第六章通过**oracle baseline** 的对比实验给出经验证据:

- 在 $c$ 低区段,所有方法的社会福利显著低于 Pareto 上界(公地悲剧 + Fehr-Schmidt 损失);
- 在 $c$ 高区段,所有方法接近 Pareto 上界(合作易达成 + Fehr-Schmidt 翻转助攻);
- 中间区段是各方法的真正区分场,也是本文 Hyper-MuZero 的核心优势区段。

### 3.8.3 评估指标的设计

基于命题 3.1 的洞察,ResourceCommons 配套提供以下评估指标:

| 指标 | 定义 | 物理含义 |
|---|---|---|
| **个体物理福利** $W_i^{\text{phys}}$ | episode 内 $\sum_t u_{i,t}$ | agent $i$ 的累计物理采集量 |
| **个体总福利** $W_i^{\text{total}}$ | episode 内 $\sum_t R_i^t$ | agent $i$ 的累计奖励(含 Fehr-Schmidt 项,仅类型 β 有差异) |
| **社会物理福利** $W_{\text{soc}}^{\text{phys}}$ | $\sum_i W_i^{\text{phys}}$ | 全体 agent 的物理收益之和,**消除偏好层影响,跨配置可比** |
| **社会总福利** $W_{\text{soc}}^{\text{total}}$ | $\sum_i W_i^{\text{total}}$ | 全体 agent 的总收益之和 |
| **公平性** $F$ | $1 - \frac{N \sigma(W_i^{\text{phys}})}{\sum_i W_i^{\text{phys}}}$ | 基于物理福利的 Gini 修正版,$F \in [0, 1]$,越大越公平 |
| **可持续性** $S$ | episode 结束时的全局资源存量 / 初始存量 | 资源是否被可持续利用 |
| **悲剧指数** $T$ | $\mathbb{1}[S < 0.2]$ | 二元指标,资源是否崩溃 |

**v4 新增指标说明**:

- **物理福利 vs 总福利分离**:v3 中所有 agent 同质,只有一个福利定义;v4 中类型 α 与类型 β 总福利不可直接相加(单位不同——α 是纯物理,β 含 Fehr-Schmidt 项),故同时报告**社会物理福利**与**社会总福利**。主对比图表以**社会物理福利**为主指标,因为它跨类型配置可比;
- **公平性基于物理福利计算**:避免类型 β 的 Fehr-Schmidt 项干扰公平性度量。

主对比实验关注**社会物理福利 + 可持续性**的联合表现;消融实验额外关注**公平性**;泛化实验关注**未见 $c$ 值下的物理福利保持率**。

## 3.10 与现有混合博弈环境的比较(v4 更新)

为定位 ResourceCommons 在 mixed-motive MARL 文献中的位置,本节将其与四类经典环境进行对比:

| 环境 | 出处 | 博弈类型 | 关系是否动态 | 偏好结构 | 类型异质性 |
|---|---|---|---|---|---|
| **Harvest** | Leibo et al. 2017 [15] | 序贯社会困境 | 静态 | 同质自利 | 无 |
| **Cleanup** | Hughes et al. 2018 [11] | 公共物品困境 | 静态 | 同质自利 + gifting | 无 |
| **Iterated PD with Inequity Aversion** | Hughes et al. 2018 [11] | 重复矩阵博弈 | 静态 | **异质 Fehr-Schmidt** | 同质 / 二值 |
| **Melting Pot Suite** | Leibo et al. 2021 [14] | 多类混合动机 | 静态(跨场景切换) | 各场景内固定 | 部分场景有 |
| **Conflict-Aware GA 环境** | Kim et al. 2025 [13] | 静态混合博弈 | 静态 | 同质 | 无 |
| **ResourceCommons (本文)** | -- | **关系动态混合博弈** | **动态**,由 $c_t$ 调控 | **异质 Fehr-Schmidt + φ 调制** | **是,类型 α / β** |

**ResourceCommons 的核心区别**:

1. **唯一同时引入"博弈关系动态切换"与"偏好层类型异质"两个维度**——其他环境最多只引入其中一个;
2. **唯一通过 c-调制的 Fehr-Schmidt 实现关系动态**——Hughes 2018 的 inequity aversion 是静态系数,本文的 $\phi(c)$ 在 c 区段反向翻转,实现连续切换;
3. **物理层完全自利同构,偏好层显式异质**——v4 砍除 v3 的 β(c) 协同加成后,物理层回归纯净,合作-竞争完全从偏好结构与时序动力学交互中涌现。

这三点共同构成了 ResourceCommons 作为 **RNS-MMG 类问题首个开源基准环境** 的学术价值,也是 Chapter 1.5 贡献 4 的环境侧落地。

## 3.11 本章小结

本章详细介绍了用于研究关系非平稳混合博弈的 ResourceCommons 基准环境的 v4 最终版。该环境严格遵循三条设计原则:**物理层自利同构 + 偏好层异质 + 博弈涌现于交互**(原则 I)、**上下文是物理状态而非标签**(原则 II)、**物理转移上下文不变**(原则 III)。环境的核心机制包括:

1. **资源场时空动力学**(3.3 节):由 logistic 增长式、邻居影响因子与公平共享上限决定的资源演化方程;**v4 砍除协同加成 β(c)**,物理采集量回归纯净形式 $u_{i,k} = \min(\eta_i, q_k/|H|)$;
2. **斑块化空间分布**(3.3.2 节):多 hotspot 资源点生成,引入空间策略博弈;
3. **共享上下文 $c_t$ 的单通道作用**(3.4 节):仅通过 $\alpha(c)$ 调控资源再生率;**v4 砍除 $c_t$ 对协同加成的第二重作用**;
4. **类型机制与 Fehr-Schmidt 偏好**(3.5 节,**v4 新增**):类型 α(纯自利)与类型 β(Fehr-Schmidt + φ 调制)异质偏好,使梯度撕裂在共享 RewardHead 下不可避免;
5. **异质智能体能力**(3.6 节):四维能力向量塑造策略空间,与类型机制叠加产生交叉异质;
6. **部分可观测 + Self Info 类型设定**(3.7 节):自己类型可见,他人类型由 BeliefNet 推断,严格对应 Harsanyi 框架;
7. **涌现性证明 v4 双通道版**(3.8 节):命题 3.1 证明 Gap(c) 在资源时序动力学与类型 β 偏好结构双通道驱动下单调切换,不再依赖人为指定的 β(c) 形状;
8. **难度分级与主对比配置标注**(3.9 节):Medium (N=4, 2α+2β) 为主对比配置,所有图表强制标注以防误读。

下一章将介绍如何在 ResourceCommons 这一基准上,通过升级版双路超网络(主客解耦 + 类型异质 + 信念状态)实现对动态混合博弈的统一建模,直接兑现 Chapter 1.5 节贡献 2 的三个可证伪断言。
